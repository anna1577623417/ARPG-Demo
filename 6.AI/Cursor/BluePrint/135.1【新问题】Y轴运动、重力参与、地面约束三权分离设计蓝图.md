# Motion Runtime Y Axis V2

## Y轴运动、重力参与、地面约束三权分离设计蓝图

> 本方案用于解决当前 XYZ Motion Runtime 引入 Y 曲线后出现的职责冲突问题，包括：
> 
> - 翻滚动作微量离地
>     
> - 升龙腾空
>     
> - 空中终结技
>     
> - GroundTargeted落地同步
>     
> - Gravity参与时机
>     
> - Motion主导权
>     
> 
> 核心目标：
> 
> **彻底解决 Y 曲线、重力、地面约束之间的职责耦合。**

# 三、问题本质分析

很多系统会把：

```text
Y Motion
Gravity
Ground
```

混为一谈。

---

实际上：

这是三件完全不同的事情。

---

# 第一层

## Y Motion

负责：

```text
角色想去哪里
```

例如：

```text
上升
下落
腾空
后空翻
```

---

这是：

```text
运动意图
```

---

# 第二层

## Gravity

负责：

```text
世界如何影响角色
```

例如：

```text
自然下落
```

---

这是：

```text
环境力
```

---

# 第三层

## Ground Constraint

负责：

```text
是否允许离开地面
```

例如：

```text
翻滚
```

虽然：

```text
YCurve > 0
```

但：

```text
不允许真正飞起来
```

---

这是：

```text
运动约束
```

---

# 当前问题根源

目前枚举：

```csharp
Use Gravity
Suspend Gravity
Motion Controlled
Additive Gravity
Ground Targeted
```

实际上同时承担：

```text
运动来源
重力策略
地面约束
```

三个职责。

---

因此：

```text
翻滚
```

无法表达：

```text
我需要Y曲线

但我不想离地
```

---

# 五、最终蓝图

不要继续扩展：

```csharp

```

---

应该拆成：

# 三层控制系统

---

## Layer1

# Y Motion Mode

决定：

```text
Y位移来自哪里
```

---

```csharp
public enum YMotionMode
{
    None,

    Curve,

    GroundTargeted
}
```

---

### None

```text
不使用Y Motion
```

---

### Curve

```text
使用YCurve
```

---

### GroundTargeted

```text
以地面为目标
```

---

# Layer2

# Gravity Mode

决定：

```text
重力如何参与
```

---

```csharp
public enum GravityMode
{
    UseGravity,

    SuspendGravity,

    AdditiveGravity
}
```

---

注意：

统一命名：

```text
SuspendGravity
```

而不是：

```text
Disabled
```

原因：

```text
重力不是被删除

而是暂时挂起
```

语义更准确。

---

### UseGravity

```text
正常重力
```

---

### SuspendGravity

```text
重力暂停
```

---

### AdditiveGravity

```text
Motion
+
Gravity
```

---

# Layer3

# Ground Constraint

决定：

```text
是否允许离地
```

---

```csharp
public enum GroundConstraintMode
{
    None,

    ClampToGround
}
```

---

### None

```text
允许离地
```

---

### ClampToGround

```text
禁止离地
```

# 十、最终结论

当前问题不是：

```text
YCurve错误
```

而是：

```text
Y Motion
Gravity
Ground Constraint
```

三种职责被压缩进：

```text
Y Policy
```

一个枚举里。

---

最终方案：

将 Y 系统拆分为：

```text
Y Motion Mode
Gravity Mode
Ground Constraint
```

三层治理。

这样才能同时满足：

- 翻滚蹬地但不浮空
    
- 升龙完全导演
    
- 跃击半物理
    
- 空连滞空
    
- 空中终结技精准落地
    

并且与未来的：

- GroundTargeted
    
- Landing Sync
    
- XYZ Motion Runtime
    
- Motion Layer
    

自然兼容，不会再次出现职责混乱。
