## §0 诉求整理（用户原话 → 工程语义）

| # | 用户诉求 | 工程定论 |
|---|----------|----------|
| 1 | Facing 是「类似旋转的东西」，绕 **Y 轴** | Facing 只产出 **Yaw（度）** 或 **LogicForward**；禁止再引入「对齐位移方向」类策略 |
| 2 | 现有旋转曲线「根本没有角度填写」 | `V2YawOverTime` 曲线 Y 轴语义是 **相对偏移度**，不是 **Start/End 绝对角**；策划无法直观配「从 0° 转到 45°」 |
| 3 | **Constant / Curve** 两种策略 | Constant：`End° = Start°`（End 只读）；Curve：`Start° → End°`，归一化曲线 **t∈[0,1]** 做插值 |
| 4 | 曲线 0 = 起点、1 = 完成 | `yaw(t) = LerpAngle(Start°, End°, curve.Evaluate(t))`；Constant 时 `curve` 忽略，恒 `Start°` |
| 5 | **Facing 任何时候不影响位移方向** | 位移基底 **仅** 由 `MotionSpace` + 起手 `CharacterForward/CameraForward/…` 决定；**禁止** `SyncPlanarForward`、禁止 `DisplacementAligned` |
| 6 | Motion Space 是 **XYZ 局部坐标系** | X=Right、Y=Up、Z=Forward（与 `MotionAxisCurves` 注释一致）；位移与 Yaw **独立通道** |
| 7 | 回撤 TL Facing 预览、Motion Space 位移对齐枚举 | 删除 Timeline `Facing` 下拉 / 紫色箭头 / `UsesMotionFacingPreview` 全链 |
| 8 | **最终零 210.2 残余** | 见 §6 删除清单；grep `210.2` / `DisplacementAligned` / `AlignToVelocity` / `MotionFacing` 主循环命中为 0 |

### §0.1 210.2 为何被否决（复盘）

```
210.2 假设：AlignToVelocity / DisplacementAligned 可让 Slide 斜向「位移+朝向」一致
实际后果：
  · AlignToVelocity 旋转位移基底 → 轨迹偏离 MP（TL 橙线变水平向左）
  · DisplacementAligned 把 Route 意图绑进 Motion 层 → 与 MotionSpace 职责重叠
  · Facing 写 LogicForward + SyncPlanarForward → 表现/位移/逻辑三轨纠缠
用户裁定：Facing 纯表现；Slide 斜向靠 MP 的 X/Z 曲线 + 固定 MotionSpace 解决
```

## §1 核心契约（单页，Landing 前必读）

### §1.1 双通道分离

```
┌─────────────────────────────────────────────────────────┐
│ 通道 A · 位移（Gameplay）                                │
│   MotionSpace → 固定起手 planarForward                   │
│   AxisCurves X/Y/Z → worldDelta（每帧）                  │
│   ★ 整段 Action 内基底不随 Facing 变化                    │
└─────────────────────────────────────────────────────────┘
                          ∥ 同帧并行，无写耦合
┌─────────────────────────────────────────────────────────┐
│ 通道 B · Yaw / Facing（Presentation → 可选写 LogicForward）│
│   YawPolicy: None | Constant | Curve                     │
│   StartYaw° / EndYaw°（相对 Action 起手 forward）         │
│   ★ 只影响朝向；VisualFacingDriver 跟随 LogicForward      │
└─────────────────────────────────────────────────────────┘
```

### §1.2 时间与结算

| 概念 | 唯一权威 | 禁止 |
|------|----------|------|
| 位移 world 位置 | `MotionExecutor` + 固定 `_direction`（Begin 写入，End 清除） | Facing 帧改 `_direction` |
| Action 起手 forward | `PlayerActionState` Enter 时 `burstFaceDir`（现有 `ResolveFacingDirection` 简化版） | `DisplacementAligned` intent |
| Yaw 采样时刻 | `motionT`（与 AxisCurves 同锚） | 用 clip 时间轴另算 |
| LogicForward 写入 | **仅** Yaw 通道（或既有 InputContext 冻结策略） | `AlignToVelocity` 读 `worldDelta` |

### §1.3 Yaw 角度语义

| 字段 | 含义 |
|------|------|
| **参考系** | 相对 **Action 进入时刻** 的 `burstFaceForward`（世界水平面） |
| **StartYaw°** | `motionT=0` 时相对偏移（通常 0） |
| **EndYaw°** | `motionT=1` 时相对偏移；Constant 策略下 **Inspector 只读 = StartYaw°** |
| **Curve** | 归一化 `[0,1]`→`[0,1]` 插值因子；**不是**「度」 |
| **运行时 yaw** | `finalYaw = startBurstYaw + LerpAngle(StartYaw°, EndYaw°, f)`，`f = curve.Eval(motionT)` 或 Constant 时 `f=0` |

> **命名**：保留字段前缀 `V2` 或改为 `Yaw` 均可；**不新增** `RotationMode.AlignToVelocity` 等等价枚举。`RotationMode` 可收敛为 `None | Yaw` + 独立 `YawPolicyMode { None, Constant, Curve }`（Landing 1 定稿）。

## §2 目标数据模型（MotionProfileSO）

### §2.1 新增 / 替换字段（草案）

```csharp
// 策略（替代 V2RotationMode 的 Align* 分支）
public YawPolicyMode YawPolicy = YawPolicyMode.None;

// 相对 Action 起手 forward 的偏移角（度）
public float YawStartDegrees = 0f;
public float YawEndDegrees = 0f;   // Constant 时 Inspector 锁定只读

// 仅 YawPolicy=Curve 时生效；Evaluate(t)∈[0,1] 作插值因子
public AnimationCurve YawBlendOverTime = AnimationCurve.Linear(0f, 0f, 1f, 1f);
```

**删除 / Obsolete 后移除**：

- `V2RotationMode` 的 `AlignToVelocity`、`AlignToTargetLock`
- `V2AlignMinPlanarSpeed`、`V2AlignMaxDegreesPerSec`
- `MotionSpace.DisplacementAligned`（枚举值 4）
- `V2YawOverTime`（「度曲线」旧语义）→ 由 Start/End + Blend 曲线替代

### §2.2 Inspector 行为

| YawPolicy | StartYaw° | EndYaw° | YawBlendOverTime |
|-----------|-----------|---------|------------------|
| **None** | 隐藏 | 隐藏 | 隐藏 |
| **Constant** | 可编辑 | **灰色只读**（= Start） | 隐藏 |
| **Curve** | 可编辑 | 可编辑 | 显示；Validate：Curve 必填、keys≥2 |

HelpBox 文案：**「Yaw 仅影响朝向，不改变 MP 位移轨迹。位移请编辑 XYZ 曲线 + Motion Space。」**

### §2.3 Slide_FL 配表示例（新模型）

| 项 | 值 |
|----|-----|
| MotionSpace | `CharacterForward`（或 Group 仍用 BodyFixed 解析 Route，**不**改 Motion 基底） |
| AxisCurves X | 负向分量（左） |
| AxisCurves Z | 正向分量（前） |
| YawPolicy | `Curve` |
| YawStart° / YawEnd° | 按视觉需求填（如 0 → 45） |
| YawBlendOverTime | EaseInOut 0→1 |

**不再使用**：`DisplacementAligned`、Facing 槽位、AlignToVelocity。

## §3 运行时通路（单轨）

### §3.1 帧序（Action 期）

```
PlayerActionState.Tick
  → MotionExecutor.Tick          // 通道 A：worldDelta，_direction 固定
  → ActionMotionPlayback.ApplyActionYaw(player, action)   // 通道 B：新名，替代 ApplyMotionFacing
       SampleYawDegrees(motionT) → desiredForward
       player.SetLogicForwardFromActionYaw(desiredForward)  // 或 Visual-only 变体（见 §3.3）
  → VisualFacingDriver 既有跟随 LogicForward
```

### §3.2 核心 API（设施表）

| 类型 | 职责 |
|------|------|
| `MotionProfileSO.SampleActionYawDegrees(motionT)` | 唯一 Yaw 采样 |

### §3.3 Logic vs Visual（与 184.1 对齐）

## §9 面试口述总结

210.5 把 Action 期的 **位移** 和 **朝向** 彻底拆成两条平行管道：位移只看 MotionSpace 下的 XYZ 曲线，整段 Action 基底不变；朝向用 **Start/End 角度 + 0~1 混合曲线** 做绕 Y 轴旋转，是表现层机制。210.2 的 AlignToVelocity 和 DisplacementAligned 因把朝向耦合进位移基底而被整体回撤；Timeline 只忠实预览 MP 轨迹，Yaw 用独立箭头表达，不再污染橙色位移线。
