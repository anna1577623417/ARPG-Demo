# 160.2【蓝图】SO 列表「源→目标」安全同步机制落地蓝图

---

## 〇、问题与目标

### 0.1 典型风险（160.1 归纳）

双数据源独立维护时必然漂移：

| 源（Authority） | 目标（Derived） | 常见事故 |
|---|---|---|
| `EnabledStates` [Flags] | `Bindings[]` | 勾了 Sprint 但没 Binding → 一级降级静默 |
| | | Binding 留了废弃 State → 策划以为仍生效 |
| | | 同一 State 重复两条 → Resolver 不确定命中哪条 |

**根因**：`源 ≠ 目标` 且 Editor **无 Fail-Fast 安全网**。

### 0.2 本蓝图目标

建立 **可复用的 Editor 配置安全机制**（非仅 Locomotion 特例）：

```
Authority（唯一真相）
    ↓ Sync（只追加缺失，不覆盖已有配置）
Target List（Bindings / 明细列表）
    ↓ Validate（Missing / Duplicate / Unused）
Inspector 实时告警 + OnValidate 缓存
    ↓ AutoFix（安全项一键修复；删除须确认）
```

**不做（本切片）**：

- ❌ 运行时双轨 / fallback 掩盖漏配
- ❌ 一键 Migrate 全项目 SO 的批处理菜单（见 `12-no-unrequested-scaffolding.mdc`）
- ❌ Phase 5「彻底 Dictionary 化」全量重构（列为 OPEN，非本切片 WIRE）

## 一、设计契约（单一真相）

### 1.1 术语

| 术语 | 含义 | LocomotionProfile 实例 |
|---|---|---|
| **Authority** | 策划勾选的「拥有哪些能力」 | `enabledStates`（`LocomotionStateFlag`） |
| **Target** | 每条能力的具体配置 | `bindings[]`（`LocomotionStateBinding`） |
| **Simple Key** | 1 Authority 项 → 1 Target 行 | `State=Idle` 唯一一行 |
| **Composite Key** | 1 Authority 项 → N Target 行 | `State=StrafeLocomotion` + `StrafeDirection` + `RunRequirement` |

### 1.2 同步铁律（强制）

| # | 规则 | 违反后果 |
|---|---|---|
| S1 | **Authority 为唯一真相**；Target 不得反向定义「启用集合」 | 双源漂移 |
| S2 | **Sync 只追加缺失项**；已存在 Target 行的 Clip/Action/数值 **禁止覆盖** | 策划配表被洗 |
| S3 | **Duplicate = Error**；Missing = Warning；Unused = Warning | Fail-Fast |
| S4 | 删除 Unused **必须** `EditorUtility.DisplayDialog` 确认 | 误删 |
| S5 | `Undo.RecordObject` + `EditorUtility.SetDirty` 包裹一切写 SO 操作 | 无法撤销 |
| S6 | Composite Key 状态 **不得**用 Simple 1:1 Sync 粗暴合并 | Strafe 16 行被压成 1 行 |

### 1.3 校验维度

```csharp
// 概念模型 — Editor/Utilities/AuthorityTargetSyncReport.cs
public struct AuthorityTargetSyncReport
{
    public List<TKey> Missing;    // Authority 有、Target 无
    public List<TKey> Unused;     // Target 有、Authority 无
    public List<TKey> Duplicate;  // Target 内同 Key 出现 >1 次
    public bool HasErrors => Duplicate.Count > 0;
    public bool HasWarnings => Missing.Count > 0 || Unused.Count > 0;
}
```

### 2.2 通用 API 签名

```csharp
public static class AuthorityTargetListSync
{
    public static AuthorityTargetSyncReport Validate<TKey>(
        IReadOnlyCollection<TKey> authority,
        IReadOnlyList<TKey> targetKeys,
        IEqualityComparer<TKey> comparer);

    /// <summary>仅追加 authority 中缺失的 key；factory 创建默认行。</summary>
    public static int SyncAppendMissing<TKey, TRow>(
        IList<TRow> target,
        IReadOnlyCollection<TKey> authority,
        Func<TKey, TRow> factory,
        Func<TRow, TKey> getKey,
        IEqualityComparer<TKey> comparer);

    /// <summary>AutoFix：补 Missing + 去 Duplicate（保留首条）；Unused 仅当 removeUnused=true 且用户确认。</summary>
    public static void AutoFix<TKey, TRow>(...);
}
```

### 2.3 Inspector UI 契约（所有试点 SO 统一）

```
┌─ Validation ─────────────────────────────┐
│ ⚠ Missing Bindings: Sprint, JumpStart   │  HelpBox Warning
│ ❌ Duplicate: Idle ×2                   │  HelpBox Error
│ ⚠ Unused: Pivot                         │  HelpBox Warning
│ [ Sync Bindings ] [ Auto Fix ] [ Remove Unused… ] │
└─────────────────────────────────────────┘
── Enabled States (Authority) ──
── Bindings (Target) ──
```

- 按钮顺序：**Sync** → **Auto Fix** → **Remove Unused**（危险操作放最后）
- Validation 区 **常驻展开**（非 Foldout）；属 Runtime 安全，不是可选工具

## 三、LocomotionProfile 试点适配

### 3.1 Key 策略

| State 类型 | Sync 策略 | Validate Duplicate |
|---|---|---|
| 普通 Id（Idle/Move/WalkEnd…） | Simple：`LocomotionStateId` | 同 State 出现 >1 且 Strafe/Turn=None 且 RunReq=Any |
| `StrafeLocomotion` | **不**随 Simple Sync 自动建 16 行；提供 **[ Expand Strafe Templates ]** 子按钮 | Composite：(State, StrafeDirection, RunRequirement) |
| `TurnInPlaceDirected` | **[ Expand Turn Templates ]** 建 4 向 | Composite：(State, TurnDirection) |
| Obsolete（Stop/RunStartLegacy） | 不参与 Authority；Unused 告警可一键清理 | — |

### 3.2 Sync Bindings 行为（Simple 部分）

```
Enabled: ✓ Idle ✓ Move ✓ WalkEnd ✓ RunEnd

Bindings 原有:
  Idle    Clip=A
  Move    Clip=B

点击 [Sync Bindings] →

  Idle     Clip=A      （保留）
  Move     Clip=B      （保留）
  WalkEnd  空          （新增）
  RunEnd   空          （新增）
```

### 3.3 OnValidate（二次校验）

```csharp
#if UNITY_EDITOR
void OnValidate()
{
    // 仅写缓存字段 validationSummary，不弹窗、不改 bindings
    validationSummary = LocomotionProfileSyncAdapter.Validate(this);
}
[SerializeField] string validationSummary; // Inspector 只读展示
#endif
```

- `[LocoProfileSync] Sync added 2 bindings: WalkEnd, RunEnd`
- `[LocoProfileSync] AutoFix removed 1 duplicate: Idle`

**本落位不做**：Strafe/Turn Expand 模板按钮（L3）

### L3/3 — Composite 模板 + 文档化复用

**Slice 验收**：
