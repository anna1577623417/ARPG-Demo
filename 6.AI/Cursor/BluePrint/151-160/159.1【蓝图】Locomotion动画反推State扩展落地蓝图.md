### 1.3 本次设计判定

**159.1 Locomotion 切片范围（定稿）**：Walk/Run **起停四态** State 拆分 +（可选后续 Landing）Strafe / Turn。**不含 Slide**。

#### 起停四态拆分

| 旧合一 State | 新 State | 枚举 | Clip |
|---|---|---|---|
| `Stop=5` | `WalkEnd` | 15 | `Walk_End_Root` |
| | `RunEnd` | 16 | `Run_End_Root` |
| `RunStart=7` | `WalkStart` | 17 | `Walk_Start_Root` |
| | `RunStart` | 18 | `Run_Start_Root` |

- **不再**用 `Stop` / 旧 `RunStart` + `RunRequirement` 查表区分走/跑。
- 四态共用 **`m_lastWantsRun` latch 体系**（press / release 读档规则见 §1.4、§1.5）。
- 未注册 → 不 FIRE（158.2 一级降级，零回归）。

**本切片后续扩展（L1+，非 L0）**：`StrafeLocomotion=19`、`TurnInPlaceDirected=20`（见 §3.1）。

**明确不做**：`LocomotionStateId.Slide`、`GameplayIntentKind.Slide`、Locomotion Profile 滑铲 Binding — 滑铲属 **Skill 域**（§1.6）。

**`RunRequirement` 保留用途**：仅 **StrafeLocomotion** 8 向查表；不用于起停四态。

### 1.4 WalkEnd / RunEnd 解算机制（release 边沿）

#### 1.4.1 设计目标

- 走停与跑停是**不同动作单元**（不同 Clip、时长、后摇 Window），与起停四态对称，用 **State 级拆分** 而非 Profile 过滤。
- Profile 未注册 → 不 `ArmPendingAction`，松开 WASD 直接 `Idle`（158.2 一级降级）。
- Resolver **纯函数**：Detect 阶段即产出 `WalkEnd` / `RunEnd`，不在 Resolver 内二次分流。

#### 1.4.2 触发条件（release 边沿）

与现 `Stop` 相同，仅 **移动意图释放边沿**：

```
wasHadInput = m_lastHadInput
hasInput    = player.HasMovementIntent

releaseEdge = wasHadInput && !hasInput
```

**不参与**：Pivot 冷却中仍先判 Pivot（优先级高于 release，与 158.2 一致）。

#### 1.4.3 速度档 latch（release 读档）

松手帧 `player.WantsRun` **不可靠**（松 W 与松 Shift 同帧乱序）。release 使用 **最后仍有输入的帧** 缓存的速度档：

```csharp
// PlayerLocomotionState 私有字段
bool m_lastWantsRun;

// TryRouteDiscreteLocomotionAction 末尾（与 m_lastHadInput 同位更新）
if (hasInput)
    m_lastWantsRun = player.WantsRun;

// DetectRequestedState — release 分支
if (m_lastHadInput && !hasInput)
{
    return m_lastWantsRun
        ? LocomotionStateId.RunEnd
        : LocomotionStateId.WalkEnd;
}
```

| 场景 | latch | RequestedState |
|---|---|---|
| 走停（无 Shift）松 W | `m_lastWantsRun=false` | `WalkEnd` |
| 跑停（按住 Shift 跑）松 W | `m_lastWantsRun=true` | `RunEnd` |
| 跑中松 Shift 再松 W（同帧） | 以**最后仍有输入的帧**的 WantsRun 为准 | 按 latch |
| 重新进入 Locomotion（158.2 OnEnter） | `m_lastHadInput=false`（已有） | 不触发 release |
| Sprint 连续态（未来） | Sprint 视为 Run 档：`WantsRun \|\| IsSprinting` | `RunEnd`（L0 可仅 WantsRun） |

#### 1.4.4 DetectRequestedState 优先级（v2 · 起停四态段）

```
1. Pivot（大角 + 有输入 + 非冷却）
2. release 边沿 → WalkEnd | RunEnd     （读 m_lastWantsRun，§1.4.3）
3. press 边沿   → WalkStart | RunStart （读当帧 WantsRun，§1.5.3）
4. 持续 hasInput → Move
5. !hasInput     → Idle
```

（LockedOn / Strafe / Turn 为 L1+，见 §5.2 完整版。）

**删除 Detect 产出**：`Stop`（5）、旧合一 `RunStart`（7）。

#### 1.4.5 shouldTrigger（FIRE 门控 · End）

```csharp
var shouldTrigger = decision.ResolvedState switch
{
    LocomotionStateId.WalkEnd   => wasHadInput && !hasInput,
    LocomotionStateId.RunEnd    => wasHadInput && !hasInput,
    LocomotionStateId.WalkStart => !wasHadInput && hasInput,
    LocomotionStateId.RunStart  => !wasHadInput && hasInput,
    LocomotionStateId.Pivot     => hasInput && m_pivotCooldownRemaining <= 0f,
    LocomotionStateId.TurnInPlace => m_pivotCooldownRemaining <= 0f,
    _ => false,
};
```

End 与 Start **各用对应边沿**；Walk/Run 互斥由 Detect 保证。

| `RunEnd` | `Action_Loco_RunEnd` | `Idle` |

### 1.5 WalkStart / RunStart 解算机制（press 边沿）

#### 1.5.1 设计目标

- 起步与跑起步是不同 Clip（`Walk_Start_Root` / `Run_Start_Root`），与 End 对称拆 State。
- 与 158.2 `RunStart` 合一 Action 解耦：Detect **不再**产出 `LocomotionStateId.RunStart`（7）。

#### 1.5.2 触发条件（press 边沿）

```
pressEdge = !wasHadInput && hasInput
```

与 End 对称：Idle（或 Action 收招回 Locomotion 且 `m_lastHadInput=false`）后首次按下 WASD。

#### 1.5.3 速度档读档（press 用当帧 WantsRun）

press 边沿与 release **共用** `m_lastWantsRun` 字段的维护规则，但 **读档时机不同**：

| 边沿 | 读档 | 原因 |
|---|---|---|
| **press** | **当帧** `player.WantsRun` | Idle 期间 latch 过期；按下瞬间 Shift 即表达走/跑意图 |
| **release** | **`m_lastWantsRun`** | 松手帧 Shift/W 顺序不可信 |

```csharp
// 每帧维护（与 m_lastHadInput 同序，在 Detect 之后更新）
if (hasInput)
    m_lastWantsRun = player.WantsRun;

// DetectRequestedState — press 分支
if (!m_lastHadInput && hasInput)
{
    return player.WantsRun
        ? LocomotionStateId.RunStart   // = 18
        : LocomotionStateId.WalkStart; // = 17
}
```

| 场景 | 当帧 WantsRun | RequestedState |
|---|---|---|
| Idle 按 W（无 Shift） | false | `WalkStart` |
| Idle 按 W+Shift | true | `RunStart` |
| 走停 Action 播完回 Locomotion 再按 W | 按当帧 Shift | WalkStart / RunStart |
| 未注册 WalkStart | — | 无 FIRE，直接 Move 连续 Clip（158.2 V4.2 同级） |

#### 1.5.4 Profile / 迁移

| State | DiscreteAction | FallbackState |
|---|---|---|
| `WalkStart` | `Action_Loco_WalkStart` | `Move`（或 `Idle`，设计师定） |
| `RunStart` | `Action_Loco_RunStart` | `Move` |

- **迁移**：旧 `RunStart=7` 单 Binding → 拆 WalkStart + RunStart 两条；关旧 `RunStart` flag。
- 代码：`RunStart=7` 标 `[Obsolete]`；新 `RunStart=18` 与旧值并存至资产清理完毕。

#### 1.5.5 验收 Log（L0 · Start）

| 通电点 | 预期 Log |
|---|---|
| 走起 FIRE | `[LocoResolver] FIRE state=WalkStart action=Action_Loco_WalkStart …` |
| 跑起 FIRE | `[LocoResolver] FIRE state=RunStart action=Action_Loco_RunStart …` |
| 未注册 WalkStart | 无 FIRE；首帧直接 Move Loop（零回归） |

## 四、Profile 查表（二维匹配）

### 4.1 新查询签名

```csharp
public class LocomotionProfile : ScriptableObject
{
    // 既有 GetBinding(LocomotionStateId) 保留作为单 key 入口

    /// <summary>
    /// 159.1：方向化 + 速度档查表（Strafe / Turn 专用；WalkEnd/RunEnd 不用）。
    /// 优先级（命中即返回）：
    ///   1. State + StrafeDirection + TurnDirection + RunRequirement 全精确
    ///   2. State + 方向精确 + RunRequirement=Any
    ///   3. State + StrafeDirection=None + RunRequirement=Any（兜底默认）
    /// </summary>
    public LocomotionStateBinding GetBinding(
        LocomotionStateId state,
        StrafeDirection8 strafeDir,
        TurnDirection4 turnDir,
        bool wantsRun)
    {
        // 第 1 轮：全精确
        for (var i = 0; i < bindings.Length; i++)
        {
            var b = bindings[i];
            if (b.State == state
                && b.StrafeDirection == strafeDir
                && b.TurnDirection == turnDir
                && RunMatch(b.RunRequirement, wantsRun))
            {
                return b;
            }
        }
        // 第 2 轮：方向精确 + RunReq 任意
        for (var i = 0; i < bindings.Length; i++)
        {
            var b = bindings[i];
            if (b.State == state
                && b.StrafeDirection == strafeDir
                && b.TurnDirection == turnDir
                && b.RunRequirement == LocomotionRunRequirement.Any)
            {
                return b;
            }
        }
        // 第 3 轮：State 兜底（方向 None + RunReq Any）
        for (var i = 0; i < bindings.Length; i++)
        {
            var b = bindings[i];
            if (b.State == state
                && b.StrafeDirection == StrafeDirection8.None
                && b.TurnDirection == TurnDirection4.None
                && b.RunRequirement == LocomotionRunRequirement.Any)
            {
                return b;
            }
        }
        return default;
    }

    static bool RunMatch(LocomotionRunRequirement req, bool wantsRun) => req switch
    {
        LocomotionRunRequirement.WalkOnly => !wantsRun,
        LocomotionRunRequirement.RunOnly  => wantsRun,
        _ => true,
    };
}
```

### 4.2 旧单 key `GetBinding(LocomotionStateId)` 保留

向后兼容：仍可仅按 State 查（用 `StrafeDir=None, TurnDir=None, wantsRun=false` 调上面新版）。

### 5.3 StrafeDirection8 计算（局部空间 8 等分）

```csharp
static StrafeDirection8 ComputeStrafeDirection(Vector3 worldInput, Vector3 forward)
{
    // 转到角色局部空间
    var local = Quaternion.Inverse(Quaternion.LookRotation(forward, Vector3.up)) * worldInput;
    var x = local.x;
    var z = local.z;
    var angle = Mathf.Atan2(x, z) * Mathf.Rad2Deg; // [-180, 180]
    // 按 45° 切片
    var sector = Mathf.RoundToInt(angle / 45f);
    return sector switch
    {
        0           => StrafeDirection8.Forward,
        1           => StrafeDirection8.ForwardRight,
        2           => StrafeDirection8.Right,
        3           => StrafeDirection8.BackwardRight,
        4 or -4     => StrafeDirection8.Backward,
        -3          => StrafeDirection8.BackwardLeft,
        -2          => StrafeDirection8.Left,
        -1          => StrafeDirection8.ForwardLeft,
        _           => StrafeDirection8.Forward,
    };
}
```

### 5.4 TurnDirection4 推导（沿用 TurnResolver）

```csharp
static TurnDirection4 ComputeTurnDirection(TurnInfo info)
{
    if (!info.IsTurning) return TurnDirection4.None;
    return (info.Type, info.Direction) switch
    {
        (TurnType.Turn90,  -1) => TurnDirection4.Left90,
        (TurnType.Turn90,  +1) => TurnDirection4.Right90,
        (TurnType.Turn180, -1) => TurnDirection4.Left180,
        (TurnType.Turn180, +1) => TurnDirection4.Right180,
        _ => TurnDirection4.None,
    };
}
```
