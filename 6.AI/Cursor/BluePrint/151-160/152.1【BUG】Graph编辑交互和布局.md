```text

```

```text

50%
```

左右分。

---

导致：

```text
Target Route
```

特别拥挤。

---

建议：

```text
Label = 90px

Value = Fill
```

---

```text

Input Slot     [Any ▼]
```

```text
Transition
[On Input]
```

# 给AI的最终Prompt（建议直接复制）

```text
目标：
将Combat Flow编辑器改造成专业Graph编辑器体验，对标Unity Animator、ShaderGraph、UE Blueprint。

重点不是新增功能，而是修复布局系统、滚动系统和Inspector交互体验。

========================
【1】Inspector布局
========================

Flow Edge Inspector固定停靠在右侧。

默认宽度：

320px

支持拖拽调整：

MinWidth = 260
MaxWidth = 700

拖拽分隔条时：

显示Resize Cursor（←→）

Hover高亮分隔条。

Inspector整体增加Padding：

Left = 8
Right = 8
Top = 6
Bottom = 6

分组之间增加8px间距。

========================
【2】滚动系统
========================

Inspector内部只允许存在一个ScrollView。

禁止嵌套ScrollView。

禁止出现双竖滚动条。

Inspector永远不显示横向滚动条。

字段超出时自动缩放。

showHorizontal = false。

========================
【3】字段布局
========================

采用两列布局：

Label Width = 90px

Value Width = Flex

示例：

Transition    [On Input ▼]

Priority      [0]

Input Slot    [Any ▼]

Target Route  [Route Asset]

不要使用全宽字段。

不要出现长条状浪费空间布局。

========================
【4】Transition默认值
========================

新建FlowEdge时：

Transition默认：

On Input

而不是：

On Segment Complete

因为绝大多数Combat Flow边都属于输入驱动。

========================
【5】Selection逻辑
========================

Edge单选：

显示Edge Inspector

Node单选：

显示Node Inspector

多选：

显示Multi Selection

框选多个对象：

禁止自动打开Edge Inspector

Inspector只在单选时显示具体属性。

========================
【6】Category显示
========================

ActionWindow支持多个Category。

不要只显示第一个Category。

改为：

cat=3 categories

鼠标悬停显示Tooltip：

Offense
Movement
Skill

或者直接显示：

Offense | Movement | Skill

========================
【7】Toolbar状态
========================

增加GraphDirty状态。

Graph未修改：

Compile按钮灰色。

Graph发生修改：

Compile按钮可点击。

Compile成功：

重新变灰。

Validate同理。

========================
【8】最终目标
========================

整体体验参考：

Unity Animator
ShaderGraph
Unreal Blueprint

重点优化：

边距
滚动
字段密度
选择逻辑
Inspector稳定性

而不是继续增加Combat Flow功能。
```
