## §0 重新理解：Intent 与 Transition 的语义切分

### §0.1 旧理解的语法错位

184.1 / 184.3 蓝图里写过："**Tap Turn 是全局 Intent**"。

实测后发现这条原则**对 Stop 不成立**：

```
Run → 松开 W → RunEnd（急停中）→ Tap D
  ↓ 旧实现：Tap Turn 作为全局 Intent 立刻触发
RunEnd 动画播一半 → Turn90R 闪一下 → 又回到 RunEnd 急停
  ↓ 玩家视觉：
"角色抽了一下"
```

**根因**：Turn 被错误地提升成了 Intent，导致它与 Stop 这种"已经在解释方向变化"的 Transition 同时获得表现权。

### §0.2 真正的分类（**Intent vs Transition**）

```
┌─────────────────────────────────────────────────────┐
│  Player Intent（玩家主动表达的目的）                 │
│  ────────────────────────────────────────           │
│  Move      "我要移动"      ← Hold WASD              │
│  Stop      "我要停下"      ← Release WASD（隐式）   │
│  Dodge     "我要闪避"      ← Space                  │
│  Attack    "我要攻击"      ← LMB                    │
│  Jump      "我要跳跃"      ← Space（情境）          │
│  Skill     "我要施法"      ← 各技能键               │
│  Guard / Parry / Execute   ← 各专属键               │
│                                                      │
│  ★ 玩家从来没有按"Turn 键"或"End 键"               │
└─────────────────────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│  Transition（系统插入的表现补偿）                    │
│  ────────────────────────────────────────           │
│  Start     起步补偿        (WalkStart / RunStart)   │
│  End       急停补偿        (WalkEnd / RunEnd)       │
│  Turn      静止转向补偿     (Turn90 / Turn180)      │
│  Pivot     运动重定向补偿   (Pivot180)              │
│                                                      │
│  ★ 这些不是玩家意图，是系统为表达 Intent 而插入的桥接 │
└─────────────────────────────────────────────────────┘
```

### §0.3 关键定理

> **Transition 不是叠加系统，而是替代系统。**
>
> Start / End / Turn / Pivot 本质上都在回答同一个问题：
> **"玩家意图发生变化时，系统该如何把这个变化表现出来？"**
>
> 既然回答同一个问题，**一次变化只允许一个 Transition 拥有表现权**。

## §1 Motion Grammar 设计哲学

### §1.1 把角色控制器视为语言系统

| 语言系统 | 角色控制器 |
|---|---|
| 词汇（Vocabulary）| 玩家输入（WASD / Space / LMB / ...）|
| 词性（Part of Speech）| Intent（动词）vs Transition（连接词）|
| 句子（Sentence）| 一连串动作输出 |
| **语法（Grammar）** | **Motion Grammar：哪些组合合法，哪些禁止** |

**类比**：
- 中文："主语 + 谓语 + 宾语" 合法；"主语 + 主语 + 宾语" 不合法
- 动作："Intent + Transition + State" 合法；"Transition + Transition" 大多不合法

### §1.2 三条核心原则

| 原则 | 含义 |
|---|---|
| **Intent 同一时刻只有一个** | 玩家不会同时想"闪避+攻击+转身" |
| **Transition 服务于 Intent** | 永远是"为了表达 Intent 才插入"，从不独立存在 |
| **Transition 之间不能自由组合** | 同一时刻一种 Transition 获得表现权，其它被替代或吞掉 |

### §1.3 Stop 吃掉 Turn 的本质

```
玩家按 W → Hold → "我要移动" Intent
玩家松开 W → 系统识别为"我要停下"（隐式 Stop Intent）
        ↓
系统插入 End Transition（RunEnd 急停补偿）→ ★ 已经在"消费方向变化"
        ↓
玩家此时按 Tap D
        ↓
旧错误：又插入一个 Turn Transition（叠加）→ 抽动
        ↓
正解：Stop 已经获得表现权 → Turn 不能同时插入 → 缓存 PendingFacing
        ↓
RunEnd 结束 → 应用 PendingFacing → Idle
```

**核心**：**Stop 不仅消费"停"，还顺带消费了"方向变化"**。再加 Turn 是意图重复，必产抽动。

## §2 数据架构：TransitionType + Grammar

### §2.1 `TransitionType` 枚举（四原型）

```csharp
public enum TransitionType : byte
{
    None    = 0,    // 非 Transition Action（Attack / Dodge / Skill 等）
    Start   = 1,    // 起步：Idle/Stop → Locomotion
    End     = 2,    // 急停：Locomotion → Idle  ★ Stop 表现权
    Turn    = 3,    // 静止转向：Idle → Facing 变 → Idle
    Pivot   = 4,    // 运动重定向：Run → 反向 → Run
}
```

### §2.2 `MotionGrammarRule` 语义属性（非自由勾选）

```csharp
[Serializable]
public struct MotionGrammarRule
{
    [Tooltip("拥有表现权 = 占据 Animator 主轨；其它 Transition 不能同时表现。")]
    public bool OwnsPresentation;

    [Tooltip("消费方向变化 = 已表达了方向意图；后续 Tap Turn 不再插入。")]
    public bool ConsumesDirectionChange;

    [Tooltip("消费动量变化 = 已表达了速度/动量变化；后续 Pivot 不再插入。")]
    public bool ConsumesMomentumChange;

    [Tooltip("阻止其它 Transition = 本 Transition 期间所有同源 Transition 都被吞掉。")]
    public bool BlocksOtherTransitions;
}
```

### §2.3 4 个 Grammar 原型（**少量、稳定、高层**）

```
TransitionType.Start (WalkStart / RunStart)
  OwnsPresentation         = true
  ConsumesDirectionChange  = true   ← 起步本身就指向新方向
  ConsumesMomentumChange   = true   ← 0→运动速度
  BlocksOtherTransitions   = true   ← 起步期间不能再插 Turn

TransitionType.End (WalkEnd / RunEnd / CrouchEnd)
  OwnsPresentation         = true
  ConsumesDirectionChange  = true   ← ★ 关键：Stop 已消费方向变化
  ConsumesMomentumChange   = true   ← 速度→0
  BlocksOtherTransitions   = true   ← End 期间 Turn / Pivot 不能插

TransitionType.Turn (Turn90 / Turn180)
  OwnsPresentation         = true
  ConsumesDirectionChange  = true
  ConsumesMomentumChange   = false  ← Turn 不动速度
  BlocksOtherTransitions   = true   ← Turn 期间不能再 Pivot

TransitionType.Pivot (Pivot180)
  OwnsPresentation         = true
  ConsumesDirectionChange  = true
  ConsumesMomentumChange   = true   ← Pivot 含动量翻转
  BlocksOtherTransitions   = true
```

### §2.4 数据继承策略

```csharp
public partial class ActionDataSO
{
    [Header("Motion Grammar (184.4)")]
    [Tooltip("此 Action 的 Transition 角色；非 Transition Action 选 None（=不参与 Grammar 决策）。")]
    public TransitionType TransitionType = TransitionType.None;

    [Tooltip("少数特殊角色可覆写 Grammar（如绝区零式 Redirectable End）；默认走 Type 原型。")]
    public bool OverrideGrammar = false;
    public MotionGrammarRule GrammarOverride;
}

// 全局 4 份原型（ScriptableObject 或常量表）：
public static class MotionGrammarPrototypes
{
    public static readonly MotionGrammarRule Start = new() { OwnsPresentation = true, ConsumesDirectionChange = true, ConsumesMomentumChange = true, BlocksOtherTransitions = true };
    public static readonly MotionGrammarRule End   = new() { OwnsPresentation = true, ConsumesDirectionChange = true, ConsumesMomentumChange = true, BlocksOtherTransitions = true };
    public static readonly MotionGrammarRule Turn  = new() { OwnsPresentation = true, ConsumesDirectionChange = true, ConsumesMomentumChange = false, BlocksOtherTransitions = true };
    public static readonly MotionGrammarRule Pivot = new() { OwnsPresentation = true, ConsumesDirectionChange = true, ConsumesMomentumChange = true, BlocksOtherTransitions = true };
}

// 解析（任一 Action 都通过这个查 Grammar）：
public static MotionGrammarRule ResolveGrammar(ActionDataSO action)
{
    if (action == null) return default;
    if (action.OverrideGrammar) return action.GrammarOverride;
    return action.TransitionType switch
    {
        TransitionType.Start => MotionGrammarPrototypes.Start,
        TransitionType.End   => MotionGrammarPrototypes.End,
        TransitionType.Turn  => MotionGrammarPrototypes.Turn,
        TransitionType.Pivot => MotionGrammarPrototypes.Pivot,
        _ => default,
    };
}
```

**关键**：策划只需选 `TransitionType`，自动继承 4 个原型之一；特殊角色才用 `OverrideGrammar`。**不暴露 N×N 矩阵勾选**。

## §3 互斥语义（**不是优先级，而是不允许出现**）

### §3.1 当前 Transition 与新 Intent 的决议矩阵

```
                         新 Intent
                ─────────────────────────────────
                Move   Stop   Dodge   Attack   Skill   TapFacing
当前 Transition  ─────────────────────────────────
Start (Idle→Run) │ ✓✓    ✓     ✓✓     ✓✓      ✓✓     ⚠cache
End   (Run→Idle) │ ✓      —    ✓✓     ✓✓      ✓✓     ⚠cache
Turn  (Idle→Idle)│ ✓✓    ✓     ✓✓     ✓✓      ✓✓     ⚠replace
Pivot (Run→Run)  │ ✓      ✓     ✓✓     ✓✓      ✓✓     ⚠cache
None  (无 Trans) │ ✓      ✓     ✓      ✓        ✓      —
```

| 符号 | 含义 |
|---|---|
| ✓✓ | 立刻打断当前 Transition，执行新 Intent |
| ✓ | 等当前 Transition 结束后执行 |
| — | 不存在该组合 |
| ⚠cache | **缓存 PendingFacing，Transition 结束时应用，不插 Turn** |
| ⚠replace | 替换当前 Turn 为新 Turn |

### §3.2 关键决议规则（**Stop × Turn 互斥**）

```csharp
public enum TapFacingDecision : byte
{
    PlayTurnImmediately,    // 当前没 Transition 或 Turn → 立刻播 Turn
    CachePendingFacing,     // 当前是 End / Pivot → 缓存，结束后应用
    Ignore,                 // 当前是 Start（起步期间不改朝向）
}

public static TapFacingDecision DecideTapFacing(ActionDataSO currentTransition)
{
    var grammar = ResolveGrammar(currentTransition);

    // ★ 已消费方向变化 → 不允许再插 Turn
    if (grammar.ConsumesDirectionChange && currentTransition.TransitionType != TransitionType.Turn)
    {
        return currentTransition.TransitionType == TransitionType.Start
            ? TapFacingDecision.Ignore          // Start 期间不缓存（避免起步方向反复）
            : TapFacingDecision.CachePendingFacing;
    }

    // Turn 期间再来 Turn → 替换
    if (currentTransition.TransitionType == TransitionType.Turn)
        return TapFacingDecision.PlayTurnImmediately;   // 切换到新 Turn

    // 无 Transition → 立刻播
    return TapFacingDecision.PlayTurnImmediately;
}
```

## §4 PendingFacing 缓存机制（**Stop 吃掉 Turn 的实现**）

### §4.1 `Player` 字段

```csharp
public partial class Player
{
    // 184.4 — Transition 期间收到 Tap Facing 请求时缓存到这里
    Vector3 m_pendingFacing;
    bool    m_hasPendingFacing;

    public bool HasPendingFacing => m_hasPendingFacing;
    public Vector3 PendingFacing => m_pendingFacing;

    public void RequestPendingFacing(Vector3 newForward)
    {
        var planar = new Vector3(newForward.x, 0f, newForward.z);
        if (planar.sqrMagnitude < 0.0001f) return;
        m_pendingFacing = planar.normalized;
        m_hasPendingFacing = true;
        MotionGrammarProbe.LogFacingCached(this, m_logicForward, m_pendingFacing);
    }

    public bool TryConsumePendingFacing(out Vector3 newForward)
    {
        if (!m_hasPendingFacing) { newForward = default; return false; }
        newForward = m_pendingFacing;
        m_hasPendingFacing = false;
        return true;
    }
}
```

### §4.2 Tap Facing 入口的 Grammar 检查

```csharp
// PlayerController.HandleTapFacing（每帧）
void HandleTapFacing(Player player, Vector3 worldDir)
{
    if (worldDir.sqrMagnitude < 0.04f) return;

    // 查当前 ActionState 内的 Transition 类型
    var currentTransition = player.States.Current is PlayerActionState actSt
        ? actSt.CurrentAction
        : null;

    var decision = MotionGrammar.DecideTapFacing(currentTransition);

    switch (decision)
    {
        case TapFacingDecision.PlayTurnImmediately:
            player.SetLogicForward(worldDir);
            // Locomotion 状态机内的 Turn 子状态决议会触发对应 Turn 动画
            break;

        case TapFacingDecision.CachePendingFacing:
            // ★ Stop / Pivot 期间：缓存，等结束后应用
            player.RequestPendingFacing(worldDir);
            break;

        case TapFacingDecision.Ignore:
            // Start 期间忽略（起步方向已锁定）
            break;
    }
}
```

### §4.3 Transition 结束时应用 PendingFacing

```csharp
// PlayerActionState.ExitToBaseline 末尾追加
if (m_action != null
    && (m_action.TransitionType == TransitionType.End
        || m_action.TransitionType == TransitionType.Pivot)
    && player.TryConsumePendingFacing(out var pendingForward))
{
    // ★ 直接修正 LogicForward，不播 Turn 动画
    player.SetLogicForward(pendingForward);
    MotionGrammarProbe.LogFacingApplied(player, m_action, pendingForward);
}
```

### §4.4 完整流程（**Run → 松开 W → Tap D**）

```
T=0   Hold W → Intent.Move → Run Loop
T=1   松开 W → Intent.Stop（隐式）
T=1   PlayerLocomotionState 触发 RunEnd → PlayerActionState
T=1   m_action.TransitionType = End；Grammar.ConsumesDirectionChange = true

T=1.1 玩家 Tap D
T=1.1 HandleTapFacing → DecideTapFacing(currentTransition=RunEnd)
T=1.1 → CachePendingFacing
T=1.1 player.m_pendingFacing = 东向
T=1.1 [Grammar] FACING-CACHED owner=RunEnd from=北 to=东

T=1.4 RunEnd 自然结束 → ExitToBaseline
T=1.4 TryConsumePendingFacing → 应用东向
T=1.4 SetLogicForward(东向)
T=1.4 [Grammar] FACING-APPLIED owner=RunEnd to=东

T=1.4 进 Locomotion → Idle 状态 + 朝东
```

**关键**：整个过程**没有 Turn 动画**；玩家看到的是"急停 → 已朝东"，干净。

## §8 运行时层（**核心模块**）

### §8.1 `MotionGrammar` 静态类

```csharp
public static class MotionGrammar
{
    public static MotionGrammarRule Resolve(ActionDataSO action)
        => ActionDataSO.ResolveGrammar(action);

    public static TapFacingDecision DecideTapFacing(ActionDataSO currentTransition)
    {
        if (currentTransition == null || currentTransition.TransitionType == TransitionType.None)
            return TapFacingDecision.PlayTurnImmediately;

        var g = Resolve(currentTransition);
        if (g.ConsumesDirectionChange)
        {
            return currentTransition.TransitionType == TransitionType.Start
                ? TapFacingDecision.Ignore
                : currentTransition.TransitionType == TransitionType.Turn
                    ? TapFacingDecision.PlayTurnImmediately
                    : TapFacingDecision.CachePendingFacing;
        }
        return TapFacingDecision.PlayTurnImmediately;
    }

    /// <summary>新 Intent 是否允许打断当前 Transition。</summary>
    public static bool CanInterrupt(ActionDataSO currentTransition, ActionCategory incoming)
    {
        // 与 184.3 IsLocomotionRecovery 旁路并存：
        // - 主动 Intent (Movement/Defensive/Offense/Skill) → 由 184.3 旁路允许打断
        // - TapFacing → 由本类的 DecideTapFacing 决定（不走 CanInterrupt）
        return true;   // 占位：实际由 184.3 路径处理
    }
}
```

## §11 关键架构约束

1. **Transition 之间互斥** —— Stop 期间不插 Turn；同源 Transition 不能同时拥有表现权
2. **Grammar 由原型继承，不暴露矩阵勾选** —— 4 个原型（Start/End/Turn/Pivot）+ 局部 Override
3. **PendingFacing 缓存机制** —— Stop/Pivot 期间 Tap → 缓存；Transition 结束时直接修正 LogicForward
4. **不在 Stop/Pivot 期间播 Turn 动画** —— 即使 LogicForward 已变（视觉错位由 VisualFacingDriver 兜底）
5. **Intent 走 184.3 旁路，TapFacing 走 184.4 Grammar** —— 正交不冲突
6. **TransitionType ∈ {Start, End} 与 IsLocomotionRecovery 强同步** —— OnValidate 自动校验

## §12 反模式清单

| 反模式 | 防御 |
|---|---|
| **Turn 作为全局 Intent** | 重新分类为 Transition（动作语法过渡词）|
| **Transition 自由叠加** | Grammar 互斥矩阵；Stop 吃掉 Turn |
| **每 Action 单独配 Grammar** | 4 个原型继承 + 局部 Override |
| **N×N 自由勾选矩阵** | 高层 4 属性（OwnsPresentation 等）+ Documentation 推导 |
| **Tap Turn 立刻打断 RunEnd** | Stop 期间走 CachePendingFacing |
| **End 后再叠加 Turn 动画** | "意图重复 = 抽动"，结构性禁止 |

## §13 三句话沉淀

> 1. **Start / End / Turn / Pivot 不是 Intent，是 Transition** —— 它们是动作语法中的过渡词，服务于真正的玩家意图
> 2. **Transition 不是叠加系统，是替代系统** —— 一次意图变化只允许一个 Transition 拥有表现权
> 3. **Stop 已经消费了方向变化** —— Tap 期间应缓存 PendingFacing，结束时直接修正，不插 Turn 补偿
