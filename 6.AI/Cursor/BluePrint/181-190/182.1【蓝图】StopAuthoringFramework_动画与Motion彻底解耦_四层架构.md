# 182.1【蓝图】Stop Authoring Framework —— 动画与 Motion 彻底解耦 / 四层架构

> **基线**：166.3 / 166.4 DynamicBrake 错误版（Snap 偷偷耦合"不播动画"；AnimSpeedCurve 在动态策略下被错认为失效）
> **本质修正**：**Stop Strategy 只决定 Motion 怎么处理，绝不决定动画播不播** —— 动画是**表现层**，Motion 是**运动层**，两者完全解耦
> **架构升级**：从"急停修补"升级为**Stop Authoring Framework**，承载 Pivot / 冲刺 / 滑铲 / 冰面惯性 / 坡地制动 等所有未来停止类玩法

## §0 旧版的根本错误（166.3/4 必须废弃）

### §0.1 隐式耦合：Snap = "不播动画"

```
166.3/4 错误实施：
  Snap → velocity=0; duration=0; → 没有 RunEnd 动画了
                                  ↑ 偷偷把"动画播不播"与"策略"绑死
```

| 误识 | 实际诉求 |
|---|---|
| Snap 立即停止 = 不需要 RunEnd 动画 | **Snap 只是不要 Motion 位移**；RunEnd 动画该播照样播 |
| DynamicBrake 替换 RunEnd 动画时长 | **不应替换**；动画的 Duration 由动画自己定，Motion 自行同步 |
| 动态策略下 AnimSpeedCurve 失效 | **永远生效**；只是 Curve 的 1.0 含义在不同策略下指向不同基准 |

### §0.2 真正的设计锚点

> **Stop Strategy 只负责停止 Motion 的生成规则**：
> - 不参与决定 Action 是否存在
> - 不参与决定动画是否播放
> - 不参与决定动画播放区段
> - 不参与决定状态是否进入

### §0.5 追加理解（**InheritPhysics 运行时脆弱性 / "动画先完再位移"复发**）

#### §0.5.1 现象（再次复发）

| 现象 | 说明 |
|---|---|
| 动画播完了，角色还在滑 | runtimeDuration 算对了，但**位移轨**没按 runtimeDuration 归一化 → 实际滑行时间 ≠ 动画时长 |
| 动画速度看起来与 runtimeDuration 不匹配 | AnimController 没收口到 `baseAnimSpeed × Curve(t)` |
| 高低速差距不明显 | nt 分母还是 ActionData.Duration，而非 runtimeDuration |
| Action 切出时机不对（早 / 晚） | ActionState 退出闸门用 `elapsed / Action.Duration` 而非 `elapsed / runtimeDuration` |

#### §0.5.2 根因：**多源 Duration**（收口失败）

```
当前可能并存的 Duration 来源（任一被读错就出 BUG）：
   A. ActionDataSO.Duration                       ← 配置（"作者期望"）
   B. ActionData.ResolveLogicalDurationSeconds()  ← 历史封装
   C. MotionProfile 自带 Duration                  ← MP 内
   D. StopRuntimeContext.RuntimeDuration          ← ★ 唯一应被消费
   E. Anim Clip.length / Segment 长度              ← 表现层时长
```

如果 ActionState / MotionExecutor / AnimController 各自读不同源 → 三轨脱钩 → 视觉"动画先完再位移"。

#### §0.5.3 收口原则（**铁律 / 一处不许漏**）

> **InheritPhysics 模式下：所有"时长分母"在一次 Build 后，由 `StopRuntimeContext.RuntimeDuration` **单一权威**驱动。**
>
> - 任何 `Duration` 字段读取必须走 `m_stopCtx.RuntimeDuration`，不能再读 ActionData.Duration
> - 任何"归一化时间 nt"必须 `nt = elapsed / RuntimeDuration`
> - 任何"动画速度"必须 `actualAnimSpeed = (Ref / RuntimeDuration) × Curve(nt)`

#### §0.5.4 6 处必须收口的代码点（**修复清单**）

| # | 位置 | 错（旧路径） | 对（收口） |
|---|---|---|---|
| 1 | `PlayerActionState.OnEnter` | 不算 runtimeDuration / 仅记 `m_startTime` | 先调 `StopMotionRuntime.Build` → 缓存 `m_stopCtx`；后续全用它 |
| 2 | `PlayerActionState.OnLogicUpdate` 计 nt | `nt = elapsed / action.Duration` | `nt = elapsed / m_stopCtx.RuntimeDuration`（StopFeature 启用且 InheritPhysics 时） |
| 3 | `PlayerActionState` 退出闸门 | `if (nt >= 1f) ExitToBaseline()` | 同上 nt 来源；闸门条件不变 |
| 4 | `MotionExecutor.Begin(profile, motionDuration, ...)` | `motionDuration = action.Duration` | `motionDuration = m_stopCtx.RuntimeDuration` |
| 5 | `MotionExecutor.SampleLocalDelta` 内部归一化 | 用自己缓存的 duration | 同 #4 — 与 ActionState 同源 |
| 6 | `PlayerAnimController.SetActionSpeed` | `speed = action.AnimSpeed × Curve(nt)` | `speed = (ReferenceDuration / m_stopCtx.RuntimeDuration) × Curve(nt)` |

#### §0.5.5 单一闸门（**ActionState 内 cache，禁止重算**）

```csharp
public sealed class PlayerActionState : EntityState<Player>
{
    StopRuntimeContext m_stopCtx;
    bool m_stopActive;            // EnableStopFeature 且策略!=Disabled 时 true
    float m_startTime;

    protected override void OnEnter(Player p)
    {
        m_startTime = Time.time;
        var entrySpeed = p.PlanarVelocity.magnitude;
        m_stopCtx = StopMotionRuntime.Build(m_action, entrySpeed);     // ★ 一次 Build
        m_stopActive = m_action.EnableStopFeature && m_stopCtx.Mode != StopMode.Disabled;

        // 把同一 ctx 透传给所有下游
        m_motionExecutor.Begin(m_action.MotionProfile, m_stopCtx.RuntimeDuration, ctx: m_stopCtx);
        p.AnimController.PlayAction(m_action, m_stopCtx);              // 让 Anim 读 ctx
    }

    public float ResolveDurationSeconds()                              // ★ 唯一对外口径
        => m_stopActive ? m_stopCtx.RuntimeDuration : m_action.Duration;

    protected override void OnLogicUpdate(Player p)
    {
        var dur = ResolveDurationSeconds();
        var elapsed = Time.time - m_startTime;
        var nt = dur > 0.001f ? Mathf.Clamp01(elapsed / dur) : 1f;

        // Motion / Anim 子系统全部用 nt 与 ctx
        m_motionExecutor.Tick(nt);                                     // 内部不再算 nt
        p.AnimController.UpdateActionSpeed(nt);                        // 内部读已缓存 ctx

        if (nt >= 1f) ExitToBaseline(p);
    }
}
```

**关键不变量**：
- `ResolveDurationSeconds()` 是**唯一**对外暴露的 Action 时长口径
- MotionExecutor / AnimController **不再自己计算 nt**；由 ActionState 统一推送
- StopCtx 在 OnEnter 时一次性算出，运行期不重算（避免帧间漂移）

#### §0.5.6 `PlayerAnimController` 单一公式

```csharp
public void PlayAction(ActionDataSO action, in StopRuntimeContext stopCtx)
{
    m_currentAction = action;
    m_stopCtx = stopCtx;
    m_animator.CrossFade(action.MainClip.name, transitionDur);
}

public void UpdateActionSpeed(float normalizedT)
{
    if (m_currentAction == null) return;

    var baseSpeed = m_stopCtx.Mode == StopMode.InheritPhysics
        ? m_currentAction.ReferenceDuration / Mathf.Max(0.001f, m_stopCtx.RuntimeDuration)
        : m_currentAction.AnimSpeed;

    var curve = m_currentAction.AnimSpeedCurve;
    var multiplier = curve != null ? curve.Evaluate(normalizedT) : 1f;

    m_animator.speed = baseSpeed * multiplier;     // ★ 单一写入点
}
```

#### §0.5.7 `MotionExecutor` 取消自治时间

```csharp
public void Begin(MotionProfileSO mp, float motionDuration, in StopRuntimeContext stopCtx)
{
    m_profile = mp;
    m_duration = motionDuration;        // ★ 由 ActionState 注入，不自算
    m_stopCtx = stopCtx;
    m_prevNt = 0f;
}

public Vector3 Tick(float currentNt)
{
    // 不再 elapsed/duration；由外部 nt 喂入
    Vector3 delta;
    if (m_stopCtx.Mode == StopMode.Snap)
    {
        delta = Vector3.zero;
    }
    else if (m_stopCtx.Mode == StopMode.InheritPhysics)
    {
        // 节奏曲线归一化采样 → 乘 runtimeDistance
        var p0 = m_profile.AxisCurves.SampleLocalPosition(m_prevNt);
        var p1 = m_profile.AxisCurves.SampleLocalPosition(currentNt);
        var normalizedDelta = p1 - p0;
        delta = Vector3.Scale(normalizedDelta * m_stopCtx.RuntimeDistance, m_stopCtx.ApplyMask);
    }
    else // MotionProfile / Disabled
    {
        delta = m_profile.AxisCurves.SampleLocalDelta(m_prevNt, currentNt);
    }
    m_prevNt = currentNt;
    return delta;
}
```

#### §0.5.8 一对一探针 `[Stop]`（防再犯）

`Player.DebugStop` 总开关；仅在 **状态翻转** 时打 1 行（不允许每帧）。

```csharp
// OnEnter 时打 1 行：算 ctx
[Stop] action=RunEnd mode=InheritPhysics entrySpeed=5.20
       runtimeDuration=0.330  runtimeDistance=1.62  ref=0.250 → baseAnim=0.758

// 每帧（可选）只在 nt 越过 [0, 0.5, 1.0] 三档时打：
[Stop] tick action=RunEnd nt=0.50 elapsedSec=0.165  posDelta=0.81m  animSpd=0.758

// OnExit 时打 1 行：实际收尾对账
[Stop] EXIT action=RunEnd  actualElapsed=0.330  expectedDur=0.330
       actualDistance=1.61m  expectedDistance=1.62m  drift=±0.6%
```

> `drift > 5%` 自动 Warn —— 表示位移与时长脱钩，必有一个组件没用 ctx.RuntimeDuration。

#### §0.5.9 4 条防再犯单测（PlayMode）

| # | 场景 | 断言 |
|---|---|---|
| 1 | InheritPhysics + entrySpeed=5 / Ref=0.25 / runtimeDur=0.33 | `m_animator.speed ≈ 0.758`（首帧）|
| 2 | 同上播完 | `actualElapsed - runtimeDuration` 偏差 < 5% |
| 3 | 同上 → grep `animator.speed = action.AnimSpeed` 调用栈 | **不在 RunEnd 期间触发**（动画速度全由 controller 统一写） |
| 4 | Snap + RunEnd | `runtimeDuration == action.Duration`；动画完整播；位移=0 |

#### §0.5.10 系统性脆弱性结论

| 脆弱点 | 风险 | 防御 |
|---|---|---|
| **多源 Duration** | 任何组件读错就脱钩 | `ResolveDurationSeconds()` 唯一口径；StopCtx OnEnter 缓存 |
| **子系统自治时间** | MotionExecutor 自算 nt 与 ActionState 偏差 | nt 由 ActionState 单点推送 |
| **动画速率多写入点** | Animator.speed 被覆盖 | `PlayerAnimController.UpdateActionSpeed` 唯一写入 |
| **runtimeDuration 重算** | 帧间漂移 | OnEnter 算一次，运行期只读 |
| **InheritPhysics 与 MP 旧路径切换** | 触发条件遗漏 | 显式 `m_stopActive` 标志位；探针每次 Build 记录 |

> 一句话：**InheritPhysics 之所以脆，是因为它把"运行时算 Duration"引入；只要把 Duration 收口成 OnEnter 一次性算 + 全链路只读，脆弱性就消失了。**

## §1 四层架构（**核心契约**）

```
┌──────────────────────────────────────────────────┐
│ Layer 1: Action（播什么动画）                     │
│   ├ Clip / Segment / TailSegment / AnimSpeed     │
│   └ 完全的表现层，不受 Stop Strategy 影响         │
└────────────────────┬─────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────┐
│ Layer 2: Stop Feature（是否启用停止系统）         │
│   ├ bool EnableStopFeature                       │
│   └ 关闭 → 整个停止系统不介入，保持旧行为         │
└────────────────────┬─────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────┐
│ Layer 3: Stop Strategy（停止 Motion 来源）        │
│   Snap / InheritPhysics / MotionProfile          │
└────────────────────┬─────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────┐
│ Layer 4: MotionProfile（减速节奏，不再是米数）    │
│   curve.Evaluate(t) → normalizedOffset (0..1)    │
└────────────────────┬─────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────────┐
│ Layer 5: AnimSpeedCurve（动画速度变化节奏）       │
│   actualAnimSpeed = baseAnimSpeed × curve(t)     │
│   baseAnimSpeed 因策略而异（§3.4）                │
└──────────────────────────────────────────────────┘
```

### §1.1 互相不越界（**铁律**）

| 层 | 职责 | 禁止 |
|---|---|---|
| Layer 1 Action | 决定动画素材 | 不读 Stop Strategy |
| Layer 2 Stop Feature | 总开关 | 不决定动画播不播 |
| Layer 3 Stop Strategy | 决定 Motion 来源 | **不决定动画播不播 / 不替换 ActionDuration** |
| Layer 4 MotionProfile | 描述减速节奏 | 不直接给真实米数 |
| Layer 5 AnimSpeedCurve | 描述动画速度倍率 | 不被策略关闭 |

## §3 三种 Stop Strategy

```csharp
public enum StopStrategy : byte
{
    /// <summary>禁用 Motion 停止位移；动画照常播。</summary>
    Snap = 0,

    /// <summary>★ 核心：跑越久停越远 —— 速度→Distance→Duration 动态映射。</summary>
    InheritPhysics = 1,

    /// <summary>固定作者模式：使用 MotionProfile 完整数据（旧 ZXY 行为）。</summary>
    MotionProfile = 2,
}
```

### §3.1 Snap（**修正后**）

```csharp
// 错误旧版：
velocity = 0;
duration = 0;        // ← 偷偷不播动画

// 正解：
disableStopMotion = true;        // 只关 Motion 位移
stopOffset = Vector3.zero;       // 不读 MotionProfile 停止三轴
runtimeDuration = ActionData.Duration;     // ← 动画时长由 Action 决定
baseAnimSpeed = ActionData.AnimSpeed;       // ← AnimSpeed 由 Action 决定
```

**适用场景**：
- 鬼泣精准取消
- 部分竞技动作
- "原地收脚但不滑行"的 RunEnd

### §3.2 InheritPhysics（**核心 / 不滑步关键**）

> 跑越久，停越远；动画速度自动适配 Duration → 动画结束时位移结束 → **无滑步**。

```csharp
[Serializable]
public struct InheritPhysicsSettings
{
    public float MinSpeed, MaxSpeed;        // 输入速度区间
    public float MinDistance, MaxDistance;  // 输出位移区间
    public float MinDuration, MaxDuration;  // 输出时长区间
    public bool AffectX, AffectY, AffectZ;  // 哪些轴参与急停
}
```

**示例参数**：
| 速度 | Distance | Duration |
|---|---|---|
| 0.5 m/s | 0.2 m | 0.10 s |
| 4.5 m/s | 1.35 m | 0.28 s（线性插值） |
| 8.0 m/s | 2.50 m | 0.45 s |

**计算流程**：
```
当前速度 v
    ↓
runtimeDistance = Lerp(MinDist, MaxDist, normalize(v, MinSpeed, MaxSpeed))
runtimeDuration = Lerp(MinDur, MaxDur, normalize(v, MinSpeed, MaxSpeed))
    ↓
MotionProfile.AxisCurves(t/runtimeDuration) → normalizedOffset
realOffset = normalizedOffset × runtimeDistance × axis(X/Y/Z mask)
    ↓
baseAnimSpeed = ReferenceDuration / runtimeDuration   ★ 动画速度自匹配
actualAnimSpeed = baseAnimSpeed × AnimSpeedCurve.Evaluate(t)
```

### §3.3 MotionProfile（**固定作者模式**） `[追加理解 §0.3-1]`

> **≠ 禁用 MotionProfile**。本策略 = **166 之前 ZXY 程序化位移的默认路径**；Stop 只标记「位移来源 = 作者曲线米数」，**不**关闭 MP、**不**跳过 AnimSpeedCurve。

旧 ZXY 行为完全保留：作者直接定义 Distance / Duration / Curve；运行时不动态计算。

```csharp
// 运行时：MotionProfile 仍启用，与 Combat/Dodge 等 Action 一致
m_useMotionProfile = true;
m_motionExecutor.Begin(action.MotionProfile, motionDuration, ...);
m_motionExecutor.SetStopContext(ctx);   // ctx.UseAuthorFixed = true

realOffset = MotionProfile.AxisCurves.SampleLocalDelta(t0, t1) × authorScale;
runtimeDuration = ActionData.Duration;          // ← 不改为 brakeDuration
baseAnimSpeed = ActionData.AnimSpeed;
actualAnimSpeed = baseAnimSpeed × AnimSpeedCurve.Evaluate(t);   // ← 仍生效
```

**适用**：演出确定性强、需要镜头精确对齐的场景；RunEnd 若需「固定滑距」选本策略，若需「速度越大停越远」选 InheritPhysics。

**禁止**：`if (StopStrategy.MotionProfile) disableMotionProfile` —— grep 必须为 0。

### §3.4 三策略下 `baseAnimSpeed` 来源（**AnimSpeedCurve 修正核心**）

```csharp
actualAnimSpeed = baseAnimSpeed × AnimSpeedCurve.Evaluate(normalizedT);

// baseAnimSpeed 来源
switch (strategy)
{
    case Snap:
    case MotionProfile:
        baseAnimSpeed = action.AnimSpeed;   // 作者静态值
        break;

    case InheritPhysics:
        baseAnimSpeed = action.ReferenceDuration / runtimeDuration;   // 动态
        break;
}
```

| 场景 | ReferenceDuration | runtimeDuration | baseAnimSpeed | AnimCurve(t=0.5) | actualAnimSpeed |
|---|---|---|---|---|---|
| Snap | — | ActionData.Duration | ActionData.AnimSpeed (1.0) | 1.2 | 1.2 |
| InheritPhysics 低速 | 0.25 | 0.10 | 2.5 | 1.0 | 2.5 |
| InheritPhysics 中速 | 0.25 | 0.25 | 1.0 | 1.0 | 1.0 |
| InheritPhysics 高速 | 0.25 | 0.50 | 0.5 | 1.0 | 0.5 |
| MotionProfile | — | ActionData.Duration | ActionData.AnimSpeed | 1.2 | 1.2 |

**核心理解**：
- AnimSpeedCurve **永远生效**
- 它表达"相对当前基准的倍率变化"
- 1.0 在 Snap/MotionProfile 下 = `ActionData.AnimSpeed`
- 1.0 在 InheritPhysics 下 = **动态基准** `ReferenceDuration / runtimeDuration`

## §4 不滑步核心公式（**整个系统的根**）

```
runtimeDuration 动态变化（InheritPhysics 下）
        ↓
baseAnimSpeed = ReferenceDuration / runtimeDuration
        ↓
actualAnimSpeed = baseAnimSpeed × AnimSpeedCurve(t)
        ↓
动画在 runtimeDuration 内播完 = Motion 在 runtimeDuration 内位移完
        ↓
★ 动画结束时位移结束 → 无滑步
```

**最重要验收标准**：

## §9 运行时层定稿

```csharp
public sealed class StopMotionRuntime
{
    public StopRuntimeContext Build(ActionDataSO action, float entrySpeed)
    {
        if (!action.EnableStopFeature)
            return StopRuntimeContext.Disabled(action);   // 走旧路径

        return action.StopStrategy switch
        {
            StopStrategy.Snap            => BuildSnap(action),
            StopStrategy.InheritPhysics  => BuildInheritPhysics(action, entrySpeed),
            StopStrategy.MotionProfile   => BuildMotionProfile(action),
            _ => StopRuntimeContext.Disabled(action),
        };
    }

    static StopRuntimeContext BuildSnap(ActionDataSO action) => new()
    {
        DisableStopMotion = true,
        StopOffset = Vector3.zero,
        RuntimeDuration = action.Duration,
        BaseAnimSpeed = action.AnimSpeed,
    };

    static StopRuntimeContext BuildInheritPhysics(ActionDataSO action, float entrySpeed)
    {
        var s = action.InheritPhysics;
        var t = Mathf.InverseLerp(s.MinSpeed, s.MaxSpeed, entrySpeed);
        var dist = Mathf.Lerp(s.MinDistance, s.MaxDistance, t);
        var dur  = Mathf.Lerp(s.MinDuration, s.MaxDuration, t);
        return new StopRuntimeContext
        {
            DisableStopMotion = false,
            RuntimeDistance = dist,
            RuntimeDuration = dur,
            BaseAnimSpeed = action.ReferenceDuration / Mathf.Max(0.001f, dur),
            ApplyMask = new Vector3(s.AffectX ? 1 : 0, s.AffectY ? 1 : 0, s.AffectZ ? 1 : 0),
        };
    }

    static StopRuntimeContext BuildMotionProfile(ActionDataSO action) => new()
    {
        DisableStopMotion = false,
        UseAuthorFixed = true,
        RuntimeDuration = action.Duration,
        BaseAnimSpeed = action.AnimSpeed,
    };
}

// 每帧采样
public Vector3 SampleOffset(in StopRuntimeContext ctx, float normalizedT, MotionAxisCurves curves)
{
    if (ctx.DisableStopMotion) return Vector3.zero;

    if (ctx.UseAuthorFixed)
        return curves.SampleLocalDelta(prevT, normalizedT);   // MotionProfile 模式：旧逻辑

    // InheritPhysics：MotionProfile 提供 normalized 节奏
    var normalized = curves.SampleLocalPosition(normalizedT);   // 0..1
    return Vector3.Scale(normalized * ctx.RuntimeDistance, ctx.ApplyMask);
}

public float SampleAnimSpeed(in StopRuntimeContext ctx, float normalizedT, AnimationCurve curve)
    => ctx.BaseAnimSpeed * (curve != null ? curve.Evaluate(normalizedT) : 1f);
```

## §12 关键架构约束（**实施时不可越界**）

1. **动画路径绝不被策略修改** —— `PlayerActionState` 内不允许出现 `if (Snap) skipAnim()` 等代码
2. **Stop Strategy 只输出 stopOffset / baseAnimSpeed** —— 不输出 "是否进入 State" 等控制流
3. **AnimSpeedCurve 永远参与计算** —— 任意策略下都不允许跳过 `curve.Evaluate(t)`
4. **EnableStopFeature = false → 完全旁路** —— 老 Action 不开关，零影响
5. **运行时 Distance/Duration "--" 不可写** —— Inspector 显示但禁止编辑
6. **TailSegment 独立于 Strategy** —— 任何策略下都能用 Tail；它属于 Action 表现，不属 Motion

> 1. **动画是表现，Motion 是运动，策略只处理运动，不干涉表现** —— Stop Authoring Framework 的根本原则
