# 184.1【蓝图】Facing 与 Turn 彻底解耦 —— 艾尔登法环式即时朝向 / Tap-Hold 时态解析

> **资料**：[183.3【资料】turn和Facing进行表现与逻辑分离.md](6.AI/Cursor/BluePrint/181-190/183.3【资料】turn和Facing进行表现与逻辑分离.md)
> **核心定论**："法环的转向不是角色慢慢转过去，而是**角色已经转过去了，只是用一个可随时打断的 Turn 动画去骗你的眼睛**"
> **现状对比**：项目 `TurnResolver` 注释已写明"代码负责转，动画负责骗"，但 `Player.LookAtDirection` 仍用 `RotateTowards` 慢转 KCC —— **理念已对，未贯彻**
> **本蓝图目标**：把"逻辑即时、表现补偿"贯穿到 KCC / Animator / Input 三层，并叠加 Tap/Hold 时态解析

## §0 现状摸底（KB-First）

### §0.1 已有基础（70% 就位）

| `Player.LookAtDirection` | `Quaternion.RotateTowards` 慢转，每帧角速度有限 | ❌ 不是即时 |

### §0.2 当前 BUG 链（与资料 §0 对照）

```
玩家朝北，瞬间按 S
       ↓
LookAtDirection → RotateTowards 慢慢转 0.3s
       ↓ 这 0.3s 内：
攻击方向 = 北（旧 forward）        ← 玩家感受到"延迟"
闪避方向 = 北
锁定切换 = 北
       ↓
Transform 转完 → 真正面向南
       ↓
玩家若同步按 Space → 此时才正确触发后闪避
```

**关键体感问题**：**输入 → 响应之间多了 1 个 Transform 渐变**。这是非 3A 手感的根源。

## §1 三层架构（**核心契约**）

```
┌────────────────────────────────────────────────────┐
│ Layer 1: Input Tense（时态解析）                    │
│   ├ Tap / Hold / Press+Hold(combo) 三态             │
│   └ Hold 触发持续运动；Tap 触发转向；Combo 触发技能  │
└──────────────────┬─────────────────────────────────┘
                   ↓
┌────────────────────────────────────────────────────┐
│ Layer 2: Logic Facing（逻辑朝向）                   │
│   ├ Vector3 LogicForward —— 输入瞬间写入            │
│   ├ 攻击 / 闪避 / 锁定 / 移动 / AI / 同步 全部读它   │
│   └ ★ 永远无过渡（输入即朝向）                       │
└──────────────────┬─────────────────────────────────┘
                   ↓
┌────────────────────────────────────────────────────┐
│ Layer 3: Visual Facing（表现朝向）                  │
│   ├ Quaternion VisualRotation —— 缓追 LogicForward  │
│   ├ 由 Turn 动画或 SmoothDamp 驱动                   │
│   └ ★ 任何主动 Intent 可打断（动画是 Polish）         │
└────────────────────────────────────────────────────┘
```

### §1.1 三层职责切线（**铁律**）

| 层 | 职责 | 禁止 |
|---|---|---|
| Layer 1 Input Tense | 解析输入时态 → 派发 Intent | 不直接操作朝向 |
| Layer 2 Logic Facing | 即时朝向，作为所有 Gameplay 计算源 | **不被表现层反向控制** |
| Layer 3 Visual Facing | 仅驱动模型可见朝向 + Turn 动画 | **不被任何 Gameplay 计算读取** |

> **资料原话**："千万别让表现反过来控制逻辑。"

### §1.2 法环手感公式

```
按下输入 (t=0)
  ↓ 同帧：
  LogicForward = inputDir            ← 攻击/闪避/锁定/移动全部立刻新朝向
  IntentBuffer.Enqueue(MoveIntent / SkillIntent)
  
  ↓ 同帧 / 下一帧：
  TurnAnimationRequest.Publish(Turn90/180)  ← 表现层独立请求

t=0 ~ 0.3s（Turn 动画期间）：
  Animator 播 Turn180（视觉补偿）
  期间任何 Intent → 立刻打断 Turn → 走新动作
```

## §2 输入金字塔（**优先级**）

```
        ┌────────────────────────────┐
        │  Combo Intent (Space/LM/...)  │   ★ 抢占
        │  WASD + Space = 八向闪避     │   重新解释 WASD 为相对方向
        └─────────────┬────────────────┘
                      ↓ （未占用时下放）
        ┌────────────────────────────┐
        │  Hold Locomotion Intent     │   ★ 持续运动
        │  Hold WASD = 走 / 跑        │   LogicForward = inputDir
        └─────────────┬────────────────┘   持续追随
                      ↓ （仅 Tap 时）
        ┌────────────────────────────┐
        │  Tap Turn Intent            │   ★ 朝向调整
        │  Tap WASD = Turn 转身       │   LogicForward = inputDir
        └────────────────────────────┘   不进入 Locomotion
```

### §2.1 三类输入对照表

| 输入 | 时态 | LogicForward | Locomotion | Skill | Turn 动画 |
|---|---|---|---|---|---|
| **Hold D** | Hold | =东（即时） | ✓ 进入 Walk/Run | ✗ | 视角度选播或不播 |
| **Tap D** | Tap | =东（即时） | ✗ 不进入 | ✗ | 强制播 Turn90/180 |
| **Tap D + Space** | Combo | **不变**（北） | ✗ | ✓ Right Dodge | ✗ |
| **Hold D + Space** | Combo | =东（即时） | ✗ | ✓ Forward Dodge | ✗ |

> **关键**：`Tap D + Space` 时 LogicForward 保持北 —— "侧翻后仍面对敌人"。这是 Skill Combo 抢占了方向解释权（资料 §1300+）。

### §2.2 Tap / Hold 判定

```csharp
const float TapMaxDuration = 0.15f;       // < 150ms 算 Tap
const float HoldEnterDelay = 0.08f;       // > 80ms 算 Hold 开始

InputTense ClassifyDirectional(float pressTime, bool stillPressed)
{
    if (stillPressed)
    {
        if (pressTime >= HoldEnterDelay) return InputTense.Hold;
        return InputTense.Pending;          // 80ms 等待窗口
    }
    if (pressTime < TapMaxDuration) return InputTense.Tap;
    return InputTense.ShortHold;            // 介于 Tap 与 Hold 之间（按设计取一边）
}
```

- 80ms 窗口期内若发生 Space 按下 → `Combo Intent` 优先抢占（不进入 Turn / Locomotion）
- 仅在 Combo 未触发且超过 TapMaxDuration 才决议为 Hold

## §3 数据层

### §3.1 `Player` 字段重构

```csharp
public partial class Player
{
    // 184.1 — 逻辑朝向（即时）vs 表现朝向（缓追）
    public Vector3 LogicForward { get; private set; } = Vector3.forward;
    public Quaternion VisualRotation => m_visualRoot != null ? m_visualRoot.rotation : transform.rotation;

    [SerializeField] Transform m_visualRoot;        // ★ 模型子物体；Transform.rotation 由 VisualFacingDriver 驱动
    VisualFacingDriver m_visualFacing;              // 缓追组件

    // 兼容 API：Forward 永远返回 LogicForward
    public Vector3 Forward => LogicForward;

    // 184.1 — 即时朝向设置（无过渡）
    public void SetLogicForward(Vector3 dir)
    {
        var planar = new Vector3(dir.x, 0f, dir.z);
        if (planar.sqrMagnitude < 0.0001f) return;
        LogicForward = planar.normalized;
        // ★ Transform.forward 也同步即时（兼容现有 KCC 朝向消费）
        transform.rotation = Quaternion.LookRotation(LogicForward, Vector3.up);
        // VisualRoot 保持原朝向 → 视觉滞后 → Turn 动画补偿
    }
}
```

### §3.2 `VisualFacingDriver`（新组件）

```csharp
public sealed class VisualFacingDriver : MonoBehaviour
{
    [SerializeField] float MaxAngularSpeedDeg = 720f;   // 大于 Turn 阈值时由 Turn 动画接管
    [SerializeField] Player m_player;

    void LateUpdate()
    {
        if (m_player == null) return;
        var target = Quaternion.LookRotation(m_player.LogicForward, Vector3.up);
        // 若 Animator 正在播 Turn 动画 → 不缓追（让动画驱动）
        if (m_player.AnimController.IsPlayingTurn) return;
        transform.rotation = Quaternion.RotateTowards(
            transform.rotation, target, MaxAngularSpeedDeg * Time.deltaTime);
    }
}
```

> Visual 仅在**没有 Turn 动画播放时**缓追 LogicForward；有 Turn 动画时**动画驱动骨骼旋转**，结束时 Visual 自动对齐到 Logic。

### §3.3 `InputTenseResolver`（新模块）

```csharp
public enum InputTense : byte { Idle, Pending, Tap, Hold, ShortHold }

public sealed class InputTenseResolver
{
    public float TapMaxDuration = 0.15f;
    public float HoldEnterDelay = 0.08f;

    float m_pressedSinceTime;
    bool  m_wasPressed;

    /// <summary>每帧调用；返回输入时态。</summary>
    public InputTense Tick(bool isPressed, float now)
    {
        if (isPressed && !m_wasPressed)
        {
            m_pressedSinceTime = now;
            m_wasPressed = true;
            return InputTense.Pending;
        }
        if (isPressed)
        {
            var pressed = now - m_pressedSinceTime;
            return pressed >= HoldEnterDelay ? InputTense.Hold : InputTense.Pending;
        }
        if (!isPressed && m_wasPressed)
        {
            var pressed = now - m_pressedSinceTime;
            m_wasPressed = false;
            if (pressed < TapMaxDuration) return InputTense.Tap;
            return InputTense.ShortHold;
        }
        return InputTense.Idle;
    }
}
```

## §4 运行时层

### §4.1 输入→朝向流水线（**关键**）

```csharp
// PlayerController 每帧：
void Tick()
{
    var wasdRaw = _inputReader.MoveRaw;
    var tense = _wasdTense.Tick(wasdRaw.sqrMagnitude > 0.04f, Time.time);

    // ① Combo 抢占（最高优先级）
    if (Input.Skill.WasPressed && wasdRaw.sqrMagnitude > 0.04f)
    {
        // WASD + Skill → 八向 Skill；LogicForward 不变
        var relDir = ResolveRelativeFromCurrentFacing(wasdRaw);
        EnqueueSkillIntent(relDir);
        return;
    }

    // ② Hold → Locomotion Intent
    if (tense == InputTense.Hold)
    {
        var newForward = CameraToWorld(wasdRaw);
        _player.SetLogicForward(newForward);             // ★ 即时
        var angle = Vector3.SignedAngle(_oldForward, newForward, Vector3.up);
        if (Mathf.Abs(angle) >= 45f)                      // 角度大才请求 Turn 动画
        {
            _player.AnimController.RequestTurn(BuildTurnIntent(angle));
        }
        EnqueueMoveIntent(wasdRaw);
        _oldForward = newForward;
        return;
    }

    // ③ Tap → 仅 Turn Intent（不进 Locomotion）
    if (tense == InputTense.Tap)
    {
        var newForward = CameraToWorld(_lastTapDir);
        _player.SetLogicForward(newForward);             // ★ 即时
        var angle = Vector3.SignedAngle(_oldForward, newForward, Vector3.up);
        _player.AnimController.RequestTurn(BuildTurnIntent(angle));
        _oldForward = newForward;
        return;
    }
}
```

### §4.2 Turn 动画为表现状态（**可打断**）

```csharp
public sealed class PlayerAnimController
{
    public bool IsPlayingTurn { get; private set; }

    public void RequestTurn(in TurnIntent intent)
    {
        if (intent.Kind == TurnKind.None) return;
        var clip = ResolveTurnClip(intent.Kind, intent.SignedAngleDeg);
        if (clip == null) return;
        IsPlayingTurn = true;
        m_animator.CrossFade(clip.name, 0.1f);
    }

    /// <summary>任何主动 Intent（Move/Attack/Dodge/Jump）触发时调用 → 立刻打断 Turn。</summary>
    public void InterruptTurnIfAny()
    {
        if (!IsPlayingTurn) return;
        IsPlayingTurn = false;
        // 切换到对应主动动作的 CrossFade 由调用方负责
    }
}
```

### §4.3 八向 Skill 方向解释

```csharp
// WASD + Space → 不改 LogicForward；以当前 LogicForward 为参考解析方向：
Vector3 ResolveRelativeFromCurrentFacing(Vector2 wasdRaw)
{
    // 摄像机相对 → 世界向量
    var worldInput = CameraToWorld(wasdRaw);
    // 以 LogicForward 为 +Z 基准的局部坐标
    var rot = Quaternion.LookRotation(_player.LogicForward, Vector3.up);
    var localDir = Quaternion.Inverse(rot) * worldInput;
    return localDir;   // (0,0,+1)=前 / (0,0,-1)=后 / (+1,0,0)=右 / ...
}

// SkillEntry 选 Action：
// localDir.z > 0.4 → Dodge_F；< -0.4 → Dodge_B
// localDir.x > 0.4 → Dodge_R；< -0.4 → Dodge_L
// 斜对角 → Dodge_FR / FL / BR / BL
```

> 关键不变量：**WASD + Space 时 LogicForward 不变 → 闪避方向永远是"相对当前朝向"** → "侧翻后仍面对敌人"。

#### §5.2.A.5 旧 vs 新 时序对比（**关键差异**）

**旧（v3.3.3）**：
```
按 S
  ↓ 当帧
LookAtDirection(南)  → RotateTowards 慢转 0.3s
  ↓ TurnResolver "观察"到角度差
触发 LocomotionStateId.TurnInPlaceDirected
  ↓ Locomotion 状态机进入 Turn 子状态
锁定 → 阻塞玩家其它输入直到 |angleDiff| < 解锁阈值
  ↓ Transform.forward 真正面南 = t≈0.3s
攻击 / 闪避 / 锁定方向 此时才更新
```

**新（184.1）**：
```
按 S
  ↓ 当帧 t=0
SetLogicForward(南)  → Transform.forward 同帧 = 南    ← 即时
所有 Gameplay 计算立刻用新朝向                       ← 攻击/闪避/锁定瞬间生效
  ↓ 同帧
TurnIntentBuilder → Kind=Turn180, Direction=Right180
  ↓
TurnInPlaceDirected 子状态进入 → 播 Turn_R180 动画
  ↓ Visual 缓追（动画驱动骨骼旋转）
任意主动 Intent → InterruptTurnIfAny → 立刻打断 Turn
  ↓ Visual 自然对齐 Logic（0~0.3s 内）
```

#### §5.2.A.6 Locomotion 状态机内的 Turn 角色变化

| 维度 | 旧（阻塞型）| 新（表现型）|
|---|---|---|
| **状态类型** | Locomotion 子状态（阻塞）| Locomotion 子状态（**可打断 Polish**）|
| **占用 LogicForward** | ✅ 自己慢转 | ❌ 不参与（OnEnter 时 LogicForward 已是目标）|
| **占用输入** | ✅ 屏蔽其它输入 | ❌ 任何主动 Intent 立刻打断 |
| **接受技能/移动打断** | ⛔ 阻塞 | ✅ 完全开放 |
| **Animator 播放** | 慢转期间的 Turn 动画 | 同上（资源不变）|
| **结束条件** | `|angleDiff| < 解锁阈值` | Visual 追上 Logic 或 nt >= 1 或被打断 |

public class TurnPresentationProfileSO : ScriptableObject

### §6.5.2 PlayerLocomotionState 内部子状态切换表（**修订版**）

```csharp
// PlayerLocomotionState.OnLogicUpdate 内部子状态决议
LocomotionStateId DecideSubState(Player p, InputTense tense, float deltaAngle)
{
    // ★ 不再用 LogicForward 慢转角度差决定（旧 TurnResolver 路径）
    //   而是用 InputTense 主动驱动

    if (!p.HasMovementIntent)
        return LocomotionStateId.Idle;

    // Tap：仅 Turn，不进 Walk/Run
    if (tense == InputTense.Tap)
    {
        if (Mathf.Abs(deltaAngle) >= tuning.Turn180ThresholdDeg)
            return LocomotionStateId.TurnInPlaceDirected;    // → Left180/Right180
        if (Mathf.Abs(deltaAngle) >= tuning.Turn90ThresholdDeg)
            return LocomotionStateId.TurnInPlaceDirected;    // → Left90/Right90
        return LocomotionStateId.Idle;                        // 小角度 Tap 仅微调 Logic，不播 Turn
    }

    // Hold：进入 Walk/Run；若起步时角度大，并行播 Turn 动画
    if (tense == InputTense.Hold)
    {
        // ★ Locomotion 继续推进（不阻塞），Turn 仅作为表现并存
        if (Mathf.Abs(deltaAngle) >= tuning.Turn90ThresholdDeg)
        {
            p.AnimController.RequestTurnInParallelWithLocomotion(BuildTurnIntent(deltaAngle));
        }
        return p.WantsRun ? LocomotionStateId.Run : LocomotionStateId.Walk;
    }

    return LocomotionStateId.Idle;
}
```

## §9 关键架构约束（**实施时不可越界**）

1. **`LogicForward` 永远即时** —— grep `RotateTowards.*forward` 调用栈必须为 0（除 VisualFacingDriver）
2. **Visual 不被 Gameplay 读取** —— grep `VisualRotation` 调用栈只在 Animator 端
3. **Combo Intent 抢占 LogicForward 改写** —— Tap+Space 时 LogicForward **不动**
4. **Turn 是表现状态** —— 任何主动 Intent 必调 `InterruptTurnIfAny`
5. **Tap / Hold 由 InputTenseResolver 唯一裁决** —— 不允许第二处算时态
6. **80ms Pending 窗口** —— 这是法环手感的关键；过短易误判 Tap，过长输入延迟

## §10 反模式清单（**本次根治**）

| 反模式 | 表现 | 防御 |
|---|---|---|
| **逻辑慢转** | RotateTowards Transform.forward | LogicForward 即时 + Visual 单独缓追 |
| **Forward 单源** | 攻击 / 动画 / 同步全读一个 Transform.forward | 拆 Logic / Visual 双轨 |

## §11 三句话沉淀

> 1. **法环的转向不是转过去，是已经转过去了** —— LogicForward 即时；Turn 动画只补偿视觉
> 2. **同一按键在不同时态下表达完全不同的意图** —— Tap=朝向 / Hold=移动 / Tap+Space=技能方向
> 3. **逻辑即时，表现补偿** —— Gameplay 永远读 LogicForward；Visual 走自己的节拍
