# 185.2【蓝图】Graph Edge Condition 升级 —— 条件边重构 / 四类 Context 仲裁器 / 下劈 MVP

> **资料**：`F:\Code\Note\...\185.1【资料】graph edge condition.md`
> **基线**：CombatGraph (149.3) / AirInterruptPolicy (168.3) / TransitionType + Motion Grammar (184.4)
> **核心目标**：
> 1. **MVP**：Start → DownwardSlash 条件边（Input=Attack + Phase=Airborne∩Apex）→ LM 在空中自动变下劈
> 2. **预留**：Event Window 上层代码框架（防御反击 / 完美闪避 / 处决 / 识破）—— 上层 API 完整，运行期事件源接通延后
>
> **资料甄别（重要）**：
> 1. 资料把 "NormalizedTimeWindow（含 Late Window）" 描述为"连招窗口的统一抽象"。**与项目现状不符**：
>    - 项目 **Early Window = Action 上的归一化时间** —— 定义"哪段时间允许被打断 / 提前衔接"，**写在 Action 上**
>    - 项目 **Late Window = Action 上的绝对时间（RealTime）** —— 定义"Action 自然结束后仍可衔接的尾段"，**也写在 Action 上**
>    - **二者都属于 Action，不属于 Edge**。Graph 编辑器中的"Window"栏目只是**只读显示** Action 的 Early Window，**不可在 Edge 上重复定义**
> 2. 因此本蓝图**不引入** `TimeNormalizedConditionSO`，**不扩展** `CombatFlowEdge.WindowStart/End`；时间窗职责留在 Action 端不动
> 3. Edge 只增加"语义条件"维度（Input / Phase / EventWindow / CombatContext **四类**）
> 4. **JumpInterruptGate 与本蓝图正交不动**

## §0 现状摸底（**避免重复造轮**）

### §0.1 项目已有的"Context 雏形"

| 模块 | 现有功能 | 复用为 |
|---|---|---|
| `ActionDataSO.EarlyWindow` | 归一化时间 [0..1]，定义"可被打断/衔接"区段 | **不动**（时间窗 = Action 职责）|
| `ActionDataSO.LateWindow` | 绝对时间（RealTime），Action 结束后衔接尾段 | **不动**（时间窗 = Action 职责）|
| `CombatFlowEdge` | `Transition` + 编辑器只读显示 Action 的 Early Window | **本蓝图扩展点**：新增 `Conditions[]` 语义维度 |
| `GameplayIntent` | Kind / SkillEntrySlot / SemanticTag | **Input Condition** 输入源 |
| `AirInterruptPolicy` (168.3) | `AscendingAllowed / ApexAllowed / DescendingAllowed` | **Phase Condition** 数据源 |
| `GameplayTagContainer` 5 轨（State/Status/Ability/Mechanic/Faction）| Tag 容器 | **CombatContext** 数据源 |
| `Player.VerticalSpeed` + `IsGrounded` | 物理量 | Phase 派生 |
| `ActionCategory` (Movement/Offense/Defensive/Utility/Locomotion/IdleFallback) | 粗分类 | 一级闸门（不动） |
| **JumpInterruptGate / AirInterruptResolver** | 168.3 已有 | **不动**（一级粗过滤） |
| 既有 `CombatFlowAuthoring` | Edge 配置 SO | **本蓝图扩展点** |

### §0.2 当前 Graph 能力的局限（**MVP 触发点**）

```
现状（合理且保留）：
  Action 端：EarlyWindow / LateWindow ── 时间维度（NT + RealTime）
  Edge 端：仅 Transition 与目标节点 ── 拓扑维度
  Edge 编辑器：只读显示 Action 的 EarlyWindow 作为时序参考

现状缺失：
  Edge 端没有"语义维度" —— 无法表达：
    "AirLoop 中 LM 按下 + Apex 阶段 → DownwardSlash"
    （AirLoop 是持续态无 Timeline；Apex 不是 Action 而是 Tag）
```

### §0.3 资料核心思想（**萃取，4 句话；不照搬术语**）

> 1. **Graph Edge 增加语义条件维度** —— Edge 端做 Conditions[]；时间窗仍归 Action（**与资料"时间窗只是 Condition 的一种"分歧 —— 项目时间窗在 Action 端单独权威**）
> 2. **Context 分层** —— Movement Phase / Event Window / Combat Context / Input 四类
> 3. **JumpInterruptGate 不动** —— 它是一级粗粒度许可（ActionCategory）；Graph 是二级细判
> 4. **Apex 不是 Action，是 Tag/Phase** —— 不要做 ApexAction 资产

## §1 设计原则

### §1.1 三层职责切线（**铁律**）

```
┌─────────────────────────────────────────────────────┐
│ Layer 1: JumpInterruptGate / AirInterruptResolver    │
│   168.3 已有，不动                                    │
│   一级粗过滤：基于 ActionCategory（5 类）             │
│   O(动作标签数)，永远稳定                              │
└──────────────────┬──────────────────────────────────┘
                   ↓ 通过
┌─────────────────────────────────────────────────────┐
│ Layer 2: Graph Edge Conditions[]                     │
│   本蓝图重构核心                                      │
│   二级细判：Input + Phase + EventWindow + Combat     │
│   策划在 Inspector 勾选条件组合                       │
└──────────────────┬──────────────────────────────────┘
                   ↓ 全部通过
                Transition
```

> **JumpInterruptGate 不应承担 Graph Edge 职责**；反之亦然 —— 一级管"哪类动作允许"，二级管"具体什么条件成立"。

### §1.2 四类 Edge Condition（**Conditions[] 的元素 —— 时间窗仍归 Action**）

```csharp
public abstract class EdgeConditionSO : ScriptableObject
{
    public abstract bool Evaluate(in EdgeContext ctx);
    public virtual string DebugLabel => name;
}
```

| 类 | SO 类型 | 用途 | 例 |
|---|---|---|---|
| **Input** | `InputConditionSO` | 输入意图匹配 | "Pressed(Attack) && SkillSlot=LM" |
| **Phase** | `PhaseConditionSO` | 运动相位（地空 / Apex） | "Airborne ∩ Apex" |
| **EventWindow** | `EventWindowConditionSO` | 最近发生事件且在有效期 | "GuardCounterWindow active" |
| **CombatContext** | `CombatContextConditionSO`（预留） | 战斗态势 | "TargetBehind && EnemyUnaware" |

**不在 Conditions[] 里的**：
- ❌ `TimeNormalizedCondition` —— Action 的 `EarlyWindow` 已是单一权威，Edge 上重复定义会污染数据所有权
- ❌ `RealTimeCondition` —— Action 的 `LateWindow` 已覆盖该需求

```csharp
[Serializable]
public class CombatFlowEdge
{
    // 既有字段（保留，不变）
    public CombatFlowTransitionMode Transition;
    public string SourceNodeId;
    public string TargetNodeId;
    // 注意：Edge 本来就不写时间窗。编辑器中 Window 栏目仅只读显示 Action.EarlyWindow

    // 185.2 唯一新字段
    [SerializeField] EdgeConditionSO[] m_conditions = Array.Empty<EdgeConditionSO>();
    public EdgeConditionSO[] Conditions => m_conditions;

    public bool EvaluateConditions(in EdgeContext ctx)
    {
        if (m_conditions == null || m_conditions.Length == 0) return true;  // 空数组 = 永真
        for (var i = 0; i < m_conditions.Length; i++)
        {
            if (m_conditions[i] == null) continue;
            if (!m_conditions[i].Evaluate(in ctx)) return false;   // AND 短路
        }
        return true;
    }
}
```

## §3 Phase Condition（**MVP 必做**）

### §3.1 `PhaseContext`（运动相位快照）

```csharp
public readonly struct PhaseContext
{
    public readonly bool IsGrounded;       // 含 Land 过渡帧
    public readonly bool IsAirborne;       // = !IsGrounded
    public readonly bool IsAscending;      // vy > apexThreshold
    public readonly bool IsApex;           // |vy| <= apexThreshold
    public readonly bool IsDescending;     // vy < -apexThreshold
    public readonly float VerticalSpeed;

    public static PhaseContext FromPlayer(Player p, float apexThreshold = 1.5f)
    {
        var vy = p.VerticalSpeed;
        var grounded = p.IsGrounded;
        return new PhaseContext(
            grounded,
            !grounded,
            !grounded && vy > apexThreshold,
            !grounded && Mathf.Abs(vy) <= apexThreshold,
            !grounded && vy < -apexThreshold,
            vy);
    }
}
```

> apexThreshold 复用 168.3 `AirInterruptPolicy.ApexVyThreshold`（**单一权威**）。

### §3.2 `PhaseConditionSO`

```csharp
[Flags]
public enum PhaseMask : byte
{
    None       = 0,
    Grounded   = 1 << 0,   // 含 Land 起始过渡（Land 的移动打断由其打断窗口完成，不独立成相位）
    Airborne   = 1 << 1,
    Ascending  = 1 << 2,
    Apex       = 1 << 3,
    Descending = 1 << 4,
}

[CreateAssetMenu(menuName="GameMain/Skill/EdgeCondition/Phase")]
public class PhaseConditionSO : EdgeConditionSO
{
    [Tooltip("勾选的相位中任一成立即通过（OR）；多 SO 串联实现 AND。")]
    public PhaseMask AllowedPhases;

    [Tooltip("勾选的相位中任一成立即失败（NOR）；用于"禁止在某相位".")]
    public PhaseMask BlockedPhases;

    public override bool Evaluate(in EdgeContext ctx)
    {
        var p = ctx.Phase;
        var hits = (p.IsGrounded ? PhaseMask.Grounded : 0)
                 | (p.IsAirborne ? PhaseMask.Airborne : 0)
                 | (p.IsAscending ? PhaseMask.Ascending : 0)
                 | (p.IsApex ? PhaseMask.Apex : 0)
                 | (p.IsDescending ? PhaseMask.Descending : 0);

        if ((BlockedPhases & hits) != 0) return false;
        if (AllowedPhases == 0) return true;
        return (AllowedPhases & hits) != 0;
    }
}
```

## §4 Event Window（**预留上层框架，可编不可跑通**）

### §4.1 `ContextWindowTracker`

```csharp
public sealed class ContextWindowTracker
{
    readonly Dictionary<EventWindowTag, float> _expires = new();

    /// <summary>开启窗口；后续 IsActive(tag) 在 expireTime 之前返回 true。</summary>
    public void Open(EventWindowTag tag, float durationSec, float now)
    {
        _expires[tag] = now + durationSec;
    }

    public bool IsActive(EventWindowTag tag, float now)
        => _expires.TryGetValue(tag, out var expire) && now <= expire;

    public void Clear(EventWindowTag tag) => _expires.Remove(tag);
    public void ClearAll() => _expires.Clear();
}
```

## §6 Input Condition（**MVP 必做**）

```csharp
[CreateAssetMenu(menuName="GameMain/Skill/EdgeCondition/Input")]
public class InputConditionSO : EdgeConditionSO
{
    [Tooltip("匹配的意图类型（None=任意）")]
    public GameplayIntentKind IntentKind = GameplayIntentKind.Skill;

    [Tooltip("匹配的槽位（None=任意）")]
    public SkillEntrySlot Slot = SkillEntrySlot.None;

    [Tooltip("语义掩码（None=不检查）")]
    public InputSemanticTagMask RequireSemantics;

    public override bool Evaluate(in EdgeContext ctx)
    {
        var i = ctx.Intent;
        if (IntentKind != GameplayIntentKind.None && i.Kind != IntentKind) return false;
        if (Slot != SkillEntrySlot.None && i.Slot != Slot) return false;
        if (RequireSemantics.Value != 0 && !i.Semantics.HasAll(RequireSemantics)) return false;
        return true;
    }
}
```

## §7 仲裁器（`EdgeConditionEvaluator`）

```csharp
public static class EdgeConditionEvaluator
{
    /// <summary>评估单条 Edge 的 Conditions[]。短路 AND。空数组 = 永真。</summary>
    public static bool Evaluate(CombatFlowEdge edge, in EdgeContext ctx, out string firstFailLabel)
    {
        firstFailLabel = null;
        if (edge == null) return false;

        // 调用方职责（不在本类内）：
        //   1. JumpInterruptGate / AirInterruptResolver（一级粗过滤，168.3）
        //   2. Action 的 EarlyWindow / LateWindow 命中（时间维度，已有）
        //   3. 本类只跑 Conditions[] —— 语义维度

        var conds = edge.Conditions;
        if (conds == null || conds.Length == 0) return true;

        for (var i = 0; i < conds.Length; i++)
        {
            var c = conds[i];
            if (c == null) continue;
            if (!c.Evaluate(in ctx))
            {
                firstFailLabel = c.DebugLabel;
                return false;
            }
        }
        return true;
    }
}
```

### §7.1 接入点：`CombatGraphRunner`

在现有 `CombatGraphRunner.TryAdvanceOn*` 系列方法的"Edge 时间窗命中后"的判定处，**追加** `EdgeConditionEvaluator.Evaluate(edge, ctx, out _)` 作为第二道门：

```
Runner.TryAdvance:
    foreach edge in current.Outgoing:
        if (!Action.EarlyWindow.Contains(nt)            // 既有：Action 时间窗
            && !Action.LateWindow.IsWithin(now))
            continue;
        if (!JumpInterruptGate.Allow(intent.Category))  // 既有：一级闸门
            continue;
        if (!EdgeConditionEvaluator.Evaluate(edge, ctx, out var fail))  // 新增：Conditions[]
        {
            EdgeConditionProbe.LogReject(edge, fail);
            continue;
        }
        Transition(edge);
        return;
```

**零回归**：未配置 Conditions[] 的 Edge 评估返回 true，流程与既有完全一致。

## §8 **MVP：Start → DownwardSlash 完整用例**

### §8.1 资产清单

| 资产 | 类型 | 配置 |
|---|---|---|
| `EdgeCondition_Input_LightAttack.asset` | `InputConditionSO` | IntentKind=Skill / Slot=LM |
| `EdgeCondition_Phase_Airborne.asset` | `PhaseConditionSO` | AllowedPhases = `Airborne`（覆盖 Ascending/Apex/Descending 整段空中）|
| `Action_DownwardSlash.asset` | `ActionDataSO` | TransitionType=None（战斗动作）/ Anim=空中下劈 |
| `Skill_DownwardSlash.asset`（或现有 Combat Graph 节点）| Route | TargetAction = DownwardSlash |

### §8.2 Graph 配置（**单条 Edge 即可**）

```
[Start (Any)] ────▶ [DownwardSlash]
            Conditions:
              ☑ EdgeCondition_Input_LightAttack       (Skill + LM)
              ☑ EdgeCondition_Phase_Airborne          (Airborne 整段)
            
            Transition: OnInput
            
            （Edge 不写时间窗；DownwardSlash 自身的 EarlyWindow 决定
             落地后多久还能由此 Edge 触发）
```

### §8.3 运行时表现

```
玩家 Hold W 起跳 → Player.VerticalSpeed = +8 → Phase.Ascending = true
玩家按 LM
  ↓ Input Intent (Skill, slot=LM) 入 IntentBuffer
  ↓ JumpInterruptGate（168.3）：Ascending 是否允许 Offense？
    若 Loadout=DescendingOnly → Ascending 拒（一级闸门）
    若 Loadout=Universal → 通过
  ↓ Graph Edge 评估：
    Input ✓（Skill+LM）
    Phase = Ascending → AllowedPhases 含 Ascending → ✓
  ↓ Transition → DownwardSlash 触发 ✓

玩家继续不松手，Vy 衰减到 0 → Phase.Apex
玩家按 LM → 同上 → 触发 DownwardSlash ✓

玩家下落 Vy = -5 → Phase.Descending
玩家按 LM → 同上 → 触发 DownwardSlash ✓

玩家落地 IsGrounded=true → Phase.Grounded
玩家按 LM → Phase 不命中 → 该 Edge 不通过 → 走其它 Edge（地面普攻）✓
```

## §12 关键架构约束（**实施时铁律**）

1. **时间维度归 Action，语义维度归 Edge** —— Action.EarlyWindow / LateWindow 是时间窗的**唯一权威**；Edge 不持有时间窗
2. **JumpInterruptGate 一级 / Graph Edge 二级** —— 两层职责绝不重叠；不在 Edge 内重复做 ActionCategory 过滤
3. **Conditions[] 是 AND** —— 短路求值；OR 通过同类 SO 内多 Flag 实现
4. **空 Conditions[] = 永真** —— 不引入"Legacy 转译"，零增量等价于零回归
5. **`ApexVyThreshold` 单一权威** —— 168.3 AirInterruptPolicy 提供；PhaseContext 复用
6. **Grounded 包含 Land 过渡** —— Land 起始的"可被移动打断"由 Action 打断窗口完成，不独立成相位
7. **EventWindow 事件源 ≠ Condition** —— Tracker 是数据；Condition 是查询；Opener 是事件源，可独立切片
8. **CombatContext 占位允许 Evaluate=true** —— 数据源未接通时不误拒（避免阻塞 Graph 配置）

## §13 反模式清单（**避免走偏**）

| 反模式 | 防御 |
|---|---|
| **Apex 做成 Action SO** | Apex 仅是 PhaseMask 一位 |
| **Context 做成大杂烩黑板（几十 bool）** | 分四类 SO，Inspector 折叠 |
| **Graph 重复做 Ability Gate** | 一级闸门保留，Graph 只跑细判 |
| **NT 时间窗写到 Edge 上** | 时间窗只能写在 Action 端（EarlyWindow / LateWindow）；Edge 仅做语义条件 |
| **EventWindow 与 NT 时间窗混用一类 SO** | 二者数据所有权完全不同（事件 vs Action 内）|
| **EventWindow 必须等事件源接通才能用** | 上层 API 先行；运行期 IsActive=false 不影响其它 Edge |

---

## §14 三句话沉淀

> 1. **时间维度归 Action（Early/Late Window），语义维度归 Edge（Conditions[]）** —— 两者正交，不互相蚕食
> 2. **JumpInterruptGate 一级粗过滤，Graph Conditions[] 二级细判** —— 各管一段，不重叠
> 3. **Apex 不是 Action，是 Tag** —— 状态上的相位，不是独立资产
