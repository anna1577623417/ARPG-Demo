## §0.4 追加理解（2026-06-08 · 法环三档输入：WASD 进 Turn / 跑或 Space 略过 Turn 动画）

### §0.4.1 策划语义（用户原话对齐）

> **WASD 可以理解成「转向」** —— 站立、大角差时，会**进入转向状态**并**播放转向动画**（Turn-In-Place）。  
> **若「方向 + 跑」或「方向 + Space」**，则**略过**（不进入）这套转向动画，直接走跑/翻滚各自的 Locomotion 或 Action 表现。

这与法环一致：

| 玩家输入语义 | 法环体感 | 本系统应对 |
|---|---|---|
| **仅方向（走/站）** | 大角差 → 原地 pivot 动画 | **进入 Turn 表现态** + Layer A 对齐输入 |
| **方向 + Run（A+跑）** | 不播 pivot，边跑边 instant 转向 | **不进入 / 立即退出 Turn 表现**；Run Loop + Snap |
| **方向 + Space（翻滚等）** | 不播 pivot，直接翻滚 Action | **离开 Locomotion 柱** → Action 动画，Turn 管线自然不参与 |

**关键**：「略过 Turn 动画」≠「不转向」—— **逻辑朝向（Layer A）仍随输入**；略过的是 **Layer B 的 Turn-In-Place 切片**。

### §0.4.2 三档分流（权威决策表）

```
                    MovementIntent 有方向？
                           │
           ┌───────────────┼───────────────┐
           ▼               ▼               ▼
    当前在 Action 柱    WantsRun 或        仅 Walk/Idle
    （Space→Dodge…）   PlanarSpeed≥阈值     + 大角差
           │               │               │
           ▼               ▼               ▼
    不评估 TurnResolver  SKIP Turn 表现    ENTER Turn 表现
    播 Action Clip       Run/Walk Clip     Turn90/180 Clip
    Layer A 按 Action 策  Layer A Snap     Layer A Snap
```

| 档位 | 判定（优先级从高到低） | Turn 表现（Layer B） | 逻辑朝向（Layer A） |
|---|---|---|---|
| **D — Action** | `PlayerActionState` 活跃；或本帧 Intent 路由到 Dodge/Roll/… | **不参与**（Anim 走 Action Presentation） | `CanRotateDuringLocomotion` / Action 内策略 |
| **C — Run 略过** | Locomotion 且 **`WantsRun == true`** **或** `PlanarSpeed ≥ LockSpeedThreshold` | **禁止 LOCK** / 强制 UNLOCK TurnResolver | **Snap**（183.1 W2） |
| **B — Walk 转向** | Locomotion、非 Run 档、`|angle| ≥ Turn90Threshold`、速度低于阈值 | **LOCK** → 播 Turn ContinuousClip | **Snap**（与 Turn 并行，不等待 Clip） |
| **A — 小角** | `|angle| < Turn90Threshold` | 无 Turn；Idle/Walk | Snap 或 Smooth |

### §0.4.3 与现有代码对照（WIRE / OPEN）

| 行为 | 现状 | 状态 |
|---|---|---|
| 站立大角 WASD → Turn 动画 | `TurnResolver` LOCK + `PlayerAnimController` Turn 子状态 | **WIRE**（162.1） |
| 跑起来后改方向 → 不播 Turn | `currentSpeed ≥ LockSpeedThreshold` → `ClearLock` | **WIRE**（TurnResolver L178） |
| **按住 Run + 方向（A+跑）首帧仍 LOCK** | 仅看 **PlanarSpeed**，不看 **WantsRun**；加速前 1～N 帧可能仍播 Turn | **OPEN** → §0.4.4 |
| **Space + 方向 → 翻滚** | Intent → `PlayerActionState`；Locomotion `OnExit` → `TurnResolver.ClearLock` | **WIRE**（柱切换） |
| 逻辑 instant 面向 | `LookAtDirection` 未 `immediate` | **OPEN**（183.1 W1/W2） |

### §0.4.4 待施工：Run 意图略过 Turn（DOC → W2b）

**目标**：`WantsRun == true` 时 **与 speed 门槛 OR**，TurnResolver **不得进入 LOCK**（即使 PlanarSpeed 仍为 0）。

```csharp
// TurnResolver.Tick — 追加理解 §0.4（伪代码）
var runSkipsTurn = player.WantsRun;   // 或 tuning.SkipTurnWhenWantsRun
if (runSkipsTurn)
{
    ClearLock();
    return BuildNonTurningAngleSnapshot(player);
}
// 原有 speedOk && angleOk → LOCK …
```

| 字段（建议挂 Tuning 或 TurnSettings） | 默认 | 说明 |
|---|---|---|
| `SkipTurnPresentationWhenWantsRun` | **true** | 法环档：A+Run 不播 Turn |
| `SkipTurnPresentationWhenSprinting` | 同左 | 别名；与 `WantsRun` 同源 |

**禁止**：Run 略过 Turn 时改 Detect 去 Fire Turn 离散 Action（164.1 路径 A 已否决）。

### §0.4.5 Space + 方向：为何自然略过（WIRE 说明）

Space（翻滚 / Dodge Route）典型路径：

1. `InputSemanticResolver` → GameplayIntent（非 Move）
2. `IntentRouter` → **`PlayerActionState`**（或 Graph Route）
3. Locomotion **`OnExit`** → `m_turnResolver.ClearLock()` + `SetTurnInfo(default)`

因此 **无需**在 TurnResolver 内 Special-case Space；**Action 柱吞掉输入**即略过 Turn 动画。  
173.1 `ShouldSuppressLocomotionRotation` 在 Directional 提交窗内另有一套「不抢朝向」——与 Space 略过 Turn **正交**。

## §1 设计锚点（不可违背）

### §1.1 两层契约（162.1 延续）

```
┌─────────────────────────────────────────────────────────┐
│ Layer A — 逻辑朝向（Gameplay / KCC / 位移方向）          │
│   权威：transform.forward 对齐 MovementIntent           │
│   入口：Player.MoveByLocomotionIntent → LookAtDirection │
│   与动画无关；必须每帧可独立 snap                       │
└────────────────────┬────────────────────────────────────┘
                     │ 只读夹角 / 速度
                     ▼
┌─────────────────────────────────────────────────────────┐
│ Layer B — Turn-In-Place 表现（Presentation）             │
│   权威：TurnResolver → TurnInfo → PlayerAnimController  │
│   只决定播 Idle/Walk/Run 还是 Turn90/Turn180 Clip        │
│   不写位移、不阻塞 Layer A                              │
└─────────────────────────────────────────────────────────┘
```

**信条（代码注释已有）**：「**代码负责转，动画负责骗**」。

### §1.2 [追加理解 §0.4] 艾尔登法环语义映射

| 法环行为 | 本系统落点 |
|---|---|
| **站立 + 方向（大角）** | Layer B：**进入 Turn 状态** + Turn90/180 Clip；Layer A：**Snap** 对齐输入 |
| **方向 + Run（A+跑）** | **略过 Turn 动画**；Layer A Snap + Run Loop（W2b：`WantsRun` 禁止 LOCK） |
| **方向 + Space（翻滚）** | **略过 Turn**；切 **Action 柱** 播 Dodge/Roll（Locomotion Exit 清 Turn） |
| 跑中改方向 | 同 Run 档：不播 Turn，仅 Snap + Run |
| Turn 动画不拖慢「能走」 | 逻辑已 Snap；不等 Clip 转完才改 forward |
| 技能方向窗内不抢朝向 | `ShouldSuppressLocomotionRotation()`（173.1） |
### §1.3 与 Stop / Action 的边界

| 系统 | 关系 |
|---|---|
| **182.1 Stop Authoring** | RunEnd 期间 `CanRotateDuringLocomotion` / Action 期旋转策略 **独立**；本蓝图 **不改** Stop 时钟 |
| **Action 期** | `ActionDataSO.CanRotateDuringLocomotion` 门控 Action 内是否 `LookAtDirection`；Locomotion 蓝图 **只覆盖 Locomotion 柱** |
| **LockOn Strafe** | 8 向 Strafe 仍走 `LocomotionResolver`；Turn-In-Place 在 LockedOn 时 **默认不触发**（Detect 走 Strafe） |

## §2 现状架构（As-Is）

### §2.1 帧序（Locomotion 柱）

```
PlayerLocomotionState.OnLogicUpdate
  ① ShouldSuppressLocomotionRotation? → 清 Turn 锁
  ② TurnResolver.Tick → player.SetTurnInfo
  ③ ProcessLocomotionResolve → 可能 FIRE WalkStart/End…
  ④ MoveByLocomotionIntent → LookAtDirection(input)   ← 始终 smooth
  ⑤ ApplyMotor
```

### §2.2 逻辑旋转（Layer A）

| 项 | 值 / 行为 |
|---|---|
| 入口 | `Player.MoveByLocomotionIntent` |
| 实现 | `Entity.LookAtDirection(worldDir, immediate=false)` |
| 角速度来源 | **`RuntimeStats.RotationSpeed`**（`StatType.RotationSpeed`，默认 **540°/s**） |
| `immediate` | API 已有，**Locomotion 未使用** |
| 180° 转满耗时 | 540°/s → **≈0.33s** |

### §2.3 Turn-In-Place（Layer B）

| 项 | 配置 | 默认 |
|---|---|---|
| 功能总开关 | `PlayerStateManager` → `TurnSettings.EnableTurnInPlacePresentation` | ON |
| 触发速度上限 | `TurnSettings.LockSpeedThreshold` | **0.2 m/s** |
| 90° 触发角 | `LocomotionTuningSO.Turn90ThresholdDeg` | **70°** |
| 180° 触发角 | `LocomotionTuningSO.Turn180ThresholdDeg` | **135°** |
| 解锁角 | `TurnSettings.UnlockAngleThreshold` | **10°** |
| 最短锁定 | `TurnSettings.MinLockDuration` | **0.12s** |
| Turn Clip | `LocomotionProfile` State=`TurnInPlaceDirected` + `ContinuousClip` | 4 向绑定 |

**触发条件（同时）**：`PlanarSpeed < LockSpeedThreshold` 且 `|angle| ≥ Turn90ThresholdDeg`。

**跑动中**：速度 ≥ 0.2 m/s → **强制解锁 Turn**；仅 Layer A（183.1 Snap）+ Run 表现。

**[追加理解 §0.4] Run 意图略过（待 W2b）**：`WantsRun == true` 时 **同样不得 LOCK** —— 解决「A+跑首帧仍播 Turn」与法环不符。

**Space / Action**：不在此节判定；Action 柱激活时 TurnResolver 不 Tick 或 OnExit 已 ClearLock → **自然略过 Turn 动画**。

### §2.4 表现路由

```
TurnInfo.IsTurning ?
  PlayerAnimController.ResolveLocomotionSub → TurnLeft90/Right90/180
  LocomotionAnimProfileBridge.TryGetTurnContinuousClip
: Walk / Run / Idle
```

Turn 切片 **跳过** 步幅匹配（`IsTurnSub`），避免 speed≈0 时 Playable 倍率异常。

### §2.5 已知缺口（本蓝图要收）

| # | 缺口 | 后果 |
|---|---|---|
| **G1** | `LocomotionTuningSO.RotationSpeedDegPerSec` **未接入** `LookAtDirection` | 改 Tuning 无效，只能改 Stats |
| **G2** | Locomotion **从不** `immediate: true` | 无法做法环式即时面向 |
| **G3** | 配置双源：Stats 角速度 + Tuning 角速度字段重复 | 策划不知改哪 |
| **G4** | Press 大角差 deferred WalkStart（`Turn90Threshold`）与 Turn 锁定 **耦合同一阈值** | Snap 后可能少播 Turn、直接起步 |
| **G5** [§0.4] | **`WantsRun` 未参与 Turn SKIP** | A+跑首帧仍可能 LOCK Turn，与法环「跑转略过 pivot」不符 |

## §3 目标配置模型（To-Be）

### §3.1 单一权威：`LocomotionRotationPolicy`（新增，挂 Tuning）

```csharp
/// <summary>Locomotion 柱逻辑朝向策略（183.1）。Turn 表现仍由 TurnResolver 独立配置。</summary>
public enum LocomotionRotationMode : byte
{
    /// <summary>RotateTowards，角速度见 RotationSpeedDegPerSec。</summary>
    Smooth = 0,

    /// <summary>每帧 Quaternion 对齐 MovementIntent（法环默认）。</summary>
    SnapAlways = 1,

    /// <summary>PlanarSpeed ≥ SnapSpeedThreshold 时 Snap；否则 Smooth（可选站立慢转）。</summary>
    SnapWhileMoving = 2,
}
```

**建议字段（`LocomotionTuningSO` Rotation 段扩展）**：

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `RotationMode` | enum | **SnapAlways**（法环档） | Layer A 策略 |
| `RotationSpeedDegPerSec` | float | 720 | **Smooth 模式**角速度；Snap 模式忽略 |
| `SnapSpeedThreshold` | float | 0.2 | 与 `TurnSettings.LockSpeedThreshold` **对齐**（见 §3.3） |
| `UseTuningRotationSpeed` | bool | true | true → Locomotion **只读 Tuning**；false → 回落 Stats（兼容旧档） |
| `SkipTurnPresentationWhenWantsRun` | bool | **true** | [§0.4] A+跑略过 Turn 动画；TurnResolver 不得 LOCK |

### §3.2 阈值对齐表（策划一处看懂）

| 语义 | 权威字段 | 推荐默认 | 对齐关系 |
|---|---|---|---|
| 「算站立」速度上限 | `TurnSettings.LockSpeedThreshold` | 0.2 m/s | = `SnapSpeedThreshold` |
| 播 Turn90 | `Tuning.Turn90ThresholdDeg` | 55°～70° | 法环可 **55°** 更易触发 pivot |
| 播 Turn180 | `Tuning.Turn180ThresholdDeg` | 135° | 不变 |
| Press 起步最大角差 | 复用 `Turn90ThresholdDeg` | 同左 | **DOC**：Snap 后夹角变小，起步更频繁 — 预期行为 |
| 逻辑角速度（Smooth） | `Tuning.RotationSpeedDegPerSec` | 720～1080 | Stats 仅 Buff/装备乘区 |

### §3.3 双阈值同步约定

**硬规则**：`SnapSpeedThreshold` 与 `LockSpeedThreshold` **必须相等**（Editor OnValidate 警告或 Tuning 只读镜像 TurnSettings）。

理由：「跑动 instant + 不播 Turn」与「站立 Turn 表现」共用同一速度分界。

## §4 运行时接线（施工规约）

### §4.1 Layer A — `Player.LookAtDirection` 扩展

```csharp
// Player.cs — MoveByLocomotionIntent 内
if (!ShouldSuppressLocomotionRotation())
{
    ApplyLocomotionRotation(input, tuning, turnSettings);
}

void ApplyLocomotionRotation(Vector3 input, LocomotionTuningSO tuning, TurnSettings turnSettings)
{
    var mode = tuning != null ? tuning.RotationMode : LocomotionRotationMode.Smooth;
    var snapThreshold = turnSettings.LockSpeedThreshold;

    var immediate = mode switch
    {
        LocomotionRotationMode.SnapAlways => true,
        LocomotionRotationMode.SnapWhileMoving =>
            PlanarVelocity.magnitude >= snapThreshold,
        _ => false,
    };

    if (!immediate && tuning != null && tuning.UseTuningRotationSpeed)
        LookAtDirectionWithSpeed(input, tuning.RotationSpeedDegPerSec);
    else
        LookAtDirection(input, immediate);
}
```

**新增** `LookAtDirectionWithSpeed(dir, degPerSec)` 或在 `Player` override 中临时覆盖角速度 —— **禁止**改 Stats 基值。

### §4.2 [追加理解 §0.4] Layer B — TurnResolver 分流

| 档位 | TurnResolver | 状态 |
|---|---|---|
| Walk/Idle 大角 | `speedOk && angleOk` → LOCK + Turn Clip | WIRE |
| Run / speed≥阈值 | UNLOCK，不播 Turn | WIRE（speed） |
| **WantsRun** | **不得 LOCK**（与 speed OR） | OPEN W2b |
| Action（Space 等） | Locomotion Exit → ClearLock | WIRE |

| RotationMode | Layer A | 说明 |
|---|---|---|
| SnapAlways | 每帧 instant | 站立 Turn 动画仍播，逻辑不等待 Clip |
| SnapWhileMoving | 跑 instant、站可 Smooth | 与 Run 略过 Turn 叠加 |

可选 **W2+**：Turn LOCK 期间 **仍每帧** `LookAtDirection(intent, immediate:true)` —— 避免 Clip 与 forward 极端不同步（默认 W2 已足够）。

## §12 面试口述总结

> Locomotion 转向拆两层：**逻辑朝向**（Snap）与 **Turn-In-Place 动画**（仅 Walk/Idle 大角）。法环三档：**仅方向** → 进 Turn 态播 pivot；**方向+Run** 或 **方向+Space** → **略过 Turn 动画**（Run 用 WantsRun/speed，Space 用 Action 柱切换）。配置收口 **`RotationMode` + `SkipTurnPresentationWhenWantsRun`** + Tuning 角速度。
