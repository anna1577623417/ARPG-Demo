# 168.3【蓝图修订】空中状态可中断闸门下沉到 SkillLoadout —— 两维度切线 / 不与 Ability 重叠

> **基线**：168.1 误诊 / 168.2 探针 / **168.3 第一版（混淆维度，已废）**
> **关键修正**：空中**状态可中断**与技能**能否释放**是**两个独立维度**，不能合并到 SkillEntryDefinition 上重复造轮。本版只动**角色侧 Loadout 配置**，**不动 Ability 白名单**。
> **职责切线**（不可越界）：
> - **空中状态可中断 mask** ←  **`SkillEntryLoadoutSO`**（角色画像 / 装载配置维度）
> - **某技能能否释放** ←  **`AbilityGateService`**（已有 — 完全不动）

---

## §0 第一版的错误（必须先看清）

| 维度 | 168.3 第一版（错） | 168.3 修订版（对） |
|---|---|---|
| **空中状态可中断 mask** | 放在 `SkillEntryDefinition.AirborneActivation`（技能侧） | 放在 `SkillEntryLoadoutSO`（**角色侧**） |
| **某技能能否释放** | 也由 `SkillEntryDefinition.AirborneActivation` 间接决定（与上重叠） | 仍由 `AbilityGateService` 现有白名单负责（**完全不动**） |
| **多角色场景** | 改一个技能要复查所有角色 Loadout | 换 Loadout = 换整套空中可中断画像，技能资产不动 |
| **"升龙能空中触发"** | 写在升龙资产上 ← 重复造轮 | 不需要写；Loadout 允许 Ascending+Offense 即可，AbilityGate 决定具体派生 |

**为什么第一版错位**：升龙是"哪个技能"是 **Ability 系统**已经管的事；本蓝图要解决的根本问题只有一个 ——

> **角色在空中（Ascending/Descending/Apex）状态下，是否允许新 Intent 中断当前 Airborne 控制权？**

这是**角色身上的状态属性**，不是某个技能的属性。同一个升龙技能挂在轻甲角色身上 = 空中可接；挂在重甲角色身上 = 空中不可接。决定权在 **Loadout / 装备 / 体型**，不在升龙 SO 本身。

---

## §1 两维度切线（**核心契约**）

### §1.1 双层独立闸门

```
玩家按 LM（空中）
    ↓
PlayerAirborneState.TryConsumeGameplayIntent
    ↓
[L1] Loadout.AirInterruptPolicy 查询           ← 168.3 本蓝图职责
    "本角色 Ascending 阶段允许 Offense 中断？"
    No  → BLOCK（连 Ability 都不查）
    Yes ↓
    
IntentRouter.Route → SkillEntryService
    ↓
[L2] AbilityGateService 查询                  ← 已有系统，不动
    "升龙派生 此刻能不能放？冷却？资源？前置 Combo？"
    No  → BLOCK（Ability 层 reject）
    Yes ↓
    
路由命中 → 切下一段 ✓
```

### §1.2 三句锁死

> 1. **L1 管"角色空中能否被中断"** —— Loadout 维度 / 角色画像 / 粗粒度
> 2. **L2 管"具体技能能否释放"** —— Ability 维度 / 技能维度 / 细粒度（已有，不动）
> 3. **不允许任何系统跨界** —— Loadout 不查技能；Ability 不查 Phase；L1 不通则 L2 不查

### §1.3 为什么这两层不能合并

| 情景 | L1 Loadout | L2 Ability | 结果 |
|---|---|---|---|
| 轻甲忍者，空中 LM 接升龙派生 | Asc 允许 Offense ✓ | 升龙派生 CD ok ✓ | 释放 |
| 同上但升龙派生 CD 未好 | Asc 允许 Offense ✓ | CD reject ✗ | L2 拒；与"空中能不能动"无关 |
| 重甲坦克，空中 LM 接升龙派生 | Asc 拒 Offense ✗ | （不查） | L1 拒；体型决定 |
| 任意角色，空中按翻滚 | Asc 允许 Movement ✓ | 翻滚 CD ok ✓ | 释放 |
| 死亡状态空中 | （硬下限拦截） | — | 系统级 BLOCK |

合并到技能上 = 同一升龙技能无法表达"轻甲可接 / 重甲不可接"差异 → 必须复制两份 SO → 维护噩梦。

### §2.1 `AirInterruptPolicy`（**Loadout 内嵌结构**）

```csharp
// 4_Data/1.Skills/Routes/AirInterruptPolicy.cs（新增）
[Flags]
public enum AirbornePhaseMask : byte
{
    None        = 0,
    Ascending   = 1 << 0,   // VerticalSpeed > 0
    ApexHold    = 1 << 1,   // |Vy| < 阈值（默认 1.5）
    Descending  = 1 << 2,   // VerticalSpeed < 0
    All         = Ascending | ApexHold | Descending,
}

[Serializable]
public struct AirInterruptPolicy
{
    [Tooltip("Ascending（上升）允许哪些 ActionCategory 中断进入新意图")]
    public ActionCategory AscendingAllowed;

    [Tooltip("ApexHold（顶点）允许哪些 ActionCategory")]
    public ActionCategory ApexAllowed;

    [Tooltip("Descending（下落）允许哪些 ActionCategory")]
    public ActionCategory DescendingAllowed;

    [Tooltip("Apex 判定阈值：|VerticalSpeed| < 此值视为顶点段")]
    [Range(0.1f, 3f)] public float ApexVyThreshold;

    [Tooltip("Coyote 宽限：刚离地此秒数内仍按地面判定（与 Jump 系统的 CoyoteTime 独立）")]
    [Range(0f, 0.3f)] public float GroundCoyoteSeconds;

    /// <summary>默认全开 — 经典 ACT 角色（鬼泣 / 战神）。</summary>
    public static AirInterruptPolicy Universal => new() {
        AscendingAllowed  = ActionCategoryPresets.AllPillar,
        ApexAllowed       = ActionCategoryPresets.AllPillar,
        DescendingAllowed = ActionCategoryPresets.AllPillar,
        ApexVyThreshold = 1.5f, GroundCoyoteSeconds = 0.08f,
    };

    /// <summary>下落可中断、上升不可 — 强调"起跳冲量神圣"（黑魂 / 只狼）。</summary>
    public static AirInterruptPolicy DescendingOnly => new() {
        AscendingAllowed  = ActionCategory.None,
        ApexAllowed       = ActionCategory.Movement | ActionCategory.Offense,
        DescendingAllowed = ActionCategoryPresets.AllPillar,
        ApexVyThreshold = 1.5f, GroundCoyoteSeconds = 0.08f,
    };

    /// <summary>纯地面角色 — 弓手 / 法师 / 重甲。</summary>
    public static AirInterruptPolicy GroundOnly => new() {
        AscendingAllowed  = ActionCategory.None,
        ApexAllowed       = ActionCategory.None,
        DescendingAllowed = ActionCategory.Movement,    // 只允许空中机动（翻滚）打断下落
        ApexVyThreshold = 1.5f, GroundCoyoteSeconds = 0.05f,
    };
}
```

## §3 运行时层

### §3.1 `AirInterruptResolver`（新静态类 / 仅 L1）

```csharp
// 2_Framework/Locomotion/Airborne/AirInterruptResolver.cs（新增）
public static class AirInterruptResolver
{
    public enum Verdict : byte { Allow, HardFloorBlock, LoadoutBlock, LoadoutMissing }

    public struct Result
    {
        public Verdict Code;
        public AirbornePhaseMask Phase;
        public ActionCategory AllowedMaskForPhase;     // L1 当前 Phase 的 mask（探针用）
    }

    public static Result Evaluate(
        Player player,
        ActionCategory incomingCategory,
        ActionCategory hardFloorBlockMask)
    {
        var phase = ResolvePhase(player);   // Ascending / ApexHold / Descending

        // ① 系统级硬下限
        if (incomingCategory != ActionCategory.None
            && (hardFloorBlockMask & incomingCategory) != 0)
            return new Result { Code = Verdict.HardFloorBlock, Phase = phase };

        // ② Loadout 空中可中断 mask
        var loadout = player.SkillEntryLoadout;
        if (loadout == null)
            return new Result { Code = Verdict.LoadoutMissing, Phase = phase };

        var policy = loadout.AirInterruptPolicy;
        var allowed = phase switch {
            AirbornePhaseMask.Ascending  => policy.AscendingAllowed,
            AirbornePhaseMask.ApexHold   => policy.ApexAllowed,
            AirbornePhaseMask.Descending => policy.DescendingAllowed,
            _ => ActionCategory.None,
        };

        if (incomingCategory != ActionCategory.None && (allowed & incomingCategory) == 0)
            return new Result { Code = Verdict.LoadoutBlock, Phase = phase, AllowedMaskForPhase = allowed };

        return new Result { Code = Verdict.Allow, Phase = phase, AllowedMaskForPhase = allowed };
    }

    static AirbornePhaseMask ResolvePhase(Player player)
    {
        var policy = player.SkillEntryLoadout?.AirInterruptPolicy ?? AirInterruptPolicy.Universal;
        var vy = player.VerticalSpeed;
        if (Mathf.Abs(vy) < policy.ApexVyThreshold) return AirbornePhaseMask.ApexHold;
        return vy > 0f ? AirbornePhaseMask.Ascending : AirbornePhaseMask.Descending;
    }
}
```

### §3.2 `PlayerAirborneState.TryConsumeGameplayIntent` 改造（只动 L1 路径）

```csharp
public override bool TryConsumeGameplayIntent(Player player, in FrameContext ctx, in GameplayIntent intent)
{
    if (intent.Kind == GameplayIntentKind.Move) return true;
    if (!IntentRouter.IsRoutable(in intent)) return false;

    var incomingAction = IntentRouter.PeekActionDataForRouting(player, in intent);
    var incomingCategory = ActionInterruptResolver.ResolveIncomingCategory(in intent, incomingAction);

    // L1 — Loadout 空中可中断
    var r = AirInterruptResolver.Evaluate(player, incomingCategory, m_hardFloorBlock);
    LogAirInterruptIfFlipped(player, in r, intent.Kind, incomingCategory);
    if (r.Code != AirInterruptResolver.Verdict.Allow) return false;

    // L2 — Ability 白名单（已有，不动）由 IntentRouter.Route → SkillEntryService → AbilityGateService 链路负责
    return IntentRouter.Route(player, in intent, forceActionReentry: false);
}
```

## §8 关键架构约束

1. **两维度独立** —— L1（Loadout 空中画像）/ L2（Ability 白名单）；不允许任何系统跨界
2. **Loadout 是唯一权威** —— 角色"空中能否被中断"的唯一来源
3. **PlayerStateManager 只留硬下限** —— 默认 None；正常情况完全不该填
4. **AbilityGateService 完全不动** —— L2 已有，本蓝图零侵入
5. **SkillEntryDefinition 完全不动** —— 第一版的 AirborneActivation 字段废弃，不引入
6. **Phase 判定走 Loadout 的阈值** —— ApexVyThreshold 是角色画像一部分（重甲 vy 较快可缩短 Apex）
7. **探针 `[AirIntr]` 一开关一前缀翻转打** —— phase|kind|cat|verdict 四元组 dedup

## §10 反模式清单（**第一版 + 本次教训**）

## §11 三句话沉淀

> 1. **"空中状态能不能被中断"是角色画像（Loadout）；"技能能不能释放"是技能能力（Ability）**—— 两维度不允许合并
> 2. **L1 不通则 L2 不查** —— 闸门有顺序，提前剪枝节流并避免误导探针
> 3. **L1 改 Loadout 一处，L2 改 Ability 一处** —— 配置中心化但仍两维度切分
