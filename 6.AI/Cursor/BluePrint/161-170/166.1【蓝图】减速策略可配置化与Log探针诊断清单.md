## 一、初步诊断（无运行时数据，纯代码事实推断）

### 1.1 Bug — WalkEnd/RunEnd 播完后忽然抖一下（#2）

**根因假设（H1，最可能）**：

```
T0  ActionState 播 WalkEnd Action
    MotionExecutor 每帧 SampleLocalDelta → SetDesiredVelocity = curveZ' / dt
    KCC.PlanarVelocity = SetDesiredVelocity 的累积写入
    若 Action.MotionProfile.Z 末段斜率非 0（Z 曲线没下到 0）
      → 末帧速度仍 V_end > 0

T1  nt ≥ 0.9999 → ExitToBaseline → OnExit
    MotionExecutor.End()  ★ 内部仅 SetDesiredVelocity(Vector3.zero)
                            **没有** ClearPlanarVelocity
    EndActionMotorSession()  仅释放 Motor 会话
                            **没有** 速度清零

T2  PlayerLocomotionState.OnEnter
    LocomotionState 不主动清速

T3  下一帧 OnLogicUpdate → MoveByLocomotionIntent (input=0)
    var planar = PlanarVelocity       // ← 仍是 V_end
    var currentSpeed = V_end
    var targetSpeed = 0               // 无输入
    var accel = moveDeceleration (或 Tuning.GroundDeceleration)
    newSpeed = MoveTowards(V_end, 0, accel * 0.016f)
    SetPlanarVelocity(dir * newSpeed) // 衰减一帧
    → 玩家感受："End 播完后角色又往前蹭/抖一下，然后才停"
```

**关键证据**：
- `PlayerActionState.OnExit:200-211` 完整调用链中**无 ClearPlanarVelocity**
- `MotionExecutor.cs:216` 仅 SetDesiredVelocity(0)，不动 KCC 累积
- `Player.MoveByLocomotionIntent:557-562` 读 `PlanarVelocity` 作 currentSpeed
- 用户截图 `Motion 主轴 Z 位移 4.000m / Clip Length 0.8333` → 平均速度 ≈ 4.8 m/s，Z 曲线末段若不归 0，残余巨大

### 1.2 Bug — JumpLand 即便关打断仍不播完（#1）

### 1.3 减速策略需求（#3）

绝区零式"滑步 End"本质：
- End Action 播放期间，**位移可由 KCC + 玩家输入 + 残余速度 多源叠加**
- 末帧速度不归 0，残余惯性自然衰减到 Idle
- 玩家在 End 期间按方向键 → 可微调方向 → 视觉上像"刹车滑步"

**与 #2 矛盾**：#2 要消除"忽然抖一下"，#3 要保留"滑步惯性"。
**统一解法**：把"末段速度处理"**显式建模为可配置策略**，资产侧选：
- `Snap` — Action 末帧立即 ClearPlanarVelocity（最干净，"硬刹"感）
- `LinearDecay` — 进入 Locomotion 后线性衰减到 0（默认；Tuning.GroundDeceleration 决定速率）
- `ExpDecay` — 指数衰减（更柔，0.3s 半衰期）
- `PreservedSlide` — 不衰减，残余完整保留 → 玩家可继续微输入引导（**绝区零模式**）

## 三、减速策略可配置化设计（#2 + #3 统一解法）

### 3.1 数据契约

`ActionDataSO` 加（仅 IsContinuousLocomotion=false 时显示）：

```csharp
[Header("Action Exit Velocity Policy (166.1)")]
[Tooltip("Action 结束时如何处理玩家残余速度。\n" +
        "· Snap = 立即清零（硬刹）\n" +
        "· LinearDecay = 线性衰减（默认；用 Tuning.GroundDeceleration）\n" +
        "· ExpDecay = 指数衰减（更柔；用 ExpDecayHalfLife）\n" +
        "· PreservedSlide = 完整保留残余惯性（绝区零滑步模式）")]
public ActionExitVelocityPolicy ExitVelocityPolicy = ActionExitVelocityPolicy.LinearDecay;

[Tooltip("ExpDecay 模式专用：速度半衰期（秒）。0.3 ≈ 较柔；0.1 ≈ 较脆。")]
[Range(0.05f, 2f)] public float ExpDecayHalfLife = 0.3f;

[Tooltip("PreservedSlide 专用：残余速度上限（防止极端 Z 曲线末段抛飞）。0 = 不限。")]
[Min(0f)] public float SlideMaxResidualSpeed = 0f;
```

```csharp
public enum ActionExitVelocityPolicy : byte
{
    Snap = 0,
    LinearDecay = 1,
    ExpDecay = 2,
    PreservedSlide = 3,
}
```

### 3.2 运行时落地

#### Step A — `PlayerActionState.OnExit` 应用策略

```csharp
// OnExit 内 EndActionMotorSession() 之前
if (m_action != null)
{
    ApplyExitVelocityPolicy(player, m_action);
}

void ApplyExitVelocityPolicy(Player player, ActionDataSO action)
{
    switch (action.ExitVelocityPolicy)
    {
        case ActionExitVelocityPolicy.Snap:
            player.ClearPlanarVelocity();
            break;
        case ActionExitVelocityPolicy.LinearDecay:
            // 不动残余；Locomotion.MoveByLocomotionIntent 自然 MoveTowards 衰减
            break;
        case ActionExitVelocityPolicy.ExpDecay:
            // 转交给 LocomotionState OnEnter 启动 ExpDecay 阶段
            player.BeginPostActionExpDecay(action.ExpDecayHalfLife);
            break;
        case ActionExitVelocityPolicy.PreservedSlide:
            // 残余保留；可选 Cap
            if (action.SlideMaxResidualSpeed > 0.01f)
            {
                var v = player.PlanarVelocity;
                if (v.magnitude > action.SlideMaxResidualSpeed)
                    player.SetPlanarVelocity(v.normalized * action.SlideMaxResidualSpeed);
            }
            break;
    }
}
```

#### Step B — `Player` 加 ExpDecay 状态

```csharp
float m_expDecayHalfLife;
float m_expDecayActiveUntilTime;

public void BeginPostActionExpDecay(float halfLife)
{
    m_expDecayHalfLife = Mathf.Max(0.05f, halfLife);
    m_expDecayActiveUntilTime = Time.time + halfLife * 6f; // 6 个半衰期后基本归零
}

public bool TryApplyExpDecay(float dt)
{
    if (Time.time >= m_expDecayActiveUntilTime) return false;
    var v = PlanarVelocity;
    var factor = Mathf.Exp(-dt * Mathf.Log(2f) / m_expDecayHalfLife);
    SetPlanarVelocity(v * factor);
    return true;
}
```

#### Step C — `PlayerLocomotionState.OnLogicUpdate` 优先 ExpDecay

```csharp
// MoveByLocomotionIntent 之前
if (!player.HasMovementIntent && player.TryApplyExpDecay(Time.deltaTime))
{
    player.ApplyMotor(MotorSolveContext.Locomotion);
    return;  // 跳过 MoveByLocomotionIntent 的 MoveTowards 衰减
}
```

### 3.3 资产侧推荐预设

| 状态 | 推荐 Policy | 备注 |
|---|---|---|
| WalkEnd | Snap | 走停立即清零，最干脆 |
| RunEnd | ExpDecay (0.25s) | 跑停带一点滑步惯性 |
| **RunEnd "滑步版"**（绝区零）| **PreservedSlide (cap=2 m/s)** | 残余惯性引导滑步 |
| JumpLand | Snap | 落地立即停（不滑） |
| Stop（旧合一） | LinearDecay | 默认兼容 |
| 普通战斗 Action | LinearDecay | 与现行行为相同（零回归） |

### 9.2 代码事实复盘（在已有 165.1 §6 之上加深）

`PlayerActionState.OnLogicUpdate:178-195`（已加 isLastStage 兜底版）：

