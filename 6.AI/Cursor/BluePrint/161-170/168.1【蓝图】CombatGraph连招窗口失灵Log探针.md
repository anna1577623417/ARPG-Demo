## 二、假设矩阵（6 个根因候选）

| H | 假设 | 关键证据 |
|---|---|---|
| **H1（最可能）** | **IntentBuffer.ExpireTime 太短**（0.18s 在挑空 0.5s 内必过期）| `bufferSeconds: 0.18f` 在测试中出现；FlushExpired 每帧丢弃 ExpireTime < now |
| **H2** | TransitionResolver 全局闸门拦截（标签未刷新到 Combo 允许态）| `CanOfferIntent` 返回 false |
| **H3** | SkillEntryService 未解析到下一段 Route / Graph 边 | `LastIntentResolvedViaGraph=false` + DualGate BLOCK |
| **H4** | ActionInterruptResolver.CanInterrupt 拒绝：当前 ActionWindow 未配 `Offense` 在 InterruptibleByCategories 中；或 nt 还在 PhaseActive 不允许打断 | window category miss |
| **H5** | GraphDualGatePolicy BLOCK：当前 Action GraphParticipation=Full + !LastIntentResolvedViaGraph → 拒绝 | `RequiresConsumeDualGate=true` + 解析路径未过 Graph |
| **H6** | ComboRoute Session 已超时 / IsActive=false（在 A1 结束瞬间被 NotifyRouteExited 清掉，导致 A2 没人接）| `_activeComboSession == null` |

辅证 — **状态机切换打断**（与 H1-H6 正交）：

| H7 | A1 结束 → PlayerActionState.ExitToBaseline → Change<Locomotion> → !IsGrounded → Change<Airborne> → 新 LM 输入路由到 Airborne 而非 Action | 切换链路过长，每次切换都可能丢 intent |

## 三、Log 探针落地点（6 处）

### A. `IntentBuffer.Enqueue` — 缓冲入队 + 过期戳

挂点：`GameplayIntentBuffer.Enqueue` 内部

```csharp
// 入队尾，立即打日志
if (Application.isPlaying)
{
    Debug.Log($"[Combo][Enq] kind={intent.Kind} slot={intent.EntrySlot} " +
              $"now={Time.time:F3} expire={intent.ExpireTime:F3} " +
              $"validFor={intent.ExpireTime - Time.time:F3}s " +
              $"bufferSize={_count} frame={Time.frameCount}");
}
```

> **关键字段**：`validFor` — 这条意图能存活多久。若用户看到 0.18s 而非 0.5s+ → **H1 确认**。

### B. `IntentBuffer.FlushExpired` — 过期丢弃事件

```csharp
public void FlushExpired(float now)
{
    while (_count > 0 && TryPeek(out var head) && head.ExpireTime < now)
    {
        if (Application.isPlaying)
        {
            Debug.LogWarning($"[Combo][Drop] EXPIRED kind={head.Kind} slot={head.EntrySlot} " +
                            $"expire={head.ExpireTime:F3} now={now:F3} " +
                            $"droppedBy={now - head.ExpireTime:F3}s frame={Time.frameCount}");
        }
        Pop();
    }
}
```

> **关键现象**：用户点 LM → A1 上挑 → 等 0.3s 再点 LM → 第一条点 LM 的 intent 已丢弃 → 第二条入队但首条已过期 → 看到 `[Combo][Drop] EXPIRED` 频繁出现 = **H1 确认**。

### C. `PlayerActionState.TryConsumeGameplayIntent` — 仲裁失败原因

挂点：`PlayerActionState.cs:220` 附近（CanInterrupt 调用处）

```csharp
public override bool TryConsumeGameplayIntent(Player player, in FrameContext ctx, in GameplayIntent intent)
{
    var incomingAction = IntentRouter.PeekActionDataForRouting(player, in intent);

    // 探针 ①：CanInterrupt 之前
    if (player.DebugLocomotion)
    {
        Debug.Log($"[Combo][Probe] action={m_action?.name} nt={m_prevNormalizedTime:F3} " +
                  $"incoming={intent.Kind} incomingAction={incomingAction?.name} " +
                  $"airborne={!player.IsGrounded} vy={player.VerticalSpeed:F2} " +
                  $"frame={Time.frameCount}", player);
    }

    if (!ActionInterruptResolver.CanInterrupt(m_action, m_prevNormalizedTime, in intent, incomingAction, player))
    {
        // 探针 ②：拒绝原因（窗口/类别/优先级）
        if (player.DebugLocomotion)
        {
            var cat = ActionInterruptResolver.ResolveIncomingCategory(in intent, incomingAction);
            var allowed = ActionInterruptResolver.GetCurrentWindowInterruptibleCategories(m_action, m_prevNormalizedTime);
            Debug.LogWarning($"[Combo][Reject] CanInterrupt=false " +
                            $"action={m_action?.name} nt={m_prevNormalizedTime:F3} " +
                            $"incomingCat={cat} windowAllowed={allowed} " +
                            $"incomingPri={incomingAction?.InterruptPriority} stabilityOfCurrent={m_action?.InterruptStability}", player);
        }
        return false;
    }

    // 探针 ③：DualGate 检查
    var needsDualGate = GraphDualGatePolicy.RequiresConsumeDualGate(incomingAction);
    var entries = player.SkillEntries;
    if (needsDualGate && entries != null && !entries.LastIntentResolvedViaGraph)
    {
        if (player.DebugLocomotion)
        {
            var part = GraphDualGatePolicy.ResolveParticipation(incomingAction);
            Debug.LogWarning($"[Combo][DualGateBlock] action={incomingAction?.name} " +
                            $"participation={part} resolvedViaGraph={entries.LastIntentResolvedViaGraph} " +
                            $"→ BLOCK; 需 SkillEntries 走 Graph 边解析", player);
        }
        return false;
    }

    // 探针 ④：仲裁通过
    if (player.DebugLocomotion)
    {
        Debug.Log($"[Combo][Pass] action={m_action?.name} → incoming={incomingAction?.name} routing...", player);
    }
    // ... 现行 IntentRouter.Route 路径 ...
}
```

> 4 个子探针覆盖所有可能的 reject 点 → 直接看哪个分支出来。

## 四、验证矩阵（对号入座）

| Log 模式 | 结论 | 修复 |
|---|---|---|
| `[Combo][Enq] validFor=0.18s` 后 0.3s 用户再按 LM 没看到第二条 Enq；首条已 `[Combo][Drop] EXPIRED` | **H1** ★最高概率 | `bufferSeconds` 由 0.18 → 0.5（与玩家直觉一致）;或按 ComboSessionResetTime 动态推算 |
| `[Combo][Reject] CanInterrupt=false incomingCat=Offense windowAllowed=Movement\|Defensive` | **H4** | A1 Action 加 ActionWindow `[recovery]` 区配 `InterruptibleByCategories \|= Offense` |
| `[Combo][DualGateBlock] participation=Full resolvedViaGraph=false` | **H5** | 检查 Combat Graph 是否真有 A1→A2 边；或 GraphParticipation 改 SourceOnly |
| `[Combo][Resolve] resolved=false routeName=NULL` | **H3** | SkillEntries 不识别该意图为 Combo 续段；检查 SkillEntryDefinition 配置 |
| `[Combo][Session] sessionActive=true linkWindowOpen=false sessionExpired=true resetTime=0.3` | **H6** | ComboSessionResetTime 从 0.3 → 0.6（与 H1 类似但作用域是 Session） |
| `[Combo][Session] IsActive=false` 在 A1 末段就出现 | A1 Route 已主动退出，Session 关 → 下一个意图无父 Session 可接 | 检查 NotifyRouteExited 时序 |
| `[Combo][StateSwap]` Action → Locomotion → Airborne → Action（短时间反复） | **H7** | 路径稳定性问题；A1 末段不应回 Locomotion，应直接 wait → A2（或 IntentBuffer 抗 SwapState）|

## 五、最高概率结论预测

```
H1（IntentBuffer 缓冲 0.18s 太短）+ H6（ComboSessionResetTime 偏短）= 80% 概率

修复：
  1. SkillEntryIntentFactory.ForEntry 的 bufferSeconds 默认 0.18 → 0.5
  2. ComboRouteDefinition.ComboSessionResetTime 默认值复核（建议 ≥ 0.6s）
  3. （可选）若 Action.IntentCategory=Combat 且当前 ActiveRoute 是 ComboRoute → 
     ExpireTime = max(默认, Session.ResetTime + 0.1s 余量)
```
