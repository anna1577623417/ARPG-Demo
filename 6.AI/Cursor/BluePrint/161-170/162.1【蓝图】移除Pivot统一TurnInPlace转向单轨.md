## 核心结论

**Pivot 不是可操作单位** —— 它是 158.2 对「大角原地转身」的笼统离散 State；Detect 早已不产出 Pivot，但枚举、Profile（`State: 6`）、`shouldTrigger`、Tuning 命名（`PivotThresholdDeg`）仍残留，与 **TurnInPlaceDirected × 4 子键** 重叠。

**真正可操作的是四向转身**：
- `Left90` / `Right90` — 小角
- `Left180` / `Right180` — 承接原 Pivot / 大角语义

**架构病灶：双轨判角**
- `DetectRequestedState` 用 `LocomotionTuning.Pivot*ThresholdDeg`
- `TurnResolver` 用 `TurnSettings` 另一套阈值  
→ 162.1 收敛为 **单点 `LocomotionTurnIntent`**，Detect **不再表达 Turn**。

**180° 转完过渡**（蓝图 §1.3）  
转身锁定结束（`TurnInfo.IsTurning` false）→ `PlayerAnimController` 用 Turn Binding 的 `TransitionDuration`（180° 可略长）CrossFade 回 `ResolveLocomotionSub()` 的 Walk/Idle，**不进 ActionState**。

## 〇、问题陈述

### 0.1 用户决议（定稿）

1. **移除 Locomotion 域 `Pivot` 状态** —— 编辑菜单、Profile Binding、Detect/Resolver/FIRE 逻辑均不再出现「Pivot」作为可操作 State。
2. **转身唯一可操作单位** = `TurnInPlaceDirected` + `TurnDirection4` 四子键（Left90 / Right90 / Left180 / Right180）。
3. **旧 Pivot 语义** = 对 **180° 原地转身** 的笼统称呼，应落到 **Left180 / Right180** 两条 Binding + Clip，不是独立 Simple State。
4. **180° 转向负责「转完过渡」** —— 播完 / 角度收敛后的 CrossFade 回 Walk/Idle（或 WalkStart），由转身子系统统一出口，不靠 Pivot Action。
5. **重新审视意图解析与状态机** —— 消除 Detect 与 `TurnResolver` 双轨判角；单点真相驱动表现。

### 0.2 代码事实（2026-06 扫描）

| 现象 | 位置 | 结论 |
|---|---|---|
| `DetectRequestedState` **永不返回** `Pivot` | `PlayerLocomotionState.cs` L272–288 | Pivot Binding **僵尸** |
| 大角 Detect 只产出 `TurnInPlaceDirected` | 同上 | 180° 已是 Turn 子键，不是 Pivot |
| `shouldTrigger` 仍含 `Pivot` 分支 | L202–215 | 死代码 |
| `m_pivotCooldownRemaining` 命名 | L27–28, L146–149 | 实际服务 Turn，命名误导 |
| `LocomotionTuningSO.PivotThresholdDeg` | Tuning + Detect | 控制 Turn180 阈值，名仍叫 Pivot |
| `TurnResolver` 独立判角 + 锁定 | `TurnResolver.cs` | **第二套**转身闸门 |
| `TurnSettings` vs `LocomotionTuning` | `PlayerStateManager` / Tuning SO | **双阈值源**，可能不一致 |
| `TurnInPlaceDirected` = Continuous | `LocomotionStateId.IsContinuous` | 绑 Clip，**不进 ActionState** |
| 转身 Anim 走 `TurnInfo` → Profile | `PlayerAnimController` + `LocomotionAnimProfileBridge` | 与 Detect 的 Intent **未握手** |
| Profile 仍有 `State: 6` (Pivot) 行 | `LocomotionProfile_Player.asset` | 资产残留 |
| `KinematicMotorSolver.*Pivot*` | Motor 层 | **角色根点/脚点**，与 Locomotion State **无关**，本切片 **不改** |

### 0.3 架构病灶（必须修）

```
【现状 · 双轨】

  MovementIntent + forward
        ├─→ DetectRequestedState ──→ LocomotionIntent.TurnDirection
        │         (Tuning.Pivot*ThresholdDeg)
        │
        └─→ TurnResolver.Tick ──→ TurnInfo (Turn90/180)
                  (TurnSettings.*Threshold)
                        │
                        ▼
              PlayerAnimController 播 Turn Clip

  两套阈值、两套「是否在转身」—— 策划无法配表，AI 无法验收。
```

**162.1 目标：单轨**

```
  MovementIntent + forward + speed + Profile
        │
        ▼
  LocomotionTurnIntent（单点 API · 本切片设施）
        │  输出：IsTurning, TurnDirection4, SignedAngleDeg
        │
        ├─→ PlayerAnimController（TurnInPlaceDirected × 4 Clip）
        ├─→ PlayerLocomotionState（逻辑移动/旋转门控 · 可选减速）
        └─→ 不写 Pivot；不 FIRE Turn 进 ActionState
```

## 一、概念契约（移除 Pivot 后）

### 1.1 术语边界

| 术语 | 保留？ | 含义 |
|---|---|---|
| `LocomotionStateId.Pivot` | **废弃**（Obsolete，Id=6 位不变） | 158.2 离散转身占位；Detect 不产出 |
| `TurnInPlaceDirected` | **唯一转身 State** | Composite：4 向 × ContinuousClip |
| `TurnDirection4.Left180/Right180` | **可操作子键** | 承接原「Pivot / 大角转身」 |
| `TurnDirection4.Left90/Right90` | **可操作子键** | 小角原地转身 |
| `TurnInfo` / `TurnResolver` | **保留并升格** | 单轨转身意图（可改名，见 L2） |
| Motor `worldPivot` | **保留** | 胶囊根点，与 Locomotion State 无关 |

### 1.2 Profile 配表契约

| 项 | 规则 |
|---|---|
| Enabled | 只勾 `TurnInPlaceDirected`；**不勾 Pivot** |
| Binding | 4 行；每行 `ContinuousClip`；`DiscreteAction` 必须空 |
| Fallback | 一律 `Idle`（AutoFix 默认） |
| 180° 资源 | `GhostSamurai_*_TurnL180_Root` / `TurnR180_Root` → Left180 / Right180 行 |
| 90° 资源 | `TurnL90` / `TurnR90` → 对应行 |
| 转完过渡 | 使用各行 `TransitionDuration` + §1.3 解锁混合 |

### 1.3 转完过渡（180° 重点）

**定义**：转身锁定结束（`TurnInfo.IsTurning` false）→ 表现层从 Turn 子切片 **CrossFade** 回 Locomotion 循环（Idle / Walk / Run）。

| 阶段 | 权威 | 行为 |
|---|---|---|
| 转身中 | `TurnInfo.IsTurning=true` | `PlayerAnimController` 播 `TurnInPlaceDirected` 对应 Clip；KCC `LookAtDirection` 继续逻辑旋转 |
| 收敛判定 | `TurnResolver` 解锁条件 | `absAngle < UnlockAngleThreshold` 且 `MinLockDuration` 已过 |
| **转完过渡** | `PlayerAnimController` | 解锁边沿：`PlayLocomotionClipForSub` 以 **Turn 行 TransitionDuration**（180° 可配置略长）切回 `ResolveLocomotionSub()` |
| 180° vs 90° | `TurnSettings` 可选扩展 | `PostTurnBlendTurn180` ≥ `PostTurnBlendTurn90`（默认 0.12 / 0.08） |

**禁止**：用 Pivot `DiscreteAction` 进 `PlayerActionState` 表达转完 —— 与 159.1 Continuous 转身冲突。

### 1.4 阈值单一真相（Tuning 收敛）

| 旧字段（废弃） | 新字段 | 消费者 |
|---|---|---|
| `PivotThresholdDeg` | `Turn180ThresholdDeg` | 唯一 `LocomotionTurnIntent` |
| `Pivot90ThresholdDeg` | `Turn90ThresholdDeg` | 同上 |
| `TurnSettings.Type180AngleThreshold` | **删除或只读镜像 Tuning** | 避免双配 |
| `TurnSettings.TriggerAngleThreshold` | 保留或迁入 Tuning `TurnTriggerThresholdDeg` | 策划一处改 |

**决议**：转身角度阈值 **只读 `LocomotionTuningSO`**；`TurnSettings` 仅保留表现开关（`EnableTurnInPlacePresentation`、Debug、MinLock、Unlock、PostTurnBlend）。

## 二、意图解析与状态机 —— 重审结论

### 2.1 当前帧序（`PlayerLocomotionState.OnUpdate`）

```
1. ProcessLocomotionResolve()     ← Detect 含 Turn 分支
2. TurnResolver.Tick()            ← 独立 TurnInfo
3. MoveByLocomotionIntent()       ← 逻辑旋转
4. m_pivotCooldownRemaining -= dt
```

### 2.2 目标帧序（162.1 终态）

```
1. LocomotionTurnIntent.Resolve()  ← 单点：角差 + 速度闸门 + 锁定
2. player.SetTurnInfo(...)
3. ProcessLocomotionResolve()      ← Detect **删除** Turn 优先级；持续输入仍 Walk/Run/Strafe
4. MoveByLocomotionIntent()        ← 转身中可抑制位移或保持 LookAt（与现 TurnResolver 一致）
5. m_turnReentryCooldown -= dt     ← 仅防 Turn Clip 连播抖动；可选 L3 删除若锁定足够
```

### 2.3 DetectRequestedState 新优先级（Pivot 删除后）

```
1. release → WalkEnd / RunEnd
2. press   → WalkStart / RunStart
3. LockOn + input → StrafeLocomotion
4. hasInput → Walk / Run
5. !hasInput → Idle

（Turn **不在 Detect** —— 不是 Locomotion「状态切换」，是表现叠加层）
```

### 2.4 `shouldTrigger` / ActionState

| State | FIRE？ |
|---|---|
| WalkStart/End, RunStart/End, Jump* | 是（边沿） |
| Pivot | **删除** |
| TurnInPlaceDirected | **否**（Continuous；永不 `ArmPendingAction`） |

### 2.5 状态机（四支柱不变）

- 转身期间 **不** `Change<ActionState>` 因 Turn。
- 仍在 `PlayerLocomotionState`；`TurnInfo` 供 Presentation 读。
- `PlayerActionState` 仅收离散 Locomotion Action（起停等）。

## 九、面试口述总结

158.2 的 **Pivot** 是「大角转身」的笼统离散 State；159.1 已用 **TurnInPlaceDirected × 四向 Clip** 替代，但 Pivot 仍留在枚举、Profile 和命名里，且 **Detect 与 TurnResolver 双轨判角**。162.1 彻底 **Obsolete Pivot**、**Detect 不再表达 Turn**、**单点 TurnIntent 读 Tuning**，180° 明确落在 **Left180/Right180** 子键，并在 **Turn 解锁边沿** 做回 Walk/Idle 的 CrossFade，使转身成为可配表、可验收的 Continuous 表现层，而不是模糊的 Pivot 概念。
