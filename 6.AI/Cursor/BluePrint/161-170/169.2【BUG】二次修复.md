我觉得你这个现象已经很关键了：

> “编辑了上一个 LateWindow，点击下一个 Edge，不会刷新正确值，而是残留上一个编辑量，必须重启。”



这说明：

> 问题很可能不是 IMGUI TextField 焦点，而是 Inspector 根本没有重绘/重新绑定数据。



前面那个修复其实是针对：

同一个 FloatField 的编辑缓存残留

但你的症状更像下面几种情况。


---

第一种可能（我觉得概率最高）

Edge Inspector 持有了旧 Edge 引用

例如：

错误写法：

private static CombatFlowEdge s_CurrentEdge;

void Draw()
{
    if (SelectionChanged)
    {
        // 没更新
    }

    EditorGUILayout.FloatField(
        s_CurrentEdge.LateWindowSeconds);
}

或者：

SerializedEdge serialEdge;

if(serialEdge == null)
    serialEdge = selectedEdge;

之后：

A → B

实际上：

selectedEdge = B

Inspector绘制仍然使用A

直到：

关闭重开

重新初始化：

serialEdge = B

才恢复正常。

这种在 GraphView 很常见。


---

验证方法：

在 Inspector 顶部打印：

EditorGUILayout.LabelField(
    "GUID",
    serialEdge.GUID);

EditorGUILayout.LabelField(
    "Late",
    serialEdge.LateWindowSeconds.ToString());

然后：

选A
编辑1.0
切B

观察：

如果 GUID 没变：

就是引用没刷新

如果 GUID 变了但 Late 还是旧值：

说明是缓存问题


---

第二种可能（比焦点问题更常见）

SerializedObject 没有重新创建

例如：

错误：

static SerializedObject s_EdgeSO;

第一次：

s_EdgeSO = new SerializedObject(edgeA);

以后：

s_EdgeSO.Update();

但：

切换EdgeB

没有：

s_EdgeSO = new SerializedObject(edgeB);

于是：

Inspector一直绑定A。

直到：

关闭窗口

静态变量清空。


---

这种症状和你描述几乎一致：

> 必须重启才能看到真实值。



因为：

> 重启刚好重建了 SerializedObject。




---

验证：

打印：

Debug.Log(s_EdgeSO.targetObject.name);

看看切换 Edge 后是否变化。


---

第三种可能

GraphView 的 SelectionChanged 根本没触发

例如：

graphView.OnSelectionChanged += OnSelectionChanged;

实际：

A → B

Graph内部选中了B，

但：

CurrentInspectorEdge

没更新。

Inspector仍然：

Draw(A)

直到重启：

重新同步。


---

验证：

切换边时：

Debug.Log("Select Edge " + edge.GUID);

如果：

A
A
A
A

没有B：

说明 Selection 链断了。


---

第四种可能（很容易忽略）

LateWindow 用的是延迟字段（Delayed）

例如：

EditorGUILayout.DelayedFloatField(...)

或者：

PropertyField(...)

对应：

[Delayed]
float LateWindow;

这种行为：

编辑中：
1

未失焦：
内部值仍然0.5

然后：

切换Edge：

ApplyModifiedProperties没执行

Unity内部编辑缓存挂着。

这种情况下：

即使换GUID，

缓存也可能继续显示。


---

验证：

搜索：

DelayedFloatField
Delayed

看看有没有。


---

第五种可能（如果你是UIToolkit Inspector）

如果你的Inspector实际上是：

FloatField lateWindow;

然后：

lateWindow.Bind(serializedObject);

那么问题更像：

lateWindow.Unbind();
lateWindow.Bind(newSO);

没有执行。

UIToolkit 会缓存：

VisualElement → SerializedProperty

导致：

UI已经换Edge
字段还是旧Binding

关闭重开：

VisualTree重建。

恢复正常。
