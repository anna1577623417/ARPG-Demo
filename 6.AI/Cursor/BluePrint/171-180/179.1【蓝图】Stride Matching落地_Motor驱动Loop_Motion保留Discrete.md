## §1 设计哲学（资料 §530-536 / §990-1004）

> 1. **Loop 动作（Walk/Run/Sprint）** = **Motor 驱动 + Stride Matching** —— 动画追随真实速度
> 2. **Discrete 动作（Start/End/Pivot/Land/Attack/Dodge）** = **Motion 驱动 + Animation** —— Motion 曲线决定位移
> 3. **永远让真实速度成为唯一真相** —— 不允许 Buff/Debuff 同时去乘 Motion 和动画倍率

**职责切线**：

```
ActionProfile
    ↓
ReferenceSpeed（数据；编辑期烘焙）

Motor
    ↓
CurrentSpeed（真实速度；唯一真相）

LocomotionRuntime ←─── 本蓝图新增模块
    ↓
PlaybackSpeed = CurrentSpeed / ReferenceSpeed

Playable
    ↓
SetSpeed()

Motion ────────── 不参与（IsContinuousLocomotion=true 时直接跳过）
```

## §3 运行时层：`LocomotionRuntime`（**新核心**）

```csharp
// 2_Framework/Locomotion/StrideMatching/LocomotionRuntime.cs
public sealed class LocomotionRuntime
{
    readonly LocomotionRuntimeProfileSO _config;
    readonly IPlayerAnimDriver _anim;            // PlayerAnimController 实现
    readonly IPlayerMotor _motor;                // KCC 接口

    ActionDataSO _currentLoop;                   // 当前 Loop Action（MotorDriven）
    float _smoothedSpeed;
    float _playbackSpeed = 1f;
    float _footPhase;                            // [0,1) 累积步相位

    public float SmoothedSpeed => _smoothedSpeed;
    public float PlaybackSpeed => _playbackSpeed;
    public float FootPhase     => _footPhase;

    public void OnEnterLoop(ActionDataSO loop)
    {
        _currentLoop = loop;
        // 不重置 _smoothedSpeed —— 跨 Loop 切换保持速度连续
    }

    public void OnExitLoop() => _currentLoop = null;

    public void Tick(float dt)
    {
        if (_currentLoop == null) return;
        if (_currentLoop.MovementMode != MovementMode.MotorDriven) return;
        if (!_currentLoop.EnableStrideMatching) return;

        // ① 平滑真实速度（避免帧抖）
        var target = _motor.HorizontalSpeed;
        var tau = Mathf.Max(0.001f, _config.SpeedSmoothingTau);
        _smoothedSpeed = Mathf.Lerp(_smoothedSpeed, target, 1f - Mathf.Exp(-dt / tau));

        // ② 计算 ratio
        var refSpeed = _currentLoop.ReferenceSpeed;
        if (refSpeed < 0.01f) return;          // 烘焙缺失：fallback playback=1
        var ratio = _smoothedSpeed / refSpeed;

        // ③ Tier 切换（资料 §962-987 — 防止超倍速快进 / 慢动作）
        if (_currentLoop.AutoTierSwitch
            && (ratio > _currentLoop.MaxPlaybackSpeed || ratio < _currentLoop.MinPlaybackSpeed))
        {
            RequestTierSwitch(_smoothedSpeed);     // 通知 LocomotionState 换 Loop
            return;
        }

        // ④ 应用到 Playable
        ratio = Mathf.Clamp(ratio, _currentLoop.MinPlaybackSpeed, _currentLoop.MaxPlaybackSpeed);
        _playbackSpeed = ratio;
        _anim.SetPlaybackSpeed(ratio);

        // ⑤ Foot Phase 累积
        if (_config.EnableFootPhase)
        {
            var stepHz = 1f / Mathf.Max(0.001f, _currentLoop.ReferenceDuration);
            _footPhase += stepHz * ratio * dt;
            _footPhase -= Mathf.Floor(_footPhase);
        }

        // ⑥ EventBus 步频更新（接 FootIK / 178.1 PhaseMatch / 音效 footstep）
        GlobalEventBus.Publish(new StrideUpdatedEvent {
            Loop = _currentLoop, Speed = _smoothedSpeed,
            Ratio = ratio, FootPhase = _footPhase });
    }

    void RequestTierSwitch(float speed)
    {
        // 找到 speed 落在哪个 Tier 区间，请求 LocomotionState 换 Loop
        LoopTier target = ResolveTier(speed, _config);
        GlobalEventBus.Publish(new LocomotionTierSwitchEvent { Target = target });
    }
}

public enum LoopTier : byte { Walk, Run, Sprint }
```

[InitializeOnLoad]
public static class StrideReferenceBaker
{
    [MenuItem("GameMain/Locomotion/Bake Stride References (Selected)")]
    public static void BakeSelected() { /* 扫描选中 ActionDataSO */ }

    [MenuItem("GameMain/Locomotion/Bake Stride References (All Loops)")]
    public static void BakeAllLoops() { /* 扫描整库 MotorDriven Loop */ }

    public static void Bake(ActionDataSO action)
    {
        var clip = action.AnimationClip;
        if (clip == null || action.MovementMode != MovementMode.MotorDriven) return;

        // ① ReferenceDuration = Clip.length（单个 Loop 循环长度）
        action.ReferenceDuration = clip.length;

        // ② ReferenceDistance：复用 ClipMotionExtractor 提取 RootMotion 总位移
        var totalDist = ClipMotionExtractor.ExtractHorizontalDistance(clip);

        // 当 Clip 是原地走 RootMotion=0 → 通过策划标定的 DesignedSpeed 反推
        if (totalDist < 0.01f && action.DesignedSpeed > 0)
            totalDist = action.DesignedSpeed * clip.length;

        action.ReferenceDistance = totalDist;

        EditorUtility.SetDirty(action);
    }
}

## §6 自动 Tier 切换（Walk↔Run↔Sprint）

### §6.1 迟滞带（防边界震荡）

```
Walk:   [0,    3.0]
Run:    [2.5,  7.5]     ← Walk 上沿 3.0 > Run 下沿 2.5，重叠 0.5m/s = 迟滞
Sprint: [7.0, 12.0]     ← Run 上沿 7.5 > Sprint 下沿 7.0，重叠 0.5m/s
```

```csharp
public static LoopTier ResolveTier(float speed, LocomotionRuntimeProfileSO cfg, LoopTier current)
{
    var h = cfg.HysteresisFraction;
    switch (current)
    {
        case LoopTier.Walk:
            if (speed > cfg.WalkRange.y + h * cfg.WalkRange.y) return LoopTier.Run;
            return LoopTier.Walk;
        case LoopTier.Run:
            if (speed < cfg.RunRange.x - h * cfg.RunRange.x) return LoopTier.Walk;
            if (speed > cfg.RunRange.y + h * cfg.RunRange.y) return LoopTier.Sprint;
            return LoopTier.Run;
        case LoopTier.Sprint:
            if (speed < cfg.SprintRange.x - h * cfg.SprintRange.x) return LoopTier.Run;
            return LoopTier.Sprint;
    }
    return current;
}
```

### §6.2 接入 `PlayerLocomotionState`

`LocomotionTierSwitchEvent` 由 `PlayerLocomotionState` 订阅 → 触发现有的 Walk↔Run 切换链路。**Sprint 档位作为新增层**（如果资产不全则 fallback 到 Run @ 1.5×）。

## §10 关键架构约束

1. **Motion 与 Stride 互斥** —— `MovementMode=MotorDriven` 时 MotionExecutor **完全跳过**；不允许两套同时影响位移。
2. **真实速度是唯一真相** —— PlaybackSpeed 永远是 `Motor.Speed / Reference.Speed` 的函数；不允许动画速度反向决定 Motor。
3. **Discrete 不参与 Stride** —— Attack / Dodge / Pivot / Land 强制 `MovementMode=MotionDriven`；Buff 加速永不污染攻击位移。
4. **烘焙在编辑期** —— ReferenceSpeed 由 `StrideReferenceBaker` 一键算；运行时**只读**。
5. **Tier 切换有迟滞** —— 边界 ±15% 才换档；防止抖动。
6. **Min/Max Playback 钳制** —— ratio < 0.6 / > 1.4 应触发 Tier 切换而不是慢动作 / 快进。
