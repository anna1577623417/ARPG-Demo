# 171.5【设计图】ActionTimeline 预览 v2 —— 轨迹锚定 / 三色分轴 / 时间节点列表 / 紧凑布局 / 预览开关 / 空间信息栏

> **基线**：171.1 MotionProfile 预览系统 / 172.2 编辑器 UX 优化（已落 W0~W6）
> **本次范围**：基于 172.2 落地后的实际运行截图反馈，做第二轮深化 —— 解决"轨迹跟角色一起动 / 颜色单一 / 圈圈写死 / 横条浪费空间 / 无显示开关 / Scene 信息追角色"六大新问题
> **核心理念**：**轨迹是世界事实，不是角色相对路径** —— 一切位置可视化锚定到 **CaptureOrigin**，角色移动只移动角色本身

## §0 现状新短板（基于实跑截图）

| # | 短板 | 截图证据 | 影响 |
|---|---|---|---|

## §1 设计原则（不可越界）

> 1. **CaptureOrigin 是世界事实** —— 进入 MotionDriven 时 cached 的 anchor.position/rotation，是**所有 Gizmo 与 Scene 信息的唯一锚点**
> 2. **角色移动不连带 Gizmo** —— Gizmo 直接 DrawWireDisc(captureOrigin + heading × motionLocal(t))，不读 anchor.position
> 3. **可视化分层可关** —— 每一类 Gizmo / 文本独立开关，最终能"只剩动作"
> 4. **配置 > 写死** —— 未来位置节点 / Gizmo 颜色 / Scene 文本样式全部 EditorPrefs + ActionDataSO 数据

## §2 改进 #1 + #2 + #3：轨迹锚定 + 三色分轴 + 时间节点列表

### §2.1 锚定策略（**核心**）

```csharp
// 现状（错）：
DrawWireDisc(motionWorldPosition);   // ← motionWorldPosition = anchor.position + offset
// anchor.position 每帧被 SamplePose 改 → Gizmo 跟着动

// 正解：
DrawWireDisc(captureOriginPos + captureOriginHeading × MotionAxisCurves.SampleLocalPosition(t));
// captureOriginPos 是进入 MotionDriven 时一次性 cached，永不变 → Gizmo 稳定
```

`PreviewController.CaptureDrivenAnchorOnce` 已记录 origin；将该 origin 暴露给 Gizmo 绘制端（`ActionDataTimelineSceneBridge` 通过 ctx.CaptureOriginPos 字段或事件）。

### §2.2 三色分轴 + 橙黄合成（Gizmo 颜色策略）

| 元素 | 颜色 | RGB |
|---|---|---|
| **合成 XYZ 轨迹**（主） | 橙黄 | (1.00, 0.65, 0.10) |
| X 分量（仅 X 变化） | 红 | (1.00, 0.30, 0.30) |
| Y 分量（高度） | 绿 | (0.45, 1.00, 0.45) |
| Z 分量（前后） | 蓝 | (0.40, 0.65, 1.00) |
| Future Position Marker | 黄白 | (1.00, 0.95, 0.50) |
| RootMotion 对比（Overlay 模式保留） | 灰 | (0.55, 0.55, 0.55) |

绘制策略：
- 合成线：CaptureOrigin → 每 Δt=0.02s 采样 `SampleLocalPosition(t)` → 折线
- 分轴线：仅当 `MotionAxisCurves.X/Y/ZCurve` 存在时绘制；从 CaptureOrigin 出发，仅在该轴方向有 offset
- 全部 Gizmo `Handles.color = ...`；颜色可在 `Preferences → ActionTimeline → Gizmo Colors` 改

### §2.3 颜色配置：`EditorPrefs` + `Reset to Default`

```csharp

```

## §3 改进 #4：紧凑布局（解决横条浪费）

### §3.1 当前 vs 改造

**当前（横条堆叠）**：
```
[Category               Offense        ▾]     ← 横条 100% 宽
[Main Clip   [Armature_Sword_Regular_A    ]]  ← 横条 100% 宽
[时长         [0.5                       ]]
[优先级       [10                        ]]
[强韧         [10                        ]]
[自打断       ☐                          ]
[预览  ●━━━━━━━━━━━━━━━━━━━ 0  ☑ Pose ☑ Scene]
[Segment ━━━━●━━━●━━ 0.42 → 0.75 Δ=0.325s [Frame] [0~1]]
[Scene Tracks Motion Combat Ghost TP FX SFX Cam Time]
```
**问题**：每行右 50% 留白 → 浪费纵向空间，挤压时间轴

**改造（**响应式紧凑卡片**）**：
```
┌─── 动作摘要 ────────────────────────────────────────────┐
│ Category [Offense ▾]    Main Clip [Sword_Regular_A ⊗] │  ← 一行两栏
│ 时长 [0.5]  优先级 [10]  强韧 [10]  自打断 ☐           │  ← 一行四栏（紧凑）
│ ─── 预览 ─────────                                     │
│ ●━━━━━━━━━━━━━━━━━━━ 0.00  ☑ Pose ☑ Scene             │
│ ─── Segment ──────                                     │
│ ━━━━●━━━●━━ 0.42→0.75  Δ=0.325s  [Frame] [0~1]        │
│ ─── 时间节点 (Markers) ──── [+] [×]                    │
│ ● 0.250 [─][×]   ● 0.500 [─][×]   ● 0.750 [─][×]      │  ← 自适应网格，宽则多列
└────────────────────────────────────────────────────────┘
Scene Tracks (toolbar):  Motion Combat Ghost TP FX SFX Cam Time   ← 折叠到 toolbar 行
```

### §3.2 关键改造规则

| 类别 | 规则 |
|---|---|
| **同行多字段** | "时长 / 优先级 / 强韧 / 自打断" 这种 1~2 数字短字段 → 一行 4 列；label 仍顶置但用 `miniLabel` 缩小 |
| **响应式列数** | 卡片宽 ≥ 600px → 4 列；≥ 400px → 2 列；< 400px → 1 列 |
| **长字段独占行** | Main Clip / Slider / Segment 这类需要全宽的字段独占 |
| **轻量分组**  | `─── 组名 ───` 分隔线替代 SectionSeparator 巨大 helpbox |
| **Scene Tracks 收 toolbar** | 当前独立行的"Motion/Combat/Ghost..."移到 Preview Toolbar 第二行 |

### §3.3 紧凑 row helper

```csharp
public static void CompactRowFloat(SerializedProperty[] props, GUIContent[] labels) {
    using var _ = new EditorGUILayout.HorizontalScope();
    for (int i = 0; i < props.Length; i++) {
        using var __ = new EditorGUILayout.VerticalScope(GUILayout.MinWidth(80f));
        EditorGUILayout.LabelField(labels[i], EditorStyles.miniLabel);
        EditorGUILayout.PropertyField(props[i], GUIContent.none);
    }
}
```

## §8 关键架构约束

1. **CaptureOrigin 是唯一锚点** —— Gizmo / Scene Label / Future Markers / 合成轨迹 / 分轴轨迹 6 个绘制源全部读 `ctx.CaptureOriginPos`，不允许读 `ctx.Anchor.position`
2. **Marker 数据存 SO** —— `ActionDataSO.PreviewTimeMarkers` 持久化；策划改 Action 即改 Marker；不存 EditorPrefs
3. **颜色 / 字号 / 可见性存 EditorPrefs** —— 跨 Action 共享；策划个人偏好；不存 SO
4. **Show 下拉是 mask** —— 单一 int；不允许散落 bool；多选 + 预设组合用同一 mask
5. **SpaceInfo 单一源** —— Timeline 下方栏 + Scene 端 Label 来自同一 `SpaceInfoModel`；任何字段计算只写一处
6. **响应式布局走宽度断点** —— 600/400/300 三档；不允许写死像素
