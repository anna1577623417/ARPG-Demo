## §1 设计哲学（资料 §467-471，**不可越界**）

> **Ability** 管"能不能做" → 角色拥有什么能力（持久状态）
> **Stance** 管"输入意味着什么" → 同一个键在不同姿态下走不同 Route
> **Route / CombatGraph** 管"接下来走哪条行为链"
> **Action / Motion** 管"实际执行"
> **PlayableGraph** 管"最终怎么表现出来"

这五层 **不允许混淆职责**。Stance 不播动画、不算伤害；Ability 不直接驱动 Motion；Route 不持久化能力位。

### §4.2 `JumpAbility` 运行时（**纯数据驱动**）

```csharp
public sealed class JumpAbility : IAbility
{
    JumpAbilityConfigSO _cfg;
    int _remainingJumps;
    float _coyoteUntil;
    float _bufferedUntil;
    float _holdSince;
    bool  _holding;
    JumpPhase _phase;       // None / Rising / Apex / Falling

    public void OnGrounded(bool grounded, float groundedAt)
    {
        if (grounded) { _remainingJumps = _cfg.MaxJumpCount; _coyoteUntil = float.PositiveInfinity; }
        else if (_coyoteUntil > Time.time + _cfg.CoyoteTimeSec)
            _coyoteUntil = Time.time + _cfg.CoyoteTimeSec;
    }

    public void OnInputPressed()
    {
        _bufferedUntil = Time.time + _cfg.JumpBufferSec;
        TryConsume();
    }

    public void OnInputReleased() => _holding = false;

    void TryConsume()
    {
        if (Time.time > _bufferedUntil) return;
        var grounded = Time.time <= _coyoteUntil;
        if (!grounded && _remainingJumps <= 0) return;

        var jumpIdx = _cfg.MaxJumpCount - _remainingJumps;
        var force = _cfg.JumpForce * _cfg.PerJumpForceMul.Evaluate((float)jumpIdx / _cfg.MaxJumpCount);

        if (_cfg.ClearFallSpeedOnJump) Motor.ClearVy();
        Motor.AddImpulseY(force);
        _remainingJumps--;
        _holding = true;
        _holdSince = Time.time;
        _bufferedUntil = 0;
        _coyoteUntil = 0;
        _phase = JumpPhase.Rising;

        // 选择起跳 Action（按当前 Stance / 速度）
        var action = SelectJumpAction(Stance.CurrentId, Velocity);
        Player.States.PlayAction(action);

        Player.Tags.State.Add(CapabilityTags.Airborne);
    }

    public void Tick(float dt)
    {
        var vy = Motor.Velocity.y;
        // Apex 检测
        if (_phase == JumpPhase.Rising && vy <= _cfg.ApexVyThreshold) _phase = JumpPhase.Apex;
        if (_phase == JumpPhase.Apex   && vy < -_cfg.ApexVyThreshold) _phase = JumpPhase.Falling;

        // 重力分层
        var g = _phase switch
        {
            JumpPhase.Apex    => _cfg.ApexGravityScale,
            JumpPhase.Falling => _cfg.FallGravityScale,
            _ => 1f
        };
        // Variable Height：松开后上升段额外重力
        if (_phase == JumpPhase.Rising && !_holding && Time.time - _holdSince > _cfg.MinHoldSec)
            g = _cfg.ReleaseEarlyGravityScale;

        Motor.ApplyGravityScale(g);

        if (_holding && Time.time - _holdSince > _cfg.MaxHoldSec) _holding = false;
    }
}
```

### §4.3 Jump 衍生为独立 Ability（**资料 §409-446**）

## §5 输入链路（Input → Ability → Route → Action）

```
PlayerInput (Unity Input System)
    ↓ 物理键映射
InputCommand (PrimaryAction / SecondaryAction / Jump / Sprint / Crouch / Utility / Skill1~4)
    ↓ StanceController.Current.InputMap 查表
AbilityId
    ↓ AbilitySystem.TryActivate(id, ctx)
    ├─ HasAbility？
    ├─ Stance.BlockedAbilities？
    ├─ Cooldown / Charge？
    └─ CapabilityTags ⨯ 当前 Action.AllowedIncomingTags 比对
    ↓ 通过
AbilityRoute（路由解析 — 按 Stance / Velocity / Grounded 分支）
    ↓
ActionDataSO
    ↓
ActionTimelineRuntime + MotionExecutor + PlayableGraph
```

**Sprint / Crouch 也是 Ability**：`Sprint = Toggle/Hold WantsRun bit`；`Crouch_Toggle = RequestStance(Crouch ⇄ Normal)`。所有键统一走 AbilitySystem，**不再有 PlayerController 直接置位 WantsRun 的旁路**。

## §9 关键架构约束

1. **Stance 不直接改 KCC 高度** —— 走 Enter/Exit Action + MotionProfile 曲线；保持单数据源原则。
2. **能力位单一来源** —— `LocomotionFeatureFlags` 渐次迁移到 `StanceDefinition.GrantedAbilities`；不允许两条并行路径。
3. **WantsRun 旁路保留期** —— W1 起 `WantsRun` 仅作 `Sprint` Ability 的 runtime cache；W7 完成后移除。
4. **Jump 数据驱动** —— 所有 magic number（CoyoteTime/JumpBuffer/Apex/Fall）必须在 SO；代码里不允许出现字面量。
5. **Ability 不持有 MonoBehaviour** —— 运行时 state 在 `AbilitySystem._runtime` 字典里；SO 永远 readonly。
6. **打断走 Tag 比对** —— W6 起 ActionDataSO 旧 Bool 字段 [Obsolete]；新内容必须用 Tag。

> 1. **Ability 管"能不能"，Stance 管"输入意味着什么"** —— 资料 §467 划下的边界，永远不混
