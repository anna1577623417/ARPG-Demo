# 172.2【设计图】ActionTimeline 编辑器 UX 优化 —— 垂直布局 / 真实 Motion 位移预览 / 循环播放 / Segment 输入

> **基线**：171.1 MotionProfile 预览系统 / 172.1 Segment 编辑兼容
> **本次范围**：编辑器 UX 四块短板（截图反馈）的设计方案 —— 不强行落代码，先给原型 + 落地路径
> **核心理念**：**编辑器 UX = 信息密度 + 操作直觉**；右属性面板**垂直滚动 > 水平堆叠**；预览**所见即所得**

## §0 现状 4 个短板（基于截图）

| # | 短板 | 截图证据 | 影响 |
|---|---|---|---|
| 1 | **右属性面板文本拥挤** | 红框处"允许类别 / 最低优先级 / 允许自打断 / 韧度狠招 / 战斗行为"全部水平 label+control 排列，label 列窄到截断 | 策划读 label 困难，需要 hover 才能识别；中文 8 字以上必截断 |

## §1 改进 #1：右属性面板**垂直化**

### §1.1 设计原则

> **竖直滚动比水平拥挤更友好** —— 用户接受向下滚动，但拒绝读截断的 label。

### §1.2 当前 vs 改造对照

**当前（水平 row）**：
```
┌─────────────────────────────────────────────────────────┐
│ 允许类别  [Locomotion ▾]                                │
│ 最低优先级 [0           ]                                │
│ 允许自打断 ☐                                            │
│ 战斗状态（Hitbox / Hurtbox / ...）                       │
│   韧德狠招  [(choose...) ]                              │
│   战斗行为  [(choose...) ]                              │
└─────────────────────────────────────────────────────────┘
```
问题：label 列宽硬编码 ~70px，中文 8 字必截断。

**改造（垂直 stack，label 在上）**：
```
┌─────────────────────────────────────────────────────────┐
│ 允许类别                                                 │
│ ┌────────────────────────────────────────────────────┐  │
│ │ Locomotion                                      ▾  │  │
│ └────────────────────────────────────────────────────┘  │
│                                                         │
│ 最低优先级                                               │
│ ┌────────────────────────────────────────────────────┐  │
│ │ 0                                                  │  │
│ └────────────────────────────────────────────────────┘  │
│                                                         │
│ ☐ 允许自打断                                            │
│                                                         │
│ ─── 战斗状态 ──────────────────────────────────────────  │
│                                                         │
│ 韧德狠招（Hitbox / Hurtbox / Invuln / Interrupt）       │
│ ┌────────────────────────────────────────────────────┐  │
│ │ (choose...)                                     ▾  │  │
│ └────────────────────────────────────────────────────┘  │
│                                                         │
│ 战斗行为（Combat Behavior Tag）                          │
│ ┌────────────────────────────────────────────────────┐  │
│ │ (choose...)                                     ▾  │  │
│ └────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### §1.3 排版规范（落地后必须遵守）

| 项 | 规范 |
|---|---|
| **label 位置** | 控件**上方**单独一行；不挤右边 |
| **label 字号** | `EditorStyles.miniLabel`（11pt）；不用 boldLabel 避免视觉过重 |
| **控件宽度** | 自适应面板宽（`GUILayout.ExpandWidth(true)`）；不固定 px |
| **label 与控件间距** | 2px（Space(2)） |
| **字段块间距** | 6px（Space(6)） |
| **分组分隔** | `─── 组名 ──────`（虚线 + 中文组名）；不用 Foldout（默认展开） |
| **三态短字段（bool / 单选小 enum）** | 仍可水平：`☐ 标签` 直接 Toggle |
| **数字字段** | DelayedFloatField（按 Enter 才提交），避免拖动时频繁触发 OnChange |

### §1.4 ScrollView 包裹

整个右属性面板用 `EditorGUILayout.BeginScrollView`，垂直滚动条贴右；横向**不允许**滚动（设 `alwaysShowHorizontal=false`）。

## §2 改进 #2：Motion 预览**真实位移叠加**

### §2.1 当前问题

`SampleAnimation(clip, t)` 把骨骼摆 Pose 但**不动 transform.position**（RootMotion 不接管）。Y/Z 曲线编辑器里能看到轨迹线，但预览窗里**角色站在原地**做动作 —— 等于失去了"所见即所得"。

### §2.2 设计方案：编辑期 Motion Sample Hook

```
PreviewContext.TickFrame(t)
   ├─ ① clip.SampleAnimation(previewCharacter, t)    （骨骼 Pose，已有）
   ├─ ② MotionExecutor.SampleLocalDelta(t-prevT)     （新增 —— 计算本帧 Δposition）
   ├─ ③ previewCharacter.transform.position += Δlocal × heading
   └─ ④ 绘制 Gizmo：完整轨迹 + 当前点高亮
```

### §2.3 三种预览模式（**用户可切**）

| 模式 | 行为 | 用途 |
|---|---|---|
| **Trajectory Only**（现状） | 原地 Pose + 曲线 Gizmo | 编辑曲线时校形 |
| **Motion Driven**（**新增 / 默认**） | Pose + 真实 ΔP 累积位移 | 验收手感 |
| **RootMotion Driven** | Pose + Clip 原始 RootMotion | 对比 MotionProfile vs Clip |

### §2.4 关键技术点

1. **累积位移可复位**：播放从 t=0 开始时 `previewCharacter.position = previewOrigin`（每次 Play / Loop 自动回正）
2. **Heading 选择**：默认 `Vector3.forward`；策划可在预览窗顶栏切"Heading"下拉（北/南/东/西/自定义角度）
3. **轨迹路径**：预览窗下方画一条 0~Clip.length 全程的浅色虚线；当前位置红点
4. **离开预览复位**：关闭窗口或选其它 Action → previewCharacter 自动回原位

### §2.5 与 174.1 三轴曲线咬合

174.1 的 X / Y / Z 三轴曲线由 `MotionExecutor.SampleLocalDelta` 已统一暴露。本设计图**只需调一次 API**就拿到完整位移，无需重复实现采样。

### §2.6 预览窗 UI 增量

```
┌─ Preview ──────────────────── 1.00x ─┐
│                                       │
│        [预览窗 Scene]                 │
│                                       │
│  ────────────────────────             │
│  Mode: [Motion Driven ▾]              │  ← §2.3 三模式切换
│  Heading: [Forward ▾]  ↻ Reset Pos    │
│  Show Trajectory: ☑                   │
│  0:00 (000.0%) Frame 0                │
└───────────────────────────────────────┘
```

## §3 改进 #3：循环播放 + 速率自由输入

### §3.1 当前 vs 改造

**当前（截图顶栏）**：
```
[Playback] 0.1x | 0.25x | 0.5x | 1x | 2x | 4x | 8x       0~1x | Anim×1.00
            ▲ 7 个互斥按钮 + 1 个 Speed Slider（隐藏在右上角）
```
问题：1.3× / 1.7× 无法精确给出；播完不回放。

**改造**：
```
[ ■ Stop ]  [ ▶ Play ]  [ 🔁 Loop ]  [Range: 0.42→0.95 ▾]
─────────────────────────────────────────────────────────
Playback Speed  ◀━━━━━●━━━━━▶  [ 1.30 ]x   预设：0.1× 0.5× 1× 2× 4×
                ↑ 拖动滑条        ↑ 直接输入   ↑ 一键预设按钮 5 个
```

### §3.2 三种速率输入并存

| 输入方式 | 类型 | 范围 |
|---|---|---|
| **滑条**（连续拖动） | Slider | 0.05 ~ 10.0 |
| **数字框**（精确输入） | DelayedFloatField | 0.05 ~ 10.0（Enter 提交） |
| **预设按钮**（5 个常用） | Button | 0.1× / 0.5× / 1× / 2× / 4× |

三者**共享同一 `_playbackSpeed` 字段**，任一改动其它两个同步。

### §3.3 循环播放规则

```
若 _loopPlayback == true：
    播放头到达 Range.End / Clip.length →
        播放头回 Range.Start / 0
        previewCharacter.position 回 Origin（§2.4）
        继续播
若 _loopPlayback == false：
    播放头到达终点 → 停止 + 留在终点（当前行为）
```

### §3.4 Loop 与 Segment 联动

若同时开了 Loop 且选了 Segment（如 0.42~0.95）→ 仅循环 Segment 段；否则循环全 Clip。

## §4 改进 #4：Segment **显式起点/终点输入**

### §4.1 当前问题

截图中 "Segment" 行仅有进度条 `0.00~1.00`，无数字输入框。要精确给"起点 0.42 终点 0.95"必须靠拖（精度不可控）。

### §4.2 改造（**垂直布局**）

```
─── Segment ──────────────────────────────────────────────
☐ Enable Segment                       ← 总开关
                                       
起点 (Start)
┌────────────────────────────────────────────────────┐
│ 0.420                                          [+] │  ← DelayedFloatField + 加减按钮
└────────────────────────────────────────────────────┘

终点 (End)
┌────────────────────────────────────────────────────┐
│ 0.950                                          [+] │
└────────────────────────────────────────────────────┘

时长（自动计算）  Duration = 0.530s

可视进度条（拖动）
[━━━━━━━━━━━━●━━━━━━━━━━━━━━━━━━━━━━━●━━━]
              ↑ Start                  ↑ End

[ Snap to Frame ]  [ Reset 0~1 ]      ← 快捷按钮
```

### §4.3 字段规约

| 字段 | 类型 | 校验 |
|---|---|---|
| `Start` | `DelayedFloatField` | clamp [0, End - 0.01] |
| `End` | `DelayedFloatField` | clamp [Start + 0.01, 1.0] |
| `Duration`（只读） | LabelField | `(End - Start) × Clip.length` 秒 |
| `Snap to Frame` 按钮 | Button | 将 Start / End 各自吸附到最近 0.0333s（30fps）边界 |
| `Reset 0~1` 按钮 | Button | Start=0 / End=1 |

### §4.4 与 Loop 联动

启用 Segment 后，§3.3 的 Loop 自动只循环 Segment 段。

## §7 三句话沉淀

> 1. **竖直滚动 > 水平拥挤** —— 中文 label 必须在控件**上方**；不要省那一行
> 2. **预览要"所见即所得"** —— 真实位移叠加比看曲线轨迹直觉 10 倍
> 3. **数字输入是策划的尊严** —— 一切关键时间字段必须可精确数字输入 + Enter 提交，而非只能拖

## §9 不做项（明确 P3+）

- ❌ 编辑器主题 / 暗色模式定制（保留 Unity 默认）
- ❌ 预览窗多角色对比（同框看 Player + Enemy 动画）—— 独立切片

- ❌ Segment 多段（一个 Action 多个 Segment）—— 独立切片
