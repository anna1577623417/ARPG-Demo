> 1. **同一份 Runtime，N 种玩法** —— Variant + Modifier 是数据，不是代码分支
> 2. **Modifier = Buff payload** —— 接已有 EffectSystem/BuffStack，不开第二条道具通道
> 3. **落地 = 5 阶表现 + AOE 衍生** —— 跳跃和战斗在 GroundPound 天然咬合 176.1 HitExecutor

# 175.2【蓝图】Jump 系统深化 —— 马里奥组合跳 + 雨 2 叠层 + Buff 修饰链 + 落地分层

> **基线**：`175.1 Jump Ability.md`（Jump 是 Ability）/ `177.1 Stance+Ability`（W4 JumpAbilityConfigSO 骨架）
> **新增维度**：3D 马里奥**组合跳族**（TripleJump/LongJump/Backflip/SideFlip/WallJump/GroundPound/Dive/SpinJump） + 雨中冒险 2 **道具叠层修饰**（蜡鹌鹑 / 火堆羽毛 / 太空药水 / 死灵兜帽）+ Effect/Buff 子系统接入 + 5 阶**落地表现矩阵**。

## §0 设计目标（3A 验收口径）

| 维度 | 目标 |
|---|---|
| **可配置** | 全部 magic number 进 SO；无字面量 |
| **可组合** | "蹲 + 跑 + 跳" / "原地按反向 + 跳" / "刚转身 + 跳" → 不同跳法，全部数据驱动 |
| **可叠层** | 拾取道具 = 给 Player 挂一个 Buff = Runtime Modifier 修改 Jump 字段 |
| **可表现** | 落地按下落高度 + 当前 Stance + 水平速度 选择 5 阶表现 |
| **可调试** | HUD 实时显示 当前 Jump 玩法名 / 段数 / Coyote / Buffer / Modifier 叠层 |
| **可扩展** | 新跳法 = 新 `JumpVariantSO` + Action 资产；零代码 |

## §1 三大跳跃维度（同时正交）

```
                    输入
                     ↓
       ┌────────────────────────────┐
       │  Variant Resolver          │  ← ① 跳法识别（条件→玩法）
       │  原地 / 蹲跳 / 长跳 / 后空翻 │
       └─────────────┬──────────────┘
                     ↓
       ┌────────────────────────────┐
       │  Modifier Chain            │  ← ② Buff 叠层修饰
       │  Hopoo×N / Quail×N / ...  │
       └─────────────┬──────────────┘
                     ↓
       ┌────────────────────────────┐
       │  Phase State Machine       │  ← ③ 起跳→上升→Apex→下落→落地
       │  TakeOff / Rise / Apex /  │
       │  Fall / Land(5 阶)        │
       └────────────────────────────┘
```

每一层都数据驱动，互不耦合：
- **Variant** 决定**用哪份 BaseConfig**
- **Modifier** 决定**字段被改成什么**
- **Phase** 决定**当前播什么 Action / 应什么重力**

### §2.4 `JumpVariantResolver`（运行时识别）

```csharp
public sealed class JumpVariantResolver
{
    readonly JumpVariantSO[] _variantsByPriority;     // 按优先级排序（高 → 低）

    public JumpVariantSO Resolve(in JumpContext ctx)
    {
        for (var i = 0; i < _variantsByPriority.Length; i++)
        {
            var v = _variantsByPriority[i];
            if (Match(v.Condition, in ctx)) return v;
        }
        return _defaultVariant;     // 兜底 = Jump_Normal
    }
}

public struct JumpContext
{
    public StanceId CurrentStance;
    public bool Grounded;
    public bool SprintHeld;
    public float HorizontalSpeed;
    public float TimeSinceLastPivot;
    public bool WallContact;
    public int CurrentAirJumpsUsed;
    public int RemainingJumps;
    public int RecentLandComboIndex;        // 落地后连按段数（0/1/2 → 普跳/二连/三连）
    public float TimeSinceLastLand;
}
```

> **优先级关键**：Triple > Long > Back/Side > Run > Normal。失配自动降级，永不报错。

### §3.3 `JumpModifierStack`（接 Buff 子系统）

```csharp
public sealed class JumpModifierStack
{
    readonly Dictionary<JumpModifierSO, int> _stacks = new();

    public void Add(JumpModifierSO mod)
    {
        _stacks.TryGetValue(mod, out var n);
        if (mod.MaxStack < 0 || n < mod.MaxStack)
            _stacks[mod] = n + 1;
        Recompute();
    }

    public void Remove(JumpModifierSO mod) { /* 减 1 */ Recompute(); }

    /// <summary>
    /// 把 BaseConfig 中所有字段按 Modifier 链算出 EffectiveConfig，运行时 Jump 用 Effective。
    /// </summary>
    public void Recompute()
    {
        _effective = _base.Clone();
        foreach (var (mod, n) in _stacks)
        foreach (var fm in mod.FieldMods)
        {
            var v = fm.Value * n;
            switch (fm.Op)
            {
                case ModifierOp.Add:        _effective[fm.Field] += v; break;
                case ModifierOp.MulCurrent: _effective[fm.Field] *= 1f + v; break;
                case ModifierOp.MulBase:    _effective[fm.Field] += _base[fm.Field] * v; break;
            }
        }
        // 能力位累加：AirJumps += AddOneAirJumpPerStack ? n : 0
    }
}
```

### §3.4 与 Buff 子系统的接口

```csharp
// 与既有 EffectSystem / BuffStack 桥接：
// 雨 2 道具拾取 = EffectDataSO (StatModifier) + 触发 OnApply 注册 JumpModifier
public class JumpModifierBridge : MonoBehaviour
{
    void Awake() { GlobalEventBus.Subscribe<BuffAppliedEvent>(OnBuff); }

    void OnBuff(BuffAppliedEvent e)
    {
        if (e.Buff.JumpModifier == null) return;
        Player.JumpModifiers.Add(e.Buff.JumpModifier);
    }
}
```

### §4.4 落地分层判定

```csharp
LandingTier Resolve(float fallHeight, JumpVariantSO variant, JumpModifierStack mods)
{
    if (variant.Id == JumpVariantId.GroundPound) return LandingTier.Pound;
    if (mods.HasModifier<HopooFeather>() && fallHeight > 8f) return LandingTier.Light;  // 蓝羽免摔伤
    if (fallHeight < 1.5f) return LandingTier.Light;
    if (fallHeight < 3f)   return LandingTier.Soft;
    if (fallHeight < 5f)   return LandingTier.Normal;
    if (fallHeight < 8f)   return LandingTier.Heavy;
    return LandingTier.Roll;
}
```

## §5 § 组合跳（马里奥 64 三连跳关键）

### §5.1 `LandComboTracker`

```csharp
public sealed class LandComboTracker
{
    float _lastLandTime;
    int   _comboIndex;
    const float ComboWindow = 0.20f;          // 落地后 0.20s 内再按 Space → 进下一段

    public void OnLand() { _lastLandTime = Time.time; }
    public void OnJump()
    {
        if (Time.time - _lastLandTime <= ComboWindow) _comboIndex = Mathf.Min(_comboIndex + 1, 2);
        else _comboIndex = 0;
    }
    public int CurrentIndex => _comboIndex;
}
```

VariantResolver 读 `RecentLandComboIndex`：
- 0 → `Jump_Normal` / `Jump_Run`
- 1 → `Jump_DoubleTap`（中等高度 1.2×）
- 2 → `Jump_Triple`（高度 1.8× + 后空翻 Action）

### §5.2 Long Jump（蹲 → 跑 → 跳）

输入连续：Sprint 持续 + Crouch 触发滑铲（可选） + Space → `Jump_Long`：
- 水平 `+8 m/s`
- 垂直 `JumpForce × 0.6`
- 锁定方向（不允许空中转身）
- 玩家飞出去一大段 —— **跨大平台核心机制**

### §5.3 Backflip（按反向起跳）

`TurnResolver` 检测最近 0.15s 内 180° 反向输入 + Space → `Jump_Back`：
- 反向冲量 `BackwardImpulse`
- 垂直 `1.5×`
- `YawSpin = 180°`（角色身体翻转贴 Action）
- 落地朝向已反

## §7 § 完整数据流

```
Space 按下
   ↓
AbilitySystem.TryActivate(Jump)
   ↓ HasAbility / Cooldown / Tag 比对通过
JumpAbility.OnPressed
   ↓ 写入 JumpBuffer
   ↓
每 Tick：
   JumpVariantResolver.Resolve(ctx) → variant
   JumpModifierStack.Recompute → effective
   if (CanConsumeBuffer):
      ConsumeJump(variant, effective)
        ├ 应用冲量（JumpForce × UpwardMul + HorizontalBoost）
        ├ 播 variant.TakeOffAction
        ├ 播 variant.TakeOffVfx
        ├ Tags.State.Add(variant.CapabilityTags)   ← Movement.Airborne + Movement.Forced
        ├ JumpPhase = TakeOff → Rise
        └ ComboTracker.OnJump()
   ↓
Phase 状态机驱动重力 / Variable Height / Apex 悬停 / Glide
   ↓
Grounded 命中：
   LandingTier = Resolve(fallHeight, variant, mods)
   播 LandAction[tier]
   触发 VFX / Camera / 锁定窗口
   if (tier == Pound): GroundPound AOE
   ComboTracker.OnLand()
```

## §10 关键架构约束

1. **同一份 Runtime** —— 所有 Variant 共用 `JumpAbility` 一个类；新跳法只能加 SO，不能加类。
2. **Modifier 不修改 BaseConfig SO** —— `Recompute` 写入 `_effective` 副本；BaseConfig 永远 readonly。
3. **Variant 识别 = 优先级匹配** —— 第一个 Match 即返回；不允许多 Variant 投票。
4. **落地 Tier 全数据驱动** —— 阈值 / Action / VFX / Camera 全在 `LandingTierProfileSO`。
5. **GroundPound AOE 走 176.1 HitExecutor** —— 跳跃系统不直接计算伤害，转译为攻击实例。
6. **Modifier 接 Buff 子系统** —— 道具拾取 = `EffectSystem.ApplyEffect(StatModifier)` payload 含 `JumpModifierSO`；不允许另开通道。
