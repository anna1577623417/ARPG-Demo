收到。169.3 的 Log 说明：**Layout/Repaint 每帧 `draw guid=…` 完全没用**，有效信息其实就几条 `SWITCH` / `STALE-FOCUS`。

已改成 **事件-only、去重** 的诊断：

## 改动

- **删除** 所有 Draw 每帧 Log（Layout/Repaint 不再刷 Console）
- **仅保留** 这些事件（每条最多打一次，Buffer 上限 16）：
  - `SELECT A→B` — 点击切边
  - `SWITCH A→B … focusCleared=… editingTF=…` — Inspector 切边
  - `STALE-FOCUS …` — 未 Enter 切边仍持旧 LateWindow 焦点（根因信号）
  - `SAVE-LATE` — Enter/失焦提交成功
  - `SYNC` — 仅 Committed 真变化时
  - `WARN` — 异常才打
- 实时状态改看 Debug 折叠里的 **Live 面板**（不刷 Console）

## 复现预期（A 改 Late → 不按 Enter → 点 B）

大约 **3～5 条**，例如：

```
[CombatFlowGraph][Insp] SELECT 95c24e7e→9322f49a ComboB→ActionC metaLate=2.000

```

169.3 已足够定位：**不按 Enter 切边 → `STALE-FOCUS` + `focusCleared=False`（首帧 Layout 跳过了清焦点）**。若你要修 bug，下一刀应在切边时强制 Apply/清焦点，而不是再加 Log。

以后 Editor 诊断默认按这个粒度：**事件驱动、一次复现 ≤10 条**；不够再收窄设计。
