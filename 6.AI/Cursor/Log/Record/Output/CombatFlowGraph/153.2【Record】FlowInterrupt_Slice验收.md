## 二、Play 验收（Debug Skill Route 开启）

### 2.1 Flow — JumpLanding → ChopDown

**前置**：Loadout 启用 CombatFlow；Slide 链路与 Flow 边独立配置。

| 步骤 | 预期 Log（前缀 `[Flow]` 或 SkillRoute） |
|---|---|
| 进入 JumpLanding 段 | `BindEntryAction …JumpLanding…` |
| 合法窗口按 LM（或所配 slot） | `FLOW advance cursor JumpLanding→ChopDown route=…` |
| 同上 | `RESOLVE node=JumpLanding in=LM … → edge→Route_…_ChopDown` |
| Route 进入 | `BindEntryAction ChopDown node …→ChopDown`（与 FLOW advance 目标一致） |

**失败定位**：
- 无 `FLOW advance` → L3 未编译 / EdgeKind 非 Flow
- `DIAG FLOW To.Action 与 Route 入口不一致` → L2 Validate 应已拦，检查是否未 Compile
- `DUAL_GATE block reason=graph-miss` → 游标不在 JumpLanding 或 InputSlot 不匹配

### 2.2 Interrupt — SlideExit → 剑冲（Route 藏边）

| 步骤 | 预期 Log |
|---|---|
| MultiStage 游标到 SlideExit | `DIAG cursor=SlideExit OnInput 边: …[Interrupt]` |
| Exit 段按 RM | `INTERRUPT via edge route=… SlideExit→End` |
| Route 进入 | `BindEntryAction SKIP interrupt-cursor stay=End action=…Sword_Dash…` |
| 双闸门 | `DUAL_GATE pass` 或 `RESOLVE node=SlideExit in=RM`（视 Early Window 配置） |

**MultiStage 段内**：段切换仍应出现 `BindEntryAction SlideLoop/SlideStart…`（非 SKIP）。

## 三、Validator 四类误配（Editor Validate）

| 误配 | 预期 ERROR（含 `flowEdges[n]`） |
|---|---|
| Flow + MultiStageRoute + To=ActionNode | `Flow 边不接受 MultiStageRoute（请用 Interrupt→End）` |
| Flow + NormalRoute 多 Stage 且未开 Single Action | `NormalRoute contains multiple stages` |
| Flow + To.Action ≠ Route 入口 | `Flow 边 To 动作与 Route 入口 Action 不一致` |
| Interrupt + To≠End | `Interrupt 边必须连接 End 节点` |

附加：**Combo/Charge Route 进边** → `不可进图（Combo/Charge 等 Unsupported）`  
附加：**MultiStageRoute + To=ActionNode**（任意 EdgeKind）→ `MultiStageRoute must terminate at EndNode`
