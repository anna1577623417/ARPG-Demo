# 167.1 Exit Velocity Policy — 运行时诊断单

配套蓝图：`166.1【蓝图】减速策略可配置化与Log探针诊断清单.md` · `167.1【蓝图】Action退出减速策略矩阵_Segment预留兼容.md`  
用户陈述：Inspector 切换 Snap / LinearDecay / Tap 等策略体感无差，都像 MotionCurveDriven；缺少「跑得越久减速越久」与 Tap 急停。

---

## 一、结论摘要（代码静态审计）

| 项 | 结论 |
|---|---|
| **167.1 运行时分发** | **已 WIRE** — `PlayerActionState.OnExit` → `ApplyExitVelocityPolicy` switch 覆盖 10 种枚举 |
| **衰减 Tick** | **已 WIRE** — `PlayerLocomotionState.OnLogicUpdate` 优先 `TryTickVelocityDecay`，期间不走 `StopMove` |
| **TapJump** | **已 WIRE，但触发面≠OnExit** — 仅在 **WalkStart/RunStart** 松手边沿；End Action 上配无效 |
| **资产默认值** | **全库 ExitVelocityPolicy=0（MotionCurveDriven）**；`Walk_End` / `Run_End` YAML **无该字段** → 运行时恒为默认 |
| **「跑得越久越久停」** | **无独立策略**；最接近的是 **`SpeedProportional`（初速越大 → 减速越久）**，不是累计跑步时长 |
| **体感无差主因** | ① 测错 Action（End vs Start）；② End 资产未落盘；③ WalkEnd `ZScale=0` 退出时残余≈0；④ RunEnd 曲线末段斜率≈0 → MotionCurveDriven 自动 Clear ≈ Snap；⑤ Log 门控导致以为「没执行」 |

**Landing 判定**：设施 + 分发 **Landing Done**；Slice 未闭环 — 资产预设、Log 可观测性、Tap 验收脚本待用户 Play 对照。

## 二、代码通电表（167.1 十策略）

| Policy | 枚举 | 触发点 | 运行时 | 验收 Log / 行为 |
|---|---|---|---|---|
| MotionCurveDriven | 0 | `OnExit` | **WIRE** | `policy=MotionCurveDriven`；末段斜率 `< threshold` → `cleared=true` |
| Snap | 1 | `OnExit` | **WIRE** | `cleared=true`，`[Loco][Enter] mag≈0` |
| LinearDecay | 2 | `OnExit` → `BeginVelocityDecay(Linear)` | **WIRE** | Exit 后 N 帧 `mag` 线性下降；`LinearDecayDuration` 或 Tuning 默认 0.15s |
| ExpDecay | 3 | `OnExit` → `BeginVelocityDecay(Exp)` | **WIRE** | 指数衰减至 `factor≤0.01` 清零 |
| FixedDuration | 4 | `OnExit` | **WIRE** | 固定 `FixedDecelDuration` 内归零 |
| FixedDistance | 5 | `OnExit` | **WIRE** | `T=2×距离/v0` 线性衰减 |
| **SpeedProportional** | 6 | `OnExit` | **WIRE** | **`T=v0×DurationPerUnitSpeed`**（初速 proportional，非跑步时长） |
| StepDecay | 7 | `OnExit` | **WIRE** | 按 `StepValues` 台阶跳变 |
| PreservedSlide | 8 | `OnExit` | **WIRE** | 保留残余；可选 `SlideMaxResidualSpeed` cap |
| TapJumpToEndTail | 9 | **Start 期间松手** | **WIRE** | `[TapJump]`（`LocomotionDebug`）；`OnExit` 分支 **空操作** |

## 三、资产审计（GhostSamurai 默认套）

| Action 资产 | YAML 有 `ExitVelocityPolicy`? | 当前有效值 | MotionProfile 备注 |
|---|---|---|---|
| `GhostSamurai_Common_Walk_End` | **否** | 默认 **0** MotionCurveDriven | `ZScale=0` → Action 期间位移≈0，退出 `residualVel≈0` |
| `GhostSamurai_Common_Run_End` | **否** | 默认 **0** | `ZScale=2`，末段斜率≈0 → MotionCurveDriven **自动 Clear** ≈ Snap |
| `GhostSamurai_Common_Walk_Start` | 是 | **0** | Tap 须改 Start，不是 End |
| `GhostSamurai_Common_Run_Start` | 是 | **0** | 同上 |
| Walk/Run **Loop** | 是 | **0** | Loop **不触发** Exit Policy（非 End hint） |

**Inspector 改策略后必须 Ctrl+S 落盘**；`Walk_End` / `Run_End` 首次保存会在 YAML 写入 `ExitVelocityPolicy` 行。

## 四、「体感都像 MotionCurveDriven」根因矩阵

| ID | 假设 | 静态证据 | 如何一锤定音 |
|---|---|---|---|
| **H1** | 在 **WalkEnd/RunEnd** 改策略，但 YAML 未保存 | End 资产无字段 | 打开 `.asset` 搜 `ExitVelocityPolicy`；Play 前确认已保存 |
| **H2** | 在 **End** 上配 **TapJumpToEndTail** | Tap 只读 Start + 松手边沿 | 改 **WalkStart**；短按 W < `TapWindowSec` 后松手 |
| **H3** | **WalkEnd ZScale=0**，退出残余速度≈0 | 各 Policy 从 v≈0 出发 | `[Action][Exit] mag`：Snap/Linear/Exp 全≈0，无可见差 |
| **H4** | **RunEnd 曲线末段斜率 < 0.5** | MotionCurveDriven 强制 Clear | 与 Snap 同为 `cleared=true`；要差开需 **PreservedSlide** 或 **非零末段斜率 + 不清零** |
| **H5** | 期望 **累计跑步时长** 决定减速 | 无此 API | 用 **SpeedProportional**（退出瞬间速度）或新策略（OPEN） |
| **H6** | Log 未开，以为代码没跑 | 见 §五 门控缺陷 | 开 `Player.DebugLocomotion` 后重测 |
| **H7** | 测 **Loop** 或 **Combat Action** | 仅 `endHint=WalkEnd/RunEnd` 时写 EndHint | 须完整 **RunLoop→松手→RunEnd→Idle** 链路 |

## 五、Log 探针（Play 前必做）

### 5.1 开关

| 字段 | 位置 | 用途 |
|---|---|---|
| **Debug Locomotion** | `Player` 组件 | `[Action][Exit]`、`[Loco][Enter]`、`[Loco][EndHint]` |
| **Locomotion Debug**（可选） | Profile / 全局 | `[TapJump]` 短按跳转 |

### 5.2 Console 过滤

```
[Action][Exit]|[Loco][Enter]|[Loco][EndHint]|[TapJump]
```

### 5.3 预期关键行（RunEnd 完整停跑一次）

```
[Loco][EndHint] set=RunEnd frame=...
[Action][Exit] endHint=RunEnd policy=??? residualVel=(...) mag=?.?? cleared=???
[Loco][Enter] planarVel=(...) mag=?.??
```

### 5.4 门控缺陷（可观测 OPEN）

`ApplyExitVelocityPolicy` 在 `endHint!=None` 时调用 `LogActionExitVelocity`，但 **该函数内部仍要求 `DebugLocomotion`**，否则 **静默不写 Log**。

→ **验收前必须勾选 Debug Locomotion**；否则无法对照 policy 字段。

## 六、Play 验收脚本（按策略）

> 通用：进 Play → 勾选 Debug Locomotion → 跑完一条链路 → 贴 Console 三行 `[EndHint][Exit][Enter]`。

### 6.1 基线 — 确认 Policy 字段真的被读到

1. 打开 `GhostSamurai_Common_Run_End_ActionData`
2. 设 **Exit Velocity Policy = Snap**，**保存资产**
3. Play：RunLoop 按住 W → 松手触发 RunEnd → 等 End 播完
4. **预期**：`policy=Snap`，`cleared=true`，`[Loco][Enter] mag=0.00`

若仍为 `policy=MotionCurveDriven` → **H1 未保存或 Profile 绑错 Action**。

### 6.2 Snap vs LinearDecay（RunEnd，需非零退出速度）

1. RunEnd 设 **PreservedSlide** + `SlideMaxResidualSpeed=6` **或** 临时把 RunEnd MotionProfile 末 5% 斜率调高（仅诊断）
2. 分别测 **Snap** 与 **LinearDecay=0.8s**
3. **预期差**：
   - Snap：`[Enter] mag=0`，无滑行
   - LinearDecay：`[Exit] mag>1`，随后 0.8s 内 `[Enter]` 后多帧速度递减（可看 `[Loco][Enter]` 仅首帧；需加 Move trace 或目视）

**WalkEnd 不适合本项**（ZScale=0，残余恒≈0）。

### 6.3 SpeedProportional — 「快停得久、慢停得短」

1. RunEnd → **Speed Proportional**，`DurationPerUnitSpeed=0.08`（8m/s → 0.64s）
2. 全速 RunLoop 再松手 vs 短按 RunStart 即松（低 v0）
3. **预期**：高 v0 时 Exit 后滑行更久；**不是** RunLoop 按住时长

### 6.4 TapJumpToEndTail — 绝区零式点按急收

| 步骤 | 操作 |
|---|---|
| 1 | 改 **`GhostSamurai_Common_Walk_Start`**（不是 WalkEnd）→ **TapJumpToEndTail** |
| 2 | `TapWindowSec=0.15`，`EndTailNormalizedStart=0.6`（或 Tuning 默认） |
| 3 | Play：轻点 W **<0.15s 后松手**（仍在 WalkStart 段） |
| 4 | **预期**：`[TapJump] start→end=...Walk_End nt=0.60`；几乎无大步，直接收脚 |

**失败对照**

| 现象 | 原因 |
|---|---|
| 仍播完整 WalkStart | 按住超过 TapWindow；或 Policy 配在 End 上 |
| 无 `[TapJump]` | 未开 LocomotionDebug；或未发生 move release 边沿 |
| 跳到 End 但还滑 | End 自身 Exit Policy 仍为 MotionCurveDriven + 有残余 |

### 6.5 PreservedSlide — 滑步 / 绝区零 End 期间可微移

1. RunEnd → **PreservedSlide**，`SlideMaxResidualSpeed=0`（不限）或 4
2. **预期**：End 退出后 `[Enter] mag>0`，Locomotion 无输入时仍惯性；`CanMoveDuringLocomotion=1` 时可微调方向

## 七、策略 ↔ 设计意图对照（避免配错）

| 你想要的手感 | 应配 Action | 应选 Policy | 参数提示 |
|---|---|---|---|
| 播完立刻钉死 | RunEnd / JumpLand | **Snap** | — |
| 固定 0.3s 匀减速 | RunEnd | **LinearDecay** / FixedDuration | 0.3s |
| **退出瞬间越快，滑越久** | RunEnd | **SpeedProportional** | `DurationPerUnitSpeed` 0.05~0.1 |
| **固定滑出距离** | RunEnd | **FixedDistance** | 0.6~1.4m |
| 柔停（指数） | RunEnd | **ExpDecay** | halfLife 0.2~0.4 |
| 滑步可转向 | RunEnd | **PreservedSlide** | cap 可选 |
| 跟 Motion 曲线自然收 | RunEnd | **MotionCurveDriven** | 末段斜率→0 则≈Snap |
| **点按急停、几乎原地收脚** | **WalkStart / RunStart** | **TapJumpToEndTail** | TapWindow + EndTailStart |
| **跑得越久停越久** | — | **OPEN** | 现有无；需累计 Run 时长或 Loop 时长新字段 |
