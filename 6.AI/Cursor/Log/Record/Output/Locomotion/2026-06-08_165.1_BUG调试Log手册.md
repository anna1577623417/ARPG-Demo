## 三、按 Bug 验收脚本

### Bug #1 + #4 — 动作时序双时钟（闪一下 / 播完才动）

**操作**：任意离散 Action（WalkEnd、JumpLand、LM 普攻）各播一次。

**预期 Log（每条 Action 进入一次）：**

```
[Action][AnimSync] action=XXX dur=0.500 clip=1.500 animSpd=3.000 autoSync=True
```

**判定：**

| 现象 | 对照 Log | 断点 |
|------|----------|------|
| 逻辑到点但 Clip 只播 1/3 | `animSpd` 仍 ≈1，`autoSync=False` | Action SO 关 AutoSync 或 Duration=0 |
| `animSpd` 正确但仍闪 | 无 AnimSync 但有 `[Action][Exit]` 过早 | 查 `nt` 与 MotionProfile 位移曲线 |
| 无 `[Action][AnimSync]` | Debug Locomotion 未开 | 开开关重试 |

**手算校验：** `animSpd ≈ clip ÷ dur`（误差 <0.01）。

---

### Bug #2 — Land 三源 / Profile 未读

**操作**：Space 跳 → 落地；Profile.Bindings 配好 `JumpLand.Action`。

**预期顺序：**

```
[Jump][OnEnter] ... profileJumpStart=...
[Jump][Land] source=Profile action=Loco_JumpLand fallHeight=...
[Action][AnimSync] action=Loco_JumpLand ...
```

**不应出现**（Profile 已配时）：`source=NONE → fallback PlayerAnimLibrary.Airborne_Land`

**判定：**

| 现象 | 断点 |
|------|------|
| `source=NONE` + **Warning** Profile 未配置 | LocomotionProfile 未绑 Player / Bindings 无 JumpLand |
| 闪一下 Idle 再 Land | 旧 AnimLibrary 与 Action 双播 → 查 Profile 是否真有 Action |
| 仍走 ctx 老动画 | 165.1 已移除 ctx 播放链；查是否未编译新代码 |

---

### Bug #3 — WalkEnd/RunEnd 打断后 Start 误触

**操作**：Run 中松手 → RunEnd 播放中按 W 打断 → 应进 Run Loop，**不重播 RunStart**。

**预期 Log：**

```
[Loco][EndHint] set=RunEnd frame=...
[Loco][SuppressEdge] frame=3 reason=AfterEnd hint=RunEnd frame=...
（随后 2 帧内无 WalkStart/RunStart 的 Resolver 离散段请求）
```

**判定：**

| 现象 | 断点 |
|------|------|
| 无 `[Loco][EndHint]` | 打断的不是 Profile 注册的 RunEnd Action |
| 无 `[Loco][SuppressEdge]` | 未从 End Action 回 Locomotion（可能直接 Interrupt 切状态） |
| 有 Suppress 仍 RunStart | Detect 在 3 帧后仍见 release 边沿 → 加帧数或查 latch 同步 |

**对照（应不受影响）**：站立连点 W → **无** `[Loco][EndHint]` / `[Loco][SuppressEdge]`，Start↔Idle 正常。

---

### Bug #5 — 跳起后 WASD 不响应

**操作**：Space 跳 → JumpStart Action 期间按住 W。

**预期 Log（节流 ~0.25s）：**

```
[Action][AirLocoMove] action=JumpStart grounded=False wantsRun=False frame=...
```

**判定：**

| 现象 | 断点 |
|------|------|
| 无 AirLocoMove | IntentCategory≠Locomotion 或已 grounded |
| 有 Log 但角色不动 | MotionExecutor 锁位移 / AirMoveMultiplier=0 |
| JumpStart 占满整段跳跃 | 缩短 JumpStart Duration 或改 Continuous（164.1 §13.1） |

---

### Bug #6 — 多 Stage 连招末段卡僵

**操作**：Graph 内 LM 多段 Route，末段下劈播完。

**预期 Log：**

```
[Action][Exit] reason=LastStageComplete action=XXX nt=1.000 routeActive=True stageCompleted=True isLastStage=True routeEnded=False frame=...
```

**判定：**

| 现象 | 断点 |
|------|------|
| 无 Exit Log、角色卡 Action | `stageCompleted=false` → Stage 未标完成 |
| `reason=RouteEnded` 仍卡 | NotifyRouteExited / 状态机未 Change |
| 只有 `routeEnded=false` 且无 Exit | 165.1 兜底未生效 → 查 `IsLastStage` |

**资产侧（仍推荐）**：末段 Stage 加 Auto Transition → Exit。

---

### Bug #7 — WW 双击跑步 → Ctrl Toggle

**操作**：W 移动 → 点 LeftCtrl（Sprint）→ 再点切换回 Walk。

**预期 Log：**

```
[Loco][Run] mode=Toggle trigger=SprintToggleEdge wantsRun=True toggled=True sprintHeld=True frame=...
[Loco][Run] mode=Toggle trigger=SprintToggleEdge wantsRun=False toggled=False ...
```

**判定：**

| 现象 | 断点 |
|------|------|
| 无 `[Loco][Run]` | Debug Locomotion 未开 |
| 双击 W 仍切 Run | 旧逻辑残留 → `grep DetectDoubleTapCardinalStickyRun` 应为 0 |
| Ctrl 无反应 | 确认 `.inputactions`：Sprint=**leftCtrl**，Shift 只绑 **SlotAbility_07** |
| Shift 误触发跑步 | Sprint 曾误绑 shift（165.1 已拆）→ 重进 Play 或 Reimport Input Actions |

**Hold 模式**：`LocomotionTuning.RunInputMode = Hold` → 应见 `trigger=SprintHoldChange`。

## 四、推荐 Play 顺序（一次会话）

1. 开 `Debug Locomotion` + `Debug Skill Route`
2. **#1** — 走/停/跳 Land 各一次，确认 `[Action][AnimSync]`
3. **#2** — 跳落地，确认 `[Jump][Land] source=Profile`
4. **#7** — Ctrl Toggle 跑，确认 `[Loco][Run]`
5. **#3** — Run 松手 + 立刻 W，确认 `[Loco][SuppressEdge]`
6. **#5** — 跳起按住 W，确认 `[Action][AirLocoMove]`
7. **#6** — 多段 LM 连招，确认 `[Action][Exit] reason=LastStageComplete`
