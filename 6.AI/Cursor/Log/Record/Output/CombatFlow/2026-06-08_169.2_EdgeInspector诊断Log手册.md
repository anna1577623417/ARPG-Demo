# 169.2 Edge Inspector LateWindow 残留 — 诊断 Log 手册

## 原则（169.3 教训）

- **仅事件 Log**：边切换、Late 保存、异常；**禁止** Draw/Layout/Repaint 每帧刷屏。
- 典型复现（A 改 Late 不按 Enter → 点 B）预期 **≤5 条** Console。
- 实时状态看 Inspector **Debug → Live** 面板，不刷 Console。

## 开启

工具栏 **Insp Dbg*** → 复现 → **Copy Buffer**（最多 16 条）

## 事件类型

| 前缀 | 何时 |
|---|---|
| `SELECT A→B` | 点击切边（GUID 变化） |
| `SWITCH A→B metaLate=… focusCleared=… editingTF=…` | Inspector 绘制切边（每切一次一条） |
| `STALE-FOCUS … stillFocused=…` | **根因信号**：未 Enter 切边，仍持上一条 LateWindow 焦点 |
| `SAVE-LATE …` | EndChangeCheck 成功写入 meta |
| `SYNC …` | GraphView 延迟同步且 Committed 真的变了 |
| `WARN …` | draw≠committed / gv≠committed / metaGuid 异常 |

## 169.3 已确认

- Enter 可提交并避免残留；不按 Enter 切边 → `STALE-FOCUS` + `focusCleared=false`（首帧常为 Layout）。
- 修复方向：切边时在 Layout 也能安全清焦点，或切边前强制 Apply FloatField。

## 判定

| 现象 | 结论 |
|---|---|
| 有 `STALE-FOCUS`，`metaLate` 正确 | H4 IMGUI 编辑缓存；非 meta/Selection |
| 无 `STALE-FOCUS` 但 UI 错 | 再开一轮更窄 Log |
| `WARN draw≠committed` | Selection 与 Draw 不同步 |
