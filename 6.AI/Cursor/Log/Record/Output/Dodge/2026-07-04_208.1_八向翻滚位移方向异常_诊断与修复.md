# 208.1 八向翻滚 — 位移方向异常（W 松手 → D+Space）

## 现象

按住 W 前进 → 松开 W → 快速 D+Space：**动画选对右翻滚**（`Route_Normal_GhostSamurai_Dodge_R`），但 **Motion 位移**可能向左/向后，与曲线预期不符。

## 根因（双轨不一致）

| 层 | 依据 | 208.1 Log 证据 |
|----|------|----------------|
| **Route 选路** | `InputChordResolver` camera-relative，`moveBuf=(1,0)` → **Right** ✓ | `PICK mode=Chord dir=Right` |
| **Motion 基底** | `InputContextResolver.CommitDirectionalAbility` 在 Chord 窗内用 **`captured@MoveDown`** | `Commit fwd=(-0.10,0.99) source=captured@MoveDown live=(-0.04,-1.00)` |

1. **Grace 继承**：松 W 后 0.12s 内按 D，`_capturedPlanarForward` **不刷新**，仍保留首次 W 的 MoveDown 快照。
2. **Locomotion 漂移**：持 W 跑步时 `LogicForward` 已更新，captured 仍停在旧值（Log 中 captured 与 live **接近反向**）。
3. **Motion 曲线**：`GhostSamurai_Dodge_R` 沿 **local +X** 位移；`MotionExecutor` 用 `burstFaceDir` 作 Z 轴，**local +X = 该 forward 的右方**。基底 forward 错误 → 世界位移方向错误。

Route 与 Motion 用了**两套方向系**（Chord camera vs  stale LogicForward capture）。

## 修复（208.1 落代码）

| 文件 | 变更 |
|------|------|
| `InputContextResolver.cs` | MoveDown **始终刷新** capture；持键期间同步 capture；Chord Commit 用 **camera forward** 作 Motion 基底 |
| `Player.cs` | `CommitDirectionalInputContext(moveBuf)` → Chord 窗内传 `ResolveCameraRelativeWorldDirection(up)` |
| `InputSemanticResolver.cs` | Directional 入队时传入 moveBuffered |
| `DodgeChord8Probe.cs` | Commit Log 增加 `source=cameraBasis@Chord` |

**契约**：Chord 短按 — Route 与 Motion 均 camera-relative；Motion 长按 — 仍用 live `LogicForward`（206.2 #5/#8）。

## Play 验收（Tools → Skill Route → Enable DodgeChord8 Log）

**复现序列**：W 长按 → 松 W → D+Space（holdDur &lt; 0.12s）

预期 Log 片段：

```
[DodgeChord8] Chord moveBuf=(1.00,0.00) → Right (camera-relative)
[DodgeChord8] Commit fwd=(…) source=cameraBasis@Chord captured=(…) live=(…)
[DodgeChord8] PICK mode=Chord dir=Right route=Route_Normal_GhostSamurai_Dodge_R
```

**肉眼**：角色向 **camera-right** 滑出，与 R 翻滚 MotionProfile X 曲线一致。

**回归**：206.2 矩阵 #5 D 长按 + Space → 仍 `source=liveLogicForward`、F-Dodge。
